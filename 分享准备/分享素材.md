# **一、最值得直接复用的素材**

## **1. TensorFlow Playground**

这是整个机器学习、深度学习阶段最值得使用的素材。

它能在浏览器中实时展示：

- 数据集；
- 输入特征；
- 神经网络层数；
- 每个神经元学到的特征；
- 激活函数；
- 决策边界；
- 训练损失与测试损失；
- 学习率；
- 正则化。

可以直接用于演示：

1. 线性模型只能画直线边界；
2. 非线性数据为什么难以分类；
3. 激活函数有什么作用；
4. 增加隐藏层后发生了什么；
5. 神经元如何学习不同的局部特征；
6. 多层网络如何组合简单特征；
7. 训练集效果和测试集效果的区别；
8. 过拟合与正则化。

TensorFlow Playground 可以直接在浏览器中运行神经网络训练，并允许调整数据、特征、隐藏层、激活函数和学习率。Google 的机器学习课程也将其用于神经网络交互练习。 

### **最适合你的演示方式**

#### **演示一：单层线性模型**

选择两团可以被直线分开的数据，只保留输入与输出层。

讲：

网络正在寻找一条线，将两类数据分开。

#### **演示二：圆形分类数据**

先不加隐藏层，让它分类失败。

再增加隐藏层和 ReLU 或 Tanh。

讲：

一个神经元只能学习一种简单分割，多个神经元先学习不同边界，后面的层再把它们组合成圆形区域。

#### **演示三：螺旋数据**

让听众看到即使增加网络层，也不一定容易训练。

讲：

神经网络有更强的表达能力，但有能力表达，不代表一定能顺利学出来。

### **建议**

分享现场直接操作一次，PPT 中再保留两张关键截图：

```text
截图一：没有隐藏层，无法解决圆形分类
截图二：加入隐藏层，逐步组合出圆形边界
```

这两张图可以承担“线性模型 → 激活函数 → 多层网络 → 特征学习”的主要解释任务。

## **2. Google Machine Learning Crash Course**

适合提取机器学习基础部分的：

- 线性回归图；
- 损失函数图；
- 梯度下降过程；
- 分类与概率；
- 训练集、验证集、测试集；
- 过拟合；
- 神经网络交互练习。

Google 的线性回归章节用图形解释梯度下降如何反复调整权重和偏置，以寻找更低的损失。 

### **你可以直接借鉴的内容**

机器学习训练闭环可以压缩成：

```text
给定模型参数
    ↓
根据样本进行预测
    ↓
计算预测与真实值的差距
    ↓
根据误差调整参数
    ↓
继续重复
```

Google 的原图可以作为理解参考，但正式分享最好自己重新画一张更简洁的中文版本。原因是原课程图通常带有较多教学文字，直接截图不利于现场表达。

## **3. CNN Explainer**

这是讲 CNN 最适合现场展示的交互网站。

它可以动态查看：

- 输入图片；
- 卷积核；
- 卷积计算；
- 特征图；
- ReLU；
- 池化；
- 各层数据形状；
- 最后的分类概率。

CNN Explainer 专门面向非专业学习者，用交互方式展示 CNN 中间结果和数据流，可以在浏览器中直接运行。 

### **最适合讲的三个画面**

#### **画面一：卷积核在图片上移动**

讲：

CNN 使用一个小窗口，在图片的不同位置寻找相同模式。

#### **画面二：卷积之后得到特征图**

讲：

输出不再是一张普通图片，而是一张“某种特征在哪里出现”的地图。

#### **画面三：多层 CNN**

讲：

```text
前层：边缘、方向、颜色变化
中层：纹理和局部形状
后层：物体部件和类别特征
```

CNN Explainer 的优势是，它能把单次数值计算和完整网络结构放在同一界面中。 

### **分享中的定位**

CNN 不要讲十分钟。

用这个网站演示三分钟，就足以说明：

深度学习可以逐层学习特征；CNN 通过局部连接和参数共享，利用图像的空间结构。

## **4. 手写数字神经网络可视化**

Adam Harley 的神经网络可视化网站允许用户手写数字，并实时查看神经网络各层神经元的激活变化。 

它适合讲：

- 原始输入是像素；
- 中间层不是明确的人类概念；
- 不同输入会激活不同的内部模式；
- 最后一层输出各数字的预测结果。

### **适合的讲解**

先让现场听众写一个数字，例如“7”。

然后展示：

```text
像素输入
→ 中间神经元产生不同响应
→ 最后输出 0～9 的概率
```

这比单纯展示一张神经网络结构图更生动。

它不适合拿来精确解释每层学习到了什么，因为中间表示未必能直接对应“边缘”“圆圈”等人类概念。

# **三、RNN 可直接使用的素材**

RNN 的优质交互素材相对 CNN 少，而且很多工具直接进入梯度传播和隐藏状态细节。

RNNbow 是一个用于展示 RNN 训练时梯度流动的交互系统，重点包括时间反向传播和梯度消失。 

但你的分享不建议使用它，原因是：

- 过于深入；
- 画面不容易被非专业听众理解；
- RNN 在分享中只是 Transformer 的前置铺垫。

RNN 最适合自己制作一张动画：

```text
输入：我
      ↓
状态 h₁

输入：喜欢 + h₁
          ↓
        状态 h₂

输入：学习 + h₂
          ↓
        状态 h₃
```

然后让状态逐步流动。

再画第二张：

```text
第一个词的信息
→ 状态1
→ 状态2
→ 状态3
→ 状态4
→ 最后一个词
```

用逐渐变淡的颜色表示信息经过多步传递。

这一部分自己做，比找复杂网站更合适。

# **六、不要直接复用整套 PPT**

你的主线是：

```text
学习参数
→ 学习特征
→ 利用数据结构学习特征
→ 序列建模遇到瓶颈
→ Transformer
```

现成课程的主线通常是：

```text
算法定义
→ 数学推导
→ 代码实现
→ 训练技巧
→ 更多算法
```

所以现有素材的最佳使用方式是：

```text
现成网站：承担现场演示
现成课程：承担知识校验
现成图片：承担局部解释
自己的 PPT：承担完整叙事
```

# **七、素材版权和使用原则**

内部技术分享通常可以引用公开教学材料，但仍建议：

- 页面底部标明来源；
- 尽量使用官方网站或原作者页面；
- 不删除原始水印；

- 对核心图进行重新绘制，而不是大量截图；
- 现场演示网站时直接展示原页面。
