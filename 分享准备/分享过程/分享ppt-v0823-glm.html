四 · LLM

采样：Temperature / Top-K / Top-P

模型输出的是：下一个 Token 的概率分布。如何从中选 Token？

Temperature

控制分布的平滑程度：低 → 更确定；高 → 更多样。

T 低
T 高

Top-K

只在概率最高的 K 个 Token 中采样。

A .41B .27C .16 D .09E .07

Top-P

选择累计概率达到 P 的 Token 集合后采样。

A .41B .27C .16 D .09

A+B+C 累计 .84，D 加入后超 P=0.9。

一句话采样控制的是生成的随机程度与风格，不负责判断答案真假。

五 · 收尾

总结：智能的涌现

今天的大模型，底层仍然只是在预测下一个 Token。

真正发生变化的是：人不断把原本需要显式设计的规则、参数、特征、上下文关系，以及部分任务表达，交给数据、模型与优化过程。

当结构足够通用、数据足够丰富、规模足够大之后——
为了做好「预测下一个 Token」这件简单的事，模型表现出了越来越多我们称之为「智能」的能力。
