# **我的学习原则：不要从地基无限往上学**

## **1. 当前核心问题**

我不是学得不够，而是**学得太深、太散、太底层**。

最大的误区是：

为了理解上层，试图先完整学完所有底层基础。

这条路线逻辑正确，但效率很低，容易进入无底洞。

---

## **2. 正确的学习方式**

采用：

**先建立完整地图 → 找到自己的能力边界 → 在边界处向外扩展 → 真正卡住时才向下补基础。**

不要默认从最底层开始。

判断是否值得深入一个知识点，只看三件事：

1. 不懂它，是否导致主线讲不通？
2. 不懂它，是否导致无法实践？
3. 它是否就在我当前能力边界附近？

如果都不是：

**记录下来，暂时不学。**

---

## **3. AI / LLM 学习目标**

不要追求：

从 0 完整学完人工智能。

改成：

**建立一套能够解释“为什么现代 LLM 会演化成今天这样”的完整心智模型。**

主线始终围绕六个问题：

1. 当时的问题是什么？
2. 旧方法为什么不行？
3. 新方法提出了什么？
4. 核心机制是什么？
5. 它解决了什么？
6. 它又留下了什么问题？

沿着演化主线学习：

规则系统 → 人工神经元 → 感知机 → MLP → BP → CNN / RNN → LSTM → Attention → Transformer → GPT-1/2/3 → Scaling → 指令微调 → RLHF → LLaMA → MoE → 现代 LLM → Agent。

**数学、论文细节、历史细节都是支撑材料，不是主线。**

---

## **4. AI 学习的完成标准**

不要用：

“我是不是把所有细节都理解了？”

作为完成标准。

改成：

**我能不能脱离资料，把这个节点清晰讲明白？**

每个主题最终压缩成一页：

- 问题
- 旧方案
- 新方案
- 核心机制
- 收益
- 代价
- 下一步演化

能讲清楚，就先继续往前。

---

## **5. 三条学习线的定位**

### **工作线：深**

当前刚转组，学习新业务的投入回报率最高。

目标：

快速建立业务全局模型，解决真实问题，提高当前工作产出。

### **AI / LLM 线：主干深，支线浅**

目标：

扩展长期技术能力边界。

优先理解演化、机制、工程权衡，不无限追溯底层。

### **认知线：慢**

《系统之美》不要变成另一门需要“学完”的课程。

每学一个概念，就映射一个真实系统。

目标：

提升理解复杂问题的方式，而不是积累更多知识点。

---

## **6. 三条线不要彼此割裂**

理想结构：

**工作提供真实问题。**  
**《系统之美》提供分析框架。**  
**AI 学习扩展未来技术能力。**

不要建设三个互不相关的知识体系，而是建设一个统一的能力系统。

---

## **7. 最重要的学习纪律**

### **不无限下钻**

发现一个陌生概念，不代表现在就要学。

### **不追求完整基础**

基础永远补不完。

### **优先能力边界**

已经懂 Transformer，就优先继续理解 RoPE、GQA、MoE、训练与推理，而不是重新回到最底层。

### **项目优于纯阅读**

最终要通过：

Tokenizer → 小型 Transformer → 预训练 → SFT → LoRA → 推理 → KV Cache → 量化 → 服务化

把知识串起来。

### **输出优于继续输入**

“看懂”之后，要转成：

**能讲清楚、能实现、能解释为什么。**

---

# **时刻提醒自己**

**不要因为一个知识点还能继续往下追，就认为自己应该继续往下追。**

**学习的目标不是把知识树的根全部挖出来，而是在当前能力边界不断向外扩张。**

**先有地图，再补缺口；先解决问题，再学习支撑问题所需的知识。**

**工作做深，LLM 沿主线扩边界，认知学习慢慢积累。**

**停止无条件向底层追溯。**

如果只保留一句作为长期提醒，建议用：**“先有地图，在能力边界扩张；真正卡住时，再向下补基础。”**
