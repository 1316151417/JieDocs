一 · 机器学习「学习」在工程上由哪几个模块构成？

四个组件，一个闭环

DATA
① 数据
经验来源 (x, y) 样本集
例：(面积, 价格) × N
→
MODEL f(x;θ)
② 模型
规律的载体 + 可调参数
例：ŷ = w·x + b
→
LOSS L(ŷ,y)
③ 损失函数
当前参数有多差
例：误差平方
→
OPTIMIZER
④ 优化算法
往哪调、调多少
例：w ← w − η·∂L/∂w
↺
记住后面所有模型——包括最大的那个——都在这个闭环里，变的只是四个零件装的东西。
一 · 机器学习把闭环在最简单的任务上完整走一遍

线性回归全文唯一完整讲的公式

预测价格 ŷ = w × 面积 + b
  • 初始 w、b 随机：预测 100 平 = 100 万，真实 300 万
  • 知道参数不对，也知道差多少 → 汇总成损失
  • 优化算法朝损失变小的方向微调 → 循环几十轮，直线贴合数据
结论学到的是一组让误差变小的数字，不是人类可读的规律——适用于所有模型。
# 四个组件各占一行
import torch
model = torch.nn.Linear(1, 1)              # 模型
opt  = torch.optim.SGD(model.parameters(), lr=0.1) # 优化
for x, y in loader:                     # 数据
    loss = ((model(x) - y) ** 2).mean()    # 损失
    opt.zero_grad(); loss.backward(); opt.step()

实际运行：损失从 ~20 降到 <0.2，几十步收敛

一 · 机器学习训练分数好 = 用起来好吗？

泛化与数值稳定

过拟合

容量过大，把数据连同噪声一起背下来——训练好、新数据乱猜

欠拟合

模型太弱、训练不够，连训练数据都拟合不好

目标：泛化

新数据上依然准——评估只看新数据，不看训练分数

数据三份职责

训练集 → 调参数验证集 → 选方案测试集 → 估真实表现
数值稳定·一句参数初始值不合适，数值会在层间越滚越大，训练直接不稳——这个主题第三章 LayerNorm 来收。

第二章 · 深度学习
02
线性模型有两条过不去的缺口：现实规律大量是非线性的（包围、螺旋，直线分不开）；世界是层次化表达的（像素→边缘→纹理→部件→物体，一层压平既低效也表达不了）。
定 义通过多层非线性变换，自动从原始数据中逐层学习特征表示，并针对数据结构设计网络架构。
多层非线性→ MLP 逐层特征→ 特征学习 数据结构→ CNN（图像）/ RNN（序列）
二 · 深度学习非线性表达能力从哪来？

MLP：多层线性 + 非线性激活

hᵢ = σ(Wᵢ·hᵢ₋₁ + bᵢ)  # σ = 激活函数，如 ReLU

激活函数增加了什么

让不同输入区域走不同的加工路径。每个隐藏神经元是一条直线分割，后层把分割组合，围出任意形状的区域。

代数事实叠线性仍是线性：W₂(W₁x+b₁)+b₂ = W′x+b′——叠十层等于一层。

反向传播（一句）

前向算值，反向用链式法则把损失对每个参数的梯度逐层算回来，照旧梯度下降更新——框架自动完成。

边界

能表达 ≠ 学得出来。换初始化、换学习率可能训崩——这盆冷水第四章还会出现。

本质深度学习的分界线：「设计特征」也交给机器——前层学简单模式，后层组合成抽象概念。
二 · 深度学习非线性边界，眼见为实

圆与螺旋

无隐藏层：永远只能画直线（表达形式里不存在圆形边界）
加一层隐藏层 + 激活：直线组合出圆
「加隐藏层之前，圆不在它的世界里」
两股螺旋缠绕：更深、更宽才能盘进去
「能表达，不等于学得出来」

二 · 深度学习为什么网络曾经"深不动"？——贯穿全场的问题

梯度消失与梯度爆炸ResNet 的主场

机制

  • 反向传播 = 梯度逐层相乘回传
  • 每层乘 <1 的因子 → 层层衰减到接近零（消失）
  • 每层乘 >1 的因子 → 层层放大到失控（爆炸）
  • 网络越深乘的次数越多 → 「深」曾经训不动

三 · Transformer注意力一上来就 QKV 会晕——先看一个只有数字的例子

原始注意力：预测正弦值

做法

  • 手头一批采样点 (xᵢ, yᵢ)，要预测目标点的值
  • 加权平均：离目标近的样本权重大，远的权重小
  • 权重归一化后加权和 = 预测值

整个例子只有一个概念：加权平均，权重由相关性计算。没有矩阵，没有 QKV。

桥接这里的权重是用「距离规则」算出来的——如果权重不由规则定，而由模型根据内容自己学出来呢？

澄清Q 不是自然语言问题、K 不是主键、V 不是现成答案——都是训练出来的向量。

四 · LLM基座模型会续写，不会回答——「助手行为」怎么教？

SFT：换数据分布，不换目标

基座模型的行为

输入：请用三句话解释缓存击穿。
输出：续写出另一个相似的问题 / 当网页标题往下编

训练数据里「问题后面还是问题」——它学的是什么文本可能接着出现，没人教它「看到请求要像助手回答」。

SFT 的做法

用「指令 + 人写的理想回答」继续训练。底层没变——仍是预测下一个 Token，变的只是数据分布：全网文本 → 高质量问答。

高频追问速查

Attention 公式？
softmax(QKᵀ/√d)·V——寻找、匹配、取回
为什么需要位置编码？
注意力只看内容，「狗咬人 ≠ 人咬狗」；RoPE 感知相对位置
梯度消失/爆炸怎么回事？
梯度逐层相乘回传：连乘 <1 衰减、>1 放大；残差连接给梯度留直交通路
温度调低会更准吗？
只会更稳；top-1 是错的，低温只会稳定地错
怎么减少幻觉？
给上下文 / RAG / 接工具 / 要引用 / 加校验
微调、RAG、提示词怎么选？
改参塑行为 / 检索进上下文 / 临时引导；灌知识别用微调，可组合
LoRA 为什么省？
冻结原参数只训低秩增量，训练量降几个数量级
「涌现」是公认的吗？
能力随规模出现跨度是观察事实；是否为度量假象有学术争论——不当绝对结论用
参数越大越强吗？
不是；固定算力下参数与数据要配平；13B 对齐后偏好可胜 175B
上下文越长记得越多吗？
「放得进」≠「用得好」：注意力计算量平方涨，长文中段利用不可靠
