## 〇、现象与主线

语音识别、图像识别、机器翻译——十年前做不好，现在随手可用。再到今天每天在用的：问答、写代码、总结文档、分析数据。

这些能力从哪来？整场沿一条主线走：**机器是怎么一步步拿走人做的东西的——拿走到哪一步时，「智能」出现了。**

| 阶段 | 机器拿走了什么 |
|---|---|
| 传统程序 | 执行（人写规则，机器照办） |
| 机器学习 | 找参数 |
| 深度学习 | 学特征 |
| Transformer | 建上下文 |
| LLM | 统一任务 + 能力涌现 |
| Agent（后续专场） | 行动 |

每一步的驱动力相同：**上一阶段交出一项工作后，剩下的瓶颈成为下一阶段的问题。**

边界：讲原理与判断方法，不讲工具技巧、模型新闻、数学推导；完整讲的公式只有一条。

## 一、机器学习

### 问题

传统程序：规则 + 输入 → 输出。规则写得清的问题（订单计价：金额、优惠、税费、运费），传统程序就是最好的方案，无可替代。

但有一大类任务，人做得出来，规则写不出来：判断垃圾邮件、识别图片里的猫、预测客户流失。写出几百条规则，照样冲突、漏网、过时。人做得出来，说不清楚自己是怎么做的。

### 定义

**让机器从数据或经验中学习可泛化的规律，使其在特定任务上的表现不断改善。**

这个定义里的四个关键词，正好就是本章的四块内容：

- 「数据」→ 组件① 数据
- 「规律」→ 组件② 模型（规律的载体，参数所在）
- 「学习」→ 组件③ 损失函数 + ④ 优化算法
- 「泛化」→ 第 4 节

### 1.1 四个组件

1. **数据**：经验来源，如（面积, 价格）样本集
2. **模型**：承载规律的结构，含待调参数，如 ŷ = w·x + b
3. **损失函数**：衡量当前参数多差，如误差平方
4. **优化算法**：沿损失变小的方向调参数

循环：预测 → 算误差 → 调参数 → 再预测。后面所有模型——包括最大的那个——都在这个闭环里，变的只是四个零件装的东西。

### 1.2 线性回归

全文唯一完整讲的公式：预测价格 ŷ = w × 面积 + b。

初始 w、b 随机。预测 100 平 = 100 万，真实 300 万——知道参数不对，也知道差多少。汇总误差得损失；优化算法朝损失变小的方向微调；循环几十轮，直线贴合数据。

**机器学到的是一组让误差变小的数字，不是人类可读的规律。**适用于所有模型，包括最大的那个。

可视化：梯度下降演示——散点、拟合直线、每步误差线、损失曲线同步变化，支持播放 / 单步 / 重置。看的过程只有一件事发生：直线在数据里「下坡」，损失单调下降。

```python
import torch
model = torch.nn.Linear(1, 1)                        # 模型：ŷ = w·x + b
opt   = torch.optim.SGD(model.parameters(), lr=0.1)  # 优化器
for x, y in loader:                                  # 数据
    loss = ((model(x) - y) ** 2).mean()              # 损失
    opt.zero_grad(); loss.backward(); opt.step()     # 反向传播 + 更新
```

四个组件各占一行，实际运行损失从 ~20 降到 <0.2，几十步收敛。

### 1.3 Softmax 回归

分类任务：先用线性算出各类别分数（logits），再经 Softmax 归一化成概率分布——猫 0.78、狗 0.21、鸟 0.01，总和为 1。

分类的损失用**交叉熵**：L = −log p(真实类别)。直觉：只罚「真实类别的概率不够高」——模型给真实类的概率越接近 1，损失越接近 0；概率越接近 0，损失趋向无穷大。训练就是不断把真实类别的概率推高。

记住这个损失。第四章预训练用的就是交叉熵，只是类别换成了全词表。

### 1.4 泛化与数值稳定

目标是新数据上依然准，不是训练数据上误差低。训练误差低有两种可能：学到可迁移的规律；或容量过大，把数据连同噪声背下来（**过拟合**）。模型太弱、训练不够，连训练数据都拟合不好（**欠拟合**）。

纪律：训练集调参数、验证集选方案、测试集估真实表现；评估只看新数据。

数值稳定一句话：参数初始值不合适，数值会在层间越滚越大，训练直接不稳——这个主题第三章 LayerNorm 来收。

### 交接

例子里「面积」是人挑的特征。图片里「猫」的特征是什么？边缘？胡须？比例？——没人写得全。人工特征成了新瓶颈。

## 二、深度学习

### 问题

线性模型有两条过不去的缺口：

1. **现实规律大量是非线性的**：一类数据包围另一类、两股螺旋缠绕，直线分不开。多叠几层线性也不行——W₂(W₁x+b₁)+b₂ = W′x+b′，叠十层等于一层。
2. **世界是层次化表达的**：像素→边缘→纹理→部件→物体。线性回归把所有细节压在一层加权求和上，不符合层次结构的高效组织。

### 定义

**通过多层非线性变换，自动从原始数据中逐层学习特征表示，并针对数据结构设计网络架构。**

- 「多层非线性变换」→ MLP
- 「逐层学习特征表示」→ 特征学习
- 「针对数据结构设计架构」→ CNN（图像）/ RNN（序列）

### 2.1 MLP

配方：多个线性层，层间夹非线性激活（如 ReLU：负数归零、正数保留）。有了非线性折叠，各层无法合并成一次线性，才能表示弯曲的、分段的边界。

激活函数的作用：**让不同输入区域走不同的加工路径。**每个隐藏神经元是一条直线分割，后层把分割组合，围出任意形状的区域。

可视化：圆 / 螺旋决策边界。蓝点居中、橙点在外——无隐藏层时无论训练多久只能画直线，表达形式里不存在圆形边界；加一层隐藏层 + 激活，直线组合出圆。**加隐藏层之前，圆不在它的世界里；加了之后，圆成了可组合的结果。**螺旋要更深更宽才能盘进去。

反向传播一句话：前向算值，反向用链式法则把损失对每个参数的梯度逐层算回来，照旧梯度下降更新，框架自动完成。

边界：**能表达 ≠ 学得出来。**换初始化、换学习率可能训崩。

### 2.2 CNN：三个代表网络

CNN 利用图像的两个先验做结构优化：局部相关性（模式由相邻像素构成→局部连接）、平移不变性（左上和右下的同一种边缘是同一模式→参数共享，同一组卷积核权重扫全图），层层堆叠自然形成层次特征。

- **LeNet（1998）**——开山：卷积 + 池化的原型，手写数字识别
- **AlexNet（2012）**——引爆深度学习：ImageNet 大幅领先 + GPU 训练，深度学习时代由此开始
- **ResNet（2015）**——把网络做深。这里正式讲一个贯穿全场的问题：

**梯度消失与梯度爆炸。**反向传播是梯度逐层相乘回传的：每层乘一个小于 1 的因子，梯度层层衰减到接近零——前面的层学不到东西（梯度消失）；每层乘一个大于 1 的因子，梯度层层放大到失控——训练直接发散（梯度爆炸）。网络越深，乘的次数越多，问题越重，所以「深」曾经训不动。

ResNet 的解法：残差连接。不再让每层学完整映射，只学「增量」：y = F(x) + x。加法给梯度留了一条直通通路，不再被层层乘法衰减——网络从此可以堆上百层。这个机制第三章会原样出现在 Transformer 里。

### 2.3 RNN

序列数据：当前词的含义可能取决于前文。RNN 维护一份随阅读进度更新的「摘要」状态：读到「我」得到 h₁，「喜欢」+ h₁ → h₂，以此类推；同一组参数逐步复用，任意长度可处理。

三个天花板：

1. **长距离路径 O(n)**：第 1 个词影响第 100 个词，要穿过中间每次状态更新——这就是上面讲的梯度消失在序列上的表现，越远损耗越大
2. **串行**：算第 100 个状态必须等第 99 个——大模型最需要的是大规模并行训练
3. **固定瓶颈**：十个词和一万个词都压进同一个固定长度向量

LSTM 缓解一和三，「按顺序逐步计算」没变。

## 三、Transformer

### 问题

承接 RNN 三问：远距离、并行、瓶颈。

### 定义

**完全以注意力取代循环与卷积的序列架构——每个位置按内容与全序列直接建立信息连接，辅以位置编码、残差与归一化，使注意力可以深层堆叠。**

- 「完全以注意力取代循环」→ 注意力机制
- 「按内容直接连接」→ 权重由内容学出：路径长度 1、可并行
- 「位置编码」→ 顺序信息
- 「残差与归一化」→ 深层可训
- 「序列架构」→ 文本进出模型

### 3.1 原始注意力：先看一个数值例子

预测正弦函数在某一点的值。手头有一批采样点 (xᵢ, yᵢ)，最简单的办法是加权平均：离目标点近的样本权重大，远的权重小，权重归一化后加权和就是预测值。

这个例子里只有一个概念：**加权平均，权重由相关性计算**（相关性 = 距离）。没有矩阵，没有 QKV。

关键一问：这里的权重是我用「距离规则」算出来的——**如果权重不由规则定，而由模型根据内容自己学出来呢？**

### 3.2 文本注意力：Q、K、V

「银行旁边有一条河」→ 河岸；「我去银行取了钱」→ 金融机构。查字典区分不了：**词的含义不在词本身，在它和上下文的关系里。**注意力热力图上能看到：第一句「银行」的权重大量落在「河」，第二句大量落在「取了钱」。

于是让「银行」这个位置根据当前内容，自己决定从哪些词取多少信息。工程上用三个可学习的投影，职责分开：

- **Q（Query）**：我在找什么信息
- **K（Key）**：我能提供什么匹配线索
- **V（Value）**：匹配之后真正递过来的内容

每个位置拿自己的 Q 和所有位置的 K 算匹配分，归一化成权重，按权重汇总 V。公式认脸：Attention(Q,K,V) = softmax(QKᵀ/√d)·V。

三个天花板同时解决：任意两词路径长度 1、所有位置并行、不压缩历史。多头一句话：多组 QKV 并行，各自学不同的关系视角——但头不对应固定的人类概念。

澄清：Q 不是自然语言问题，K 不是主键，V 不是现成答案——都是训练出来的向量。

### 3.3 位置编码（带过）

注意力只按内容匹配，「狗咬人」和「人咬狗」词集合相同、含义相反——所以要把位置信息加进表示。现代主流是 RoPE：让匹配天然感知相对位置。

### 3.4 残差连接（带过）

和 ResNet 同一个机制搬进 Transformer：每个子层只学增量，y = F(x) + x，梯度有直通通路。

### 3.5 LayerNorm（带过）

回收第一章「数值稳定」：把每层的数值拉回稳定区间（均值方差受控），深层堆叠训得动。

### 3.6 分词与向量化（带过）

文本 → Token（离散单元，不总等于词）→ 整数 ID → Embedding 查表得向量。同一个「银行」初始向量相同，含义分化发生在后面几十层注意力的加工里。

### 3.7 组装 Decoder Block

注意力（跨位置通信）+ FFN（位置内加工，容量主要在这）+ 残差 + Norm，堆几十上百层，就是 GPT、LLaMA 的骨架。分工记法：**注意力管通信，FFN 管加工。**

### 交接

此刻参数全是随机数，一个字都不认识。架构 ≠ 能力——能力从哪来？

## 四、LLM

### 问题链

1. 监督学习需要标注，互联网有的是无标注文本——怎么用？
2. NLP 任务千千万（翻译、摘要、问答、分类），每个任务训一个模型吗？
3. 模型不断变大，会发生什么？

### 定义

**在互联网规模文本上，以「预测下一个 Token」为统一目标做自监督预训练，随参数、数据与算力扩大涌现通用语言能力，再经监督微调与偏好对齐塑造助手行为。**

### 4.1 预训练

监督信号哪来？文本自己就是答案。一句语料「机器学习可以从数据中学习参数」左移一位，得到所有位置的练习题：「机器 → 学习」「机器 学习 → 可以」……零人工标注。这就是自监督。

训练「预测下一个词」不能偷看答案——**因果掩码**：第 t 个位置只能看第 1 到第 t 个词，未来位置分数屏蔽。一石二鸟：

- 训练时：整段已知，所有位置一次前向并行练习——防偷看，不牺牲并行
- 生成时：本来就只有过去——天然从左到右续写

损失就是第一章的交叉熵，类别换成全词表。

【实验占位：llama.c 预训练实录，内容待设计】

### 4.2 GPT 三步：量变引起质变

三步各有质变点，不只是变大：

- **GPT-1**：确立「预训练 + 下游微调」范式——预训练的能力可以迁移
- **GPT-2**：去掉微调，多任务统一成「续写文本」——任务接口开始统一
- **GPT-3**：任务说明直接写在上下文里，不训练就适配新任务（上下文学习）

合起来：从「每个任务训一个模型」变成「一个模型，任务写在提示词里」。规模继续扩大，能力不是线性改善而是出现跨度——量变引起质变，这叫**涌现**。

### 4.3 SFT：会续写 ≠ 会当助手

基座模型的行为：输入「请用三句话解释缓存击穿」，它续写出另一个相似问题，或把这句当网页标题往下编。训练数据里「问题后面还是问题」——它学的是「什么文本可能接着出现」，没人教它「看到请求要像助手回答」。

SFT：用「指令 + 人写的理想回答」继续训练。底层没变，仍是预测下一个 Token，变的只是数据分布——从全网文本换成高质量问答。行为随分布改变：识别任务、遵守格式、控制篇幅、助手身份。**SFT 教行为，不注知识。**

【实验占位：基座 vs 微调对比，内容待设计】

### 4.4 偏好对齐（一条线）

SFT 之后的问题：几个回答都「对」但质量不同——准但啰嗦、简洁但漏边界、自信但没验证。「哪种更好」写不成规则，改成人做选择题：同一问题出四个回答，人排序。比较比写答案容易十倍，可规模化。

几十万条排序训一个奖励模型（替人打分），再用强化学习让高分回答更常出现——RLHF；DPO 简化成直接从偏好对学习。实证：130 亿参数的 InstructGPT，人类偏好评分超过 1750 亿参数的原始 GPT-3——能力大小和行为是否合意图是两个独立维度。

边界：奖励模型只是偏好的近似；人更偏好 ≠ 更真实。**对齐管倾向，不管真值。**

### 4.5 LoRA：低成本适配

SFT / 偏好对齐都要更新参数，全量更新成本高。LoRA：冻结原参数，只额外训练一小块低秩增量矩阵，训练量降几个数量级。

三段训练的成本特性：

| | 数据量 | 耗时 | 成本 |
|---|---|---|---|
| 预训练 | 最大 | 最长 | 高 |
| SFT | 中等 | 中等 | 中 |
| LoRA | 小 | 短 | 低（消费级显卡可做） |

【实验占位：私有数据适配对比，内容待设计】

实验要支撑的结论：**预训练给能力，后训练给行为——两个独立的旋钮。**

### 4.6 训练 vs 推理（极简）

| | 训练 | 推理 |
|---|---|---|
| 正确答案 | 有 | 没有 |
| 算损失、调参数 | 是 | 否 |
| 产出 | 一组参数 | 下一个 Token |

使用阶段参数冻结。生成循环三行伪代码：

```
while 没结束:
    算出全词表每个 Token 的概率
    按概率挑一个，追加到上下文末尾，再来
```

整段回答是一次一个 Token 循环出来的。采样一句话：温度等参数管选词风格，不注入知识——top-1 是错的，低温只会更稳定地错。

### 4.7 延伸能力（一句话）

Tool call、思维链，本质都是后训练带来的行为延伸——机制的展开留待后续 Agent 专场。

## 收尾

主线复现，每步一句：

1. **机器学习**：预测 → 误差 → 调整；学到的是数字，不是规则
2. **深度学习**：非线性 + 多层，特征自己学
3. **Transformer**：按内容直达上下文，残差与 Norm 让它可深可训
4. **LLM**：预测下一个 Token 的自监督预训练，规模之后能力涌现
5. **后训练**：SFT 教形式、偏好教倾向——能力和行为是两回事
6. Agent（虚线）：模型决定、系统执行——后续专场

收尾句：**今天的大模型，底层仍然在预测下一个 Token。让人惊讶的不是这个目标多简单，而是当结构、数据和规模足够大之后，为了持续做好这件小事，机器长出了我们称之为「智能」的行为。**

后续两场预告：工程实战（PyTorch / llama.c / SFT-LoRA 全过程）；Agent（Tool Call / ReAct / LangChain / LangGraph）。
