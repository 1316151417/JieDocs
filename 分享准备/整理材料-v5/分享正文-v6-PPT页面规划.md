# **一、机器学习**

## **P3｜机器学习：问题**

传统程序：

输入 → 人工规则 → 输出

问题：

- 一大类任务人可以判断
- 但很难写出完整规则

例如：

- 垃圾邮件判断
- 猫狗识别
- 用户流失预测

核心矛盾：

**规则写不出来怎么办？**

---

## **P4｜机器学习：定义与定义拆解**

定义：

**机器学习：让机器从数据或经验中学习可泛化的规律，使其在特定任务上的表现不断改善。**

定义拆解：

- 数据 / 经验
- 规律
- 学习
- 泛化

对应后面的机器学习核心机制。

---

## **P5｜机器学习的四个组件**

机器学习闭环：

数据 → 模型 → 损失函数 → 优化算法 → 再次预测

四个核心组件：

1. 数据
2. 模型
3. 损失函数
4. 优化算法

核心：

学习就是不断调整参数，让损失下降。

---

## **P6｜线性回归：最小实例**

公式：

ŷ = w·x + b

解释：

- 输入 x
- 参数 w、b
- 输出 ŷ

重点：

参数不是人写出来的，而是模型从数据中学出来的。

### **可视化**

梯度下降演示：

- 散点数据
- 初始拟合线
- 参数不断更新
- 拟合线逐渐逼近数据
- Loss 持续下降

可配 PyTorch 最小代码。

---

## **P7｜Softmax 与交叉熵**

从回归进入分类。

流程：

线性分数 → Softmax → 概率分布

Softmax：

把任意分数转换为总和为 1 的概率分布。

交叉熵：

真实类别概率越低，损失越大。

例如：

- 真实类别 = 猫
- P(猫) = 0.9 → Loss 小
- P(猫) = 0.1 → Loss 大

伏笔：

后面的 LLM 预测 Token，本质仍然是一个巨大的分类问题。

---

## **P8｜泛化与数值稳定**

### **泛化**

- 训练集
- 验证集
- 测试集

两个典型问题：

- 欠拟合
- 过拟合

### **数值稳定**

模型越来越深后：

- 数值可能不断放大 / 缩小
- 梯度也可能不稳定

参数初始化一句话带过。

伏笔：

Transformer 的 LayerNorm 再回收这个问题。

---

## **P9｜机器学习的局限**

机器学习已经拿走：

**参数选择**

但仍然存在问题：

**特征还需要人设计。**

例如图片识别：

- 耳朵？
- 眼睛？
- 毛发？
- 轮廓？

问题：

参数可以学习，特征为什么不能也让机器自己学习？

→ 深度学习

# **二、深度学习**

## **P10｜深度学习：问题**

两个核心问题：

1. **世界大量规律是非线性的**
2. **人工设计特征越来越困难**

传统线性模型无法解决。

核心问题：

能不能让机器连特征也自己学习？

---

## **P11｜深度学习：定义与定义拆解**

定义：

**深度学习：通过多层非线性变换，自动从原始数据中逐层学习特征表示的机器学习方法。**

定义拆解：

- 多层
- 非线性
- 自动学习
- 特征表示

---

## **P12｜MLP：非线性与层次特征**

### **1. 为什么需要非线性**

线性层继续叠加线性层：

最终仍然只是线性变换。

因此需要：

激活函数 / 非线性

核心：

**没有非线性的深度，只是假深度。**

### **2. 多层意味着什么**

逐层学习特征：

低层 → 简单特征  
高层 → 组合特征

从人工特征设计转向：

自动学习特征表示。

---

## **P13｜MLP：如何学习**

问题：

这么多层参数怎么训练？

机制：

前向传播 + 反向传播 + 梯度下降

反向传播：

- 前向计算结果
- 反向计算梯度
- 链式法则
- 自动求导

可配：

- 非线性决策边界可视化
- 圆 / 螺旋分类

核心：

能表达复杂规律，还必须能够把参数真正学出来。

---

## **P14｜MLP 的局限**

MLP 足够通用，但效率很低。

根本原因：

**没有利用数据自身的结构。**

### **图像**

- 参数量巨大
- 相同特征在不同位置重复学习

### **序列**

- 没有天然顺序
- 没有记忆

结论：

**效率来自把数据结构写进网络。**

---

## **P15｜CNN：把图像结构写进网络**

图像的结构先验：

1. 局部性
2. 平移不变性

对应 CNN：

- 局部连接
- 参数共享

效果：

- 参数量大幅减少
- 相同模式可以复用

历史路标：

LeNet → AlexNet

一句话：

AlexNet + ImageNet + GPU 引爆现代深度学习。

---

## **P16｜ResNet：深层网络如何训练**

问题：

网络越来越深以后，优化越来越困难。

包括：

- 梯度传播困难
- degradation problem
- 深层网络训练误差反而可能更高

ResNet：

H(x) = F(x) + x

核心机制：

**恒等捷径 / 残差连接**

作用：

- 信息可以直接传播
- 梯度可以走捷径
- 深层网络更容易优化

伏笔：

Transformer 后面会继续使用同样的残差结构。

---

## **P17｜RNN：序列与记忆**

CNN 解决图像结构。

但文本需要：

顺序 + 上下文

RNN：

按顺序处理输入，并通过隐藏状态不断携带历史信息。

机制：

h₁ → h₂ → h₃ → …

核心：

循环更新隐藏状态。

局限：

- 长距离信息传递困难
- 串行计算
- 固定维度状态形成瓶颈

→ Transformer

# **三、Transformer**

## **P18｜Transformer：问题**

承接 RNN 的三个问题：

1. 远距离信息路径太长
2. 必须串行计算
3. 历史信息被压缩进隐藏状态

核心问题：

一个 Token 能不能直接找到自己真正需要的 Token？

---

## **P19｜Transformer：定义与定义拆解**

定义：

**Transformer：一种完全基于注意力机制、摒弃循环与卷积结构进行序列建模的神经网络架构。**

定义拆解：

- 注意力机制
- 摒弃循环
- 序列建模
- 可堆叠的深层架构

对应：

- Attention
- 位置编码
- FFN
- 残差
- LayerNorm

---

## **P20｜Attention：注意力直觉**

先不讲 QKV。

核心概念：

**加权平均。**

不同信息：

- 相关性高 → 权重大
- 相关性低 → 权重小

输出：

对所有信息按照相关性进行加权汇总。

桥接：

如果权重不再由人规定，而是让模型自己根据内容计算呢？

---

## **P21｜QKV：文本注意力**

Q / K / V：

- Q：我在找什么？
- K：我有什么线索？
- V：我真正提供什么信息？

流程：

1. Q 与所有 K 计算相关性
2. 得到 Attention Score
3. Softmax 转成权重
4. 根据权重聚合 V

公式认脸：

softmax(QKᵀ / √d) · V

需要讲清：

- Q / K / V 各自职责
- 完整信息流
- Attention 公式
- 多头注意力

可配：

「银行」两句话的 Attention 热力图

---

## **P22｜位置编码**

问题：

Attention 本身不知道顺序。

例如：

狗咬人 ≠ 人咬狗

因此需要：

Position Encoding

现代 LLM：

RoPE

一句话：

让 Attention 在匹配内容时同时感知位置信息。

---

## **P23｜FFN**

问题：

Attention 完成了 Token 之间的信息交换，但信息拿回来以后谁来加工？

FFN：

对每个 Token 独立执行非线性前馈网络。

记忆：

**Attention 管通信，FFN 管加工。**

---

## **P24｜残差 + LayerNorm**

模型需要堆很多层。

问题：

深层网络如何保持可训练？

### **残差**

回扣 ResNet：

给信息和梯度提供捷径。

### **LayerNorm**

回扣第一章数值稳定：

让中间表示保持相对稳定的尺度。

---

## **P25｜组装 Transformer Block**

将前面的组件组装起来：

输入  
→ Self-Attention  
→ 残差 / LayerNorm  
→ FFN  
→ 残差 / LayerNorm  
→ 重复 N 层

形成 Transformer Block。

核心分工：

Attention 管通信，FFN 管加工。

---

## **P26｜原始 Transformer 论文与架构**

论文：

Attention Is All You Need

原始结构：

Encoder + Decoder

展示原论文架构图。

说明：

- 原始 Transformer 为 Encoder–Decoder
- 现代主流 LLM 主要采用 Decoder-only
- GPT / LLaMA 属于这一主线

不展开 Decoder-only 为什么成为主流。

---

## **P27｜Transformer 的局限**

此时：

- 架构已经有了
- 参数量可以很大
- 网络可以很深

但：

**架构 ≠ 能力。**

刚初始化的 Transformer：

参数仍然全部是随机数。

它：

- 不认识文字
- 不懂知识
- 不会写代码

关键问题：

能力从哪里来？

→ LLM

# **四、LLM**

## **P28｜LLM：三个问题**

### **问题 1**

互联网有海量文本，但没有人工标注。

数据怎么利用？

### **问题 2**

NLP 有大量不同任务：

- 翻译
- 问答
- 摘要
- 分类
- 编程

每个任务都单独训练一个模型吗？

### **问题 3**

模型、数据、计算不断扩大以后：

会发生什么？

---

## **P29｜LLM：定义与定义拆解**

定义：

**大型语言模型：在大规模文本上，以预测下一个 Token 为核心训练目标进行自监督预训练得到的语言模型；通常再经过监督微调和偏好对齐，使其适配具体任务与交互。**

定义拆解：

- 文本
- Token
- 预测下一个 Token
- 自监督预训练
- 大规模
- SFT
- 偏好对齐

---

## **P30｜文本如何进入模型**

输入流程：

文本  
→ Token  
→ Token ID  
→ Embedding  
→ 向量

输出流程：

隐藏向量  
→ 输出层  
→ 全词表 Logits  
→ Softmax  
→ 下一个 Token 概率

重点：

LLM 最终仍然是在进行一个超大规模分类。

---

## **P31｜预训练**

核心机制：

### **1. 预测下一个 Token**

文本本身就是训练数据。

### **2. 一次训练多个位置**

整段文本同时参与训练。

### **3. 因果掩码**

保证：

当前 Token 看不到未来答案。

同时：

训练仍然可以并行。

### **4. 损失函数**

回收：

全词表交叉熵。

结论：

文本自己给自己出题，不需要人工标注。

## **P36｜通用能力为什么会出现**

关键问题：

为什么预测下一个 Token 最后会产生这么多能力？

因为语言本身承载：

- 世界知识
- 任务描述
- 推理过程
- 对话
- 代码
- 人类行为痕迹

模型为了预测好下一个 Token：

必须学习这些文本背后的规律。

随着：

- 数据增加
- 参数增加
- 计算增加

模型学习的对象逐渐从：

某一个具体任务

变成：

**承载大量任务的语言分布。**

这也是「智能涌现」的关键逻辑桥。

## **P37｜SFT：从续写模型到助手**

问题：

会续写 ≠ 会当助手。

用户需要：

SFT：

使用 Instruction → Response 数据继续监督训练。

变化：

数据分布改变，Next Token Prediction 的训练目标没有根本改变。

核心：

**从续写 → 助手。**

## **P40｜LoRA：机制**

问题：

全参数微调成本太高。

LoRA：

冻结原模型参数，只训练少量低秩增量参数。

核心：

W → W + ΔW

特点：

- 更新参数少
- 显存需求低
- 训练快
- 容易保存多个适配版本

定位：

LoRA 是低成本参数高效微调方法。

## **P42｜训练 vs 推理**

对比：

||**训练**|**推理**|
|---|---|---|
|有正确答案|有|没有|
|计算 Loss|是|否|
|反向传播|是|否|
|更新参数|是|否|
|逐 Token 生成|否|是|

推理过程：

Prompt  
→ 预测 Token  
→ 拼回输入  
→ 再预测  
→ 循环

回收：

训练可以并行，生成必须逐 Token 进行。

## **P43｜采样：Temperature / Top-K / Top-P**

模型输出的是：

下一个 Token 的概率分布。

如何从概率分布中选 Token：

### **Temperature**

控制概率分布的平滑程度：

- 低 → 更确定
- 高 → 更多样

### **Top-K**

只在概率最高的 K 个 Token 中采样。

### **Top-P**

选择累计概率达到 P 的 Token 集合后采样。

一句话：

采样控制的是生成的随机程度与风格，不负责判断答案真假。

## **P45｜总结：智能的涌现**

整场最终结论：

今天的大模型，底层仍然只是在预测下一个 Token。

真正发生变化的是：

人不断把原本需要显式设计的规则、参数、特征、上下文关系，以及部分任务表达，交给数据、模型与优化过程。

最终：

**当结构足够通用、数据足够丰富、规模足够大之后，为了做好“预测下一个 Token”这件简单的事，模型表现出了越来越多我们称之为「智能」的能力。**
