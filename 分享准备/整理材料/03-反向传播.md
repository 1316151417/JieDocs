# **反向传播**

## **1. 定义**

**反向传播（Backpropagation）**：  
沿计算图从损失函数向前逆序计算梯度，并复用中间结果，高效得到损失对所有可训练参数梯度的算法。

---

## **2. 解决的问题**

多层神经网络只有最终输出有明确的监督信号，隐藏层没有自己的标准答案。

反向传播解决：

**最终误差应该如何分配到各层、各参数。**

也就是让每个参数都知道：

自己对最终 Loss 产生了多大影响。

这就是**信用分配问题**。

---

## **3. 在训练流程中的位置**

```text
前向传播
↓
得到预测结果
↓
计算 Loss
↓
反向传播
↓
得到所有参数梯度
↓
优化器更新参数
```

核心区别：

- **前向传播**：计算结果
- **反向传播**：计算梯度
- **优化器**：根据梯度修改参数

反向传播本身**不更新参数**。

---

## **4. 数学基础：链式法则**

如果一个变量经过多层计算最终影响 Loss：

```text
x → h1 → h2 → Loss
```

那么 x 对 Loss 的影响，可以拆成每一段局部影响的组合。

核心规则：

**沿同一条计算路径，局部梯度连续相乘。**

因此每一层不需要理解整个网络，只需要知道：

1. 后面传回来的梯度
2. 自己这一层的局部导数

然后就能继续向前传播梯度。

---

## **5. 每一层反向传播做什么**

假设：

```text
输入
↓
当前层
↓
输出
↓
后续网络
↓
Loss
```

当前层收到：

Loss 对当前层输出的梯度

然后结合自己的局部导数，计算两类结果：

```text
上游梯度
   ↓
当前层局部求导
   ↓
┌──────────────┐
参数梯度      输入梯度
   ↓             ↓
更新参数      继续向前传播
```

所以反向传播本质上是：

**梯度在计算图中逐层向前传递。**

---

## **6. 计算图中的两个核心规则**

### **串联：梯度相乘**

```text
x → A → B → Loss
```

x 对 Loss 的影响，要经过 A、B 两段。

因此：

**同一路径上的梯度相乘。**

---

### **分支：梯度相加**

```text
      → A →
x →         → Loss
      → B →
```

x 通过两条路径影响 Loss。

因此：

**不同路径产生的梯度贡献相加。**

可以记成：

```text
路径内部：乘
多条路径：加
```

---

## **7. 残差连接**

残差连接：

```text
        → F(x) →
x →              + → y
        ─────────→
```

x 有两条路径影响输出：

1. 经过 F(x)
2. 直接通过 shortcut

所以反向传播时，两条路径的梯度会相加。

其中 shortcut 是恒等映射，它提供了一条直接的梯度传播路径。

这也是残差连接有利于训练深层网络的重要原因之一：

**梯度不必全部穿过复杂的多层变换，可以沿 shortcut 直接传播。**

---

## **8. 不可导点**

神经网络并不要求所有函数在所有位置都严格可导。

例如 ReLU 在 0 点不可导。

工程上通常做法是：

**人为给这个点规定一个确定的反向梯度。**

例如常见实现取 0。

因此实际要求不是：

每个算子必须处处可导。

而是：

**每个训练算子必须有明确的反向传播规则。**

---

## **9. 反向传播为什么高效**

反向传播的高效不只是因为使用了链式法则。

真正核心是：

**公共的中间计算只做一次，然后反复复用。**

主要有两类复用。

### **复用前向结果**

前向传播已经计算出的：

- 输入
- 中间激活值
- 各层输出

反向求局部梯度时直接使用，不重新计算。

---

### **复用中间梯度**

这是更核心的部分。

例如：

```text
w1 → h1 → h2 → Loss
w2 ↗
w3 ↗
```

多个参数共享：

```text
h1 → h2 → Loss
```

反向传播会先算一次：

Loss 对 h1 的梯度

然后 w1、w2、w3 都直接复用这个结果。

而不是每个参数都重新从 Loss 开始求一遍。

所以可以把反向传播理解为：

**链式法则 + 逆序遍历 + 动态规划式的中间结果复用。**

---

## **10. 为什么要从 Loss 向前算**

神经网络通常是：

```text
大量参数
   ↓
多层计算
   ↓
一个 Loss
```

如果从每个参数分别向 Loss 求导，会重复经过大量相同的后续路径。

从 Loss 反向计算，则公共路径只算一次：

```text
Loss
↓
中间梯度
↓
中间梯度
↓
分发给大量参数
```

因此反向模式特别适合：

**大量输入参数 → 一个标量 Loss**

这正是神经网络训练的典型结构。

---

## **11. 与自动求导的关系**

**自动求导**：根据程序实际形成的计算图，自动计算导数。

反向传播可以理解为：

**反向模式自动求导在神经网络训练中的应用。**

PyTorch 的：

```python
loss.backward()
```

本质就是：

```text
从 Loss 开始
↓
逆序遍历计算图
↓
调用每个算子的反向规则
↓
复用并累积梯度
↓
得到所有参数的 grad
```

---

# **核心骨架**

```text
神经网络训练
│
├─ 前向传播：算预测结果
│
├─ Loss：衡量错误
│
├─ 反向传播：算每个参数对错误的影响
│    │
│    ├─ 数学基础：链式法则
│    ├─ 路径内：梯度相乘
│    ├─ 路径间：梯度相加
│    └─ 高效来源：中间结果复用
│
└─ 优化器：根据梯度更新参数
```

最终可以压缩成一句话：

**反向传播就是从最终 Loss 出发，沿计算图逆序传播梯度，通过链式法则和中间结果复用，高效算出所有参数应该如何影响 Loss。**
