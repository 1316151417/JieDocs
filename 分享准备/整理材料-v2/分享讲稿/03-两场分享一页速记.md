# 两场分享一页速记

这份材料可以在第二场结束后发给听众，也可以作为讲师开场前的快速复习。

---

## 1. 机器学习是什么

**普通程序由人直接编写规则；机器学习让模型从数据中调整参数，形成难以人工枚举的规律。**

统一训练闭环：

~~~text
训练数据
   ↓
模型作出预测
   ↓
与目标比较
   ↓
得到损失
   ↓
调整参数
   ↓
重复
~~~

五个核心概念：

- 数据：模型学习所依据的经验。
- 模型：把输入转换为输出的可调整结构。
- 参数：训练过程中被改变的内部数值。
- 损失：衡量当前预测错了多少。
- 训练：根据错误反复调整参数。

两个核心区别：

- 训练是改变模型，推理是使用模型。
- 过拟合是记住训练样本，泛化是能够处理未见数据。

---

## 2. LLM 是什么

**LLM 是在大规模文本上训练、根据已有上下文预测下一个 Token 的概率模型。**

对应关系：

|机器学习概念|LLM 中的内容|
|---|---|
|数据|大规模文本与代码|
|输入|前面的 Token|
|目标|真实的下一个 Token|
|模型|Transformer|
|损失|下一个 Token 预测错误|
|训练结果|Base Model|

---

## 3. Token 与 Transformer

文本进入模型：

~~~text
原始文本
   ↓
Token
   ↓
Token ID
   ↓
可学习的内部表示
   ↓
Transformer
~~~

- Token 是模型处理文本的离散基本单位，不一定等于一个字或一个词。
- Transformer 让每个 Token 根据当前需要，从上下文中的其他 Token 获取相关信息。
- 同一个 Token 在不同上下文中可以形成不同的内部表示。

---

## 4. 预训练与后训练

### 预训练

~~~text
海量文本
   ↓
预测下一个 Token
   ↓
与原文真实 Token 比较
   ↓
调整参数
   ↓
Base Model
~~~

预训练主要获得：

- 语言结构。
- 词义和上下文关系。
- 事实与概念关系。
- 文本、代码和任务模式。
- 部分推理规律。

### 后训练

~~~text
Base Model
   ↓
SFT：学习理想指令回答
   ↓
偏好与安全训练：学习哪个回答更好
   ↓
Assistant Model
~~~

**预训练获得通用能力，后训练塑造这些能力怎样表现。**

---

## 5. 一次回答怎样产生

~~~text
用户 Prompt + 对话历史
          ↓
        Token
          ↓
Transformer 处理当前上下文
          ↓
预测下一个 Token 的概率
          ↓
选择并追加一个 Token
          ↓
继续预测，直到结束
~~~

普通对话中：

- Prompt 会改变当前输出。
- 模型参数通常不会改变。
- 模型不是一次性写完全文，而是逐 Token 生成。

---

## 6. 为什么会犯错

- 训练目标是生成合理后续，不是证明每句话真实。
- 知识来自有限训练数据，存在缺失、错误和时效限制。
- 上下文长度和利用能力有限。
- 模型输出是概率分布，同一问题可能产生不同回答。
- 后训练只能提高期望行为概率，不能保证所有情况下都正确安全。

最终判断：

> LLM 是强大的概率生成模型，不是事实数据库、搜索引擎或确定性程序。

---

## 7. 两场分享最终只记住八句话

1. 人写不完规则时，可以让模型从数据中学习。
2. 数据提供经验，模型承载规律，损失指出错误，训练调整参数。
3. 训练改变参数，推理使用参数。
4. 真正目标不是记住训练数据，而是泛化到新数据。
5. LLM 根据上下文预测下一个 Token。
6. Transformer 让 Token 结合上下文信息。
7. 预训练获得通用能力，后训练塑造助手行为。
8. 语言流畅不等于事实可靠。
