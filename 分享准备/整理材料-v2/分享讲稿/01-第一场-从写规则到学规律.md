## 第 1 页：有些问题，为什么不能直接写规则

预计时间：4 分钟

### 页面上放什么

**明确规则的问题**

~~~text
订单金额 + 折扣规则 → 最终价格
~~~

**难以穷举规则的问题**

~~~text
一封邮件 → 是不是垃圾邮件？
一张图片 → 是不是猫？
一句话 → 表达了什么意图？
~~~

页面结论：

> 当规则无法被完整写出来时，我们需要让机器从大量例子中学习规律。

### 讲稿

大家好。今天是两场分享中的第一场，我们先不讲大语言模型，也暂时不讲 ChatGPT。

我们先回答一个更基础的问题：机器到底是怎么“学会”一件事的？

先看一个普通程序。比如计算一笔订单的最终价格，我们知道商品原价、会员等级、优惠券和满减规则。这里的规则很明确，我们可以让程序按照条件一步一步计算。

在这类问题里，最困难的部分是人把业务规则想清楚，然后把规则写进程序。程序本身不会学习，它只是非常准确地执行我们写好的步骤。

但现在换一个问题：怎样判断一封邮件是不是垃圾邮件？

我们当然也可以尝试写规则。比如包含“免费中奖”的算垃圾邮件，包含很多感叹号的算垃圾邮件，发件人陌生的算垃圾邮件。

可是真实情况很快就会失控。正常邮件里也可能出现“中奖”，垃圾邮件也可以故意避开这些关键词。不同语言、不同行业、不同发送者的表达方式都不同。规则会越来越多，规则之间还会发生冲突。

图片识别、语音识别、自然语言理解也有相同问题。不是因为我们完全不知道答案，而是因为我们很难把判断过程拆成一套完整、稳定、可以人工维护的规则。

于是我们换了一种思路：不再要求人把所有规则写出来，而是给机器看大量例子，让它自己调整内部状态，逐渐找到能够作出正确判断的规律。

这种思路，就是我们今天要讲的机器学习。

### 互动

可以问：

> 大家觉得“判断一封邮件是不是垃圾邮件”，如果完全依靠人工规则，最容易遇到什么问题？

接受两三个回答即可，不必展开讨论。

## 第 2 页：普通程序与机器学习的区别

预计时间：5 分钟

### 页面上放什么

**普通程序**

~~~text
人工规则 + 输入数据 → 输出
~~~

**机器学习训练**

~~~text
训练数据 + 已知结果 → 学出模型
~~~

**机器学习使用**

~~~text
训练好的模型 + 新输入 → 新预测
~~~

关系：

~~~text
人工智能：目标
机器学习：让机器从数据中学习的方法
深度学习：使用多层神经网络的机器学习方法
LLM：深度学习在语言上的大规模实现
~~~

### 讲稿

普通程序和机器学习最大的区别，不在于有没有代码，也不在于是不是用了 GPU，而在于最终用来判断的规则来自哪里。

普通程序里，规则由人直接提供。程序接收输入，再严格执行规则，得到输出。

机器学习里，人不再直接写出全部判断规则。我们提供大量训练数据，以及这些数据对应的结果。训练过程会从这些例子中调整出一个模型。

模型训练完成后，我们再把一个新的输入交给它，让模型作出预测。

注意这里有两个阶段。

第一个阶段叫训练。训练阶段的目标是从已有数据中找到一组能够完成任务的内部参数。

第二个阶段叫使用，也就是推理。推理阶段不再重新学习，而是使用已经训练好的模型处理新输入。

顺便把几个容易混在一起的词放到同一张图里。

人工智能是一个比较宽泛的目标：让机器完成通常需要智能才能完成的任务。

机器学习是实现人工智能的一类方法：让机器从数据中学习规律。

深度学习是机器学习中的一类方法，它使用多层神经网络学习复杂表示。

大语言模型，也就是 LLM，是深度学习在语言建模上的大规模实现。

所以它们不是四个互相竞争的东西，而是从目标到方法，再到具体模型的一条关系链。

今天我们主要停留在“机器学习到底怎么学”。下一场再把这套机制完整放到 LLM 上。

### 互动

可以让听众判断：

- 按照固定税率计算税额，是普通程序还是机器学习？

重点不是答案难度，而是让听众抓住“规则来自人工还是数据”。

## 第 3 页：机器学习只有五个核心角色

预计时间：6 分钟

### 页面上放什么

以垃圾邮件判断为例：

| 概念  | 在例子中是什么       |
| --- | ------------- |
| 数据  | 大量历史邮件        |
| 目标  | 每封邮件是否为垃圾邮件   |
| 模型  | 把邮件转换为判断的结构   |
| 参数  | 模型内部可被训练调整的数值 |
| 损失  | 当前预测错了多少      |

页面结论：

> 训练，就是根据损失不断调整参数。

### 讲稿

机器学习的论文、框架和算法很多，但站在最上层，训练过程只有几个核心角色。

第一个是数据。

数据是模型学习所依据的经验。垃圾邮件任务的数据，就是过去积累的大量邮件。

第二个是目标，也可以叫标签。

对每封历史邮件，我们需要知道它到底是不是垃圾邮件。这个结果为训练提供了方向。

第三个是模型。

模型可以理解为一个带有大量可调节位置的计算结构。我们把邮件交给模型，它会给出一个预测，比如“这封邮件有 80% 的可能是垃圾邮件”。

第四个是参数。

参数是模型内部可以被训练改变的数值。大家不需要知道每个参数具体代表什么。只需要知道，模型的行为取决于这些参数；训练的主要结果，就是找到一组更合适的参数。

第五个是损失。

损失是一个错误分数。它回答的不是“模型聪不聪明”，而是“模型当前的预测和训练目标差了多少”。

如果一封邮件真实是正常邮件，但模型非常确定地说它是垃圾邮件，这次损失就会比较大。

如果模型判断正确而且比较确定，损失就会比较小。

把这几个角色放在一起，训练就很好理解了：

模型先根据当前参数作出预测；损失衡量预测错了多少；训练方法再根据这个错误调整参数。

数据没有直接把完整规则写进模型。数据提供例子，损失提供方向，训练通过很多次调整，让参数逐渐形成能够完成任务的规律。

### 互动

可以问：

> 如果只有大量邮件，却不知道哪些是垃圾邮件，这个训练例子里缺少了什么？

预期答案：缺少目标或标签。

随后补一句：后面会看到，LLM 可以直接从文本中自动构造自己的训练目标。

## 第 4 页：模型是怎样一步一步学会的

预计时间：7 分钟

### 页面上放什么

~~~text
1. 取一批训练数据
        ↓
2. 模型作出预测
        ↓
3. 与目标比较
        ↓
4. 得到损失
        ↓
5. 调整参数
        ↓
6. 换下一批数据，继续重复
~~~

页面结论：

> 学习不是一次发生的，而是大量微小参数调整累积的结果。

### 讲稿

我们现在完整走一遍训练过程。

第一步，从训练数据中取一批历史邮件。

第二步，把这些邮件交给模型。模型根据当前参数，对每封邮件作出预测。

请注意，训练刚开始时，参数通常还没有形成有用规律，所以模型的预测可能接近随机。

第三步，把模型预测和真实标签进行比较。

第四步，根据差异得到损失。损失越大，说明当前模型在这批数据上错得越严重。

第五步，根据损失提供的信息，对模型参数作一次小调整。这个调整不是直接告诉模型“以后看到中奖两个字就判断成垃圾邮件”，而是改变模型内部很多数值，让类似输入下一次更可能得到正确结果。

第六步，换下一批数据，继续重复。

模型会见到正常邮件、垃圾邮件、不同写法、不同发送者和不同主题。每一批数据都会产生新的预测、新的损失和新的参数调整。

一次调整几乎不会让模型突然变聪明。真正的能力来自大量小调整不断累积。

大家可以把它想象成练习投篮。你投出一个球，看它偏左还是偏右，然后稍微调整动作。下一次再投，再根据结果调整。不是某一次投篮直接把完整技巧写进身体，而是大量反馈逐渐改变动作。

机器学习训练也是一样：预测、比较、调整，然后重复。

这里我们故意不展开参数究竟怎样调整。技术上会涉及梯度、反向传播和优化算法，但它们解决的是“怎样高效算出参数该往哪个方向变”。对今天的主线来说，我们只需要保留结果：

> 模型根据错误信号，对参数进行许多次小调整。

这已经足够解释机器学习是怎样从数据中获得能力的。

### 互动

可以口头给出一个例子：

> 一封正常的项目邮件里出现了“免费试用”，模型却判断成垃圾邮件。下一轮训练应该让模型更依赖单个关键词，还是结合更多上下文？

不需要讨论具体算法，只引出“模型应从多个特征和上下文中形成规律”。

### 转场

到这里我们完成了训练。但真实使用模型时，情况和训练完全不同。这个区别对理解 LLM 非常重要。

## 第 5 页：训练与推理是两件事

预计时间：4 分钟

### 页面上放什么

|训练|推理|
|---|---|
|有训练数据和目标|只有新输入|
|计算预测错误|直接产生预测|
|修改模型参数|通常不修改参数|
|成本高、耗时长|重复使用、响应较快|

页面结论：

> 训练是改变模型，推理是使用模型。

### 讲稿

训练结束后，我们得到了一组已经学习好的模型参数。

接下来有一封新邮件进来。模型读取邮件内容，使用已经训练好的参数，输出判断结果。

这个过程叫推理。

训练和推理最大的区别是：训练会改变模型参数，普通推理通常不会。

训练需要数据、目标、损失和大量参数调整，成本很高，而且通常由模型开发者集中完成。

推理只需要把新输入交给训练好的模型，然后得到结果。一个模型训练完成后，可以被大量用户反复使用。

这个区别可以压缩成一句话：

> 训练是改变模型，推理是使用模型。

为什么这件事对理解 LLM 很重要？

因为我们和聊天模型进行一次普通对话时，模型会读取当前上下文，并根据上下文改变当前回答，但这通常不等于它正在现场重新训练自己的参数。

当前对话可以临时影响输出；真正把新规律长期写进模型参数，通常需要重新进入训练流程。

所以“模型记得这段对话”和“模型通过训练学会了一个长期能力”不是同一件事。

## 第 6 页：记住答案不等于真正学会

预计时间：5 分钟

### 页面上放什么

~~~text
训练集：用来学习
验证/测试数据：用来检查能否处理没见过的样本
~~~

**过拟合**

> 训练数据上很好，新数据上很差。

**泛化**

> 能把学到的规律用于未见数据。

### 讲稿

想象一个学生，把练习册里所有题目和答案全部背了下来。

如果考试题和练习册完全一样，他可能得到满分。但题目稍微改变，他就不会做了。

我们不能说这个学生真正掌握了知识，只能说他记住了答案。

机器学习也会遇到同样的问题。

如果模型只是在训练数据上表现好，却不能处理新的邮件，那么它没有学到足够通用的规律。

这种现象叫过拟合：模型过度适应了训练数据中的具体样本、偶然特征甚至噪声。

所以我们不能只看模型在训练数据上的表现。

通常会把数据分成不同部分。

训练集用于调整参数。

验证或测试数据不参与参数学习，用来检查模型面对未见数据时是否仍然有效。

模型能够把学到的规律用于新样本，这种能力叫泛化。

机器学习真正的目标不是把训练集背下来，而是通过有限训练数据，学到能够适用于真实新数据的规律。

这也解释了为什么数据的覆盖非常重要。如果训练数据只包含一种语言、一种行业或者一种表达方式，那么模型进入新环境后就可能表现明显下降。

模型能够学到什么，不只取决于模型有多大，也取决于它见过怎样的数据，以及我们使用什么方式检查它。

### 互动

可以让听众判断：

> 一个模型在训练数据上准确率 100%，但在新邮件上只有 60%，它是真的学会了吗？

答案：没有充分泛化，很可能发生了过拟合。

## 第 7 页：神经网络与深度学习处在什么位置

预计时间：5 分钟

### 页面上放什么

~~~text
机器学习
   ↓
神经网络：大量可调整参数组成的模型
   ↓
深度学习：使用多层神经网络学习复杂表示
   ↓
LLM：面向语言的大规模深度学习模型
~~~

对比：

~~~text
人工设计特征：人告诉模型应该关注什么
表示学习：模型从数据中学习应该怎样表示输入
~~~

### 讲稿

机器学习并不等于神经网络。机器学习包含很多类型的模型。

但今天语音、图像和语言领域的大模型，主要建立在神经网络和深度学习之上。

大家可以把神经网络理解为一种由大量可调整参数组成的模型结构。

输入进入模型后，会经过多层转换。训练过程中，每一层的参数都会根据最终错误一起被调整。

为什么需要多层？

因为复杂任务通常不能直接从原始输入一步得到结果。模型需要逐层形成更有用的内部表示。

以邮件为例，模型最初看到的是文本。经过多层处理后，它可能逐渐形成对词语组合、语气、发送意图和上下文关系有用的内部表示。

这些内部表示不一定是人提前规定好的。模型会根据训练目标，自动形成有利于降低损失的表示。

这就是深度学习里非常重要的“表示学习”。

需要特别澄清一点：神经网络不等于按照人脑原样复制出来的电子大脑。这个名字有历史来源，但工程上我们更应该把它看成一种可以通过数据训练的大规模参数化计算结构。

网络更深、参数更多，通常意味着可以表示更复杂的关系。但参数多不自动等于模型好。

它仍然需要：

- 足够且合适的数据。
- 明确的训练目标。
- 有效的训练过程。
- 对未见数据的评测。

也就是说，即使进入深度学习时代，我们前面讲的数据、模型、损失、训练和泛化仍然全部成立。

## 第 8 页：把机器学习骨架套到 LLM

预计时间：5 分钟

### 页面上放什么

| 机器学习概念 | LLM 中的对应内容       |
| ------ | ---------------- |
| 数据     | 大量文本和代码          |
| 输入     | 前面的 Token        |
| 目标     | 真实的下一个 Token     |
| 模型     | Transformer      |
| 损失     | 预测下一个 Token 错了多少 |
| 训练     | 根据错误调整大量参数       |
| 结果     | Base Model       |

总主线：

~~~text
大量文本
   ↓
预测下一个 Token
   ↓
根据错误调整参数
   ↓
重复海量次数
   ↓
得到语言模型
~~~

### 讲稿

我们用这一页把今天的机器学习和下一场的 LLM 连接起来。

机器学习需要数据。LLM 的主要预训练数据是大量文本和代码。

机器学习需要输入和目标。对于语言模型，我们可以把前面的 Token 作为输入，把真实出现的下一个 Token 作为目标。

机器学习需要模型。现代 LLM 使用的核心模型结构叫 Transformer。下一场我们只解释它在整条链上的作用，不会推导数学公式。

机器学习需要损失。LLM 会衡量自己对真实下一个 Token 的预测错了多少。

机器学习需要训练。模型根据预测错误，调整内部大量参数，然后继续处理下一批文本。

这个过程重复海量次数之后，我们会得到一个 Base Model，也就是基础语言模型。

这里有一个非常重要的地方：普通监督学习通常需要人给每个样本标注答案，但文本天然提供了下一个 Token。

例如一句话原本是“今天下午我们开会”。

看到“今天”，真实下一个 Token 已经在原文里。

看到“今天下午”，真实的后续 Token 仍然在原文里。

也就是说，模型可以从原始文本中自动构造大量训练题目，不需要人逐个位置写答案。这就是为什么大规模语言预训练成为可能。

今天请大家只带走下面几句话。

第一，普通程序由人写规则，机器学习从数据中调整出模型参数。

第二，训练的核心闭环是：作出预测、比较目标、得到损失、调整参数。

第三，训练会改变模型，推理只是使用模型。

第四，真正的目标不是记住训练数据，而是能够处理没见过的新数据。

第五，LLM 并没有脱离这套机器学习骨架。它只是把数据换成海量文本，把任务换成预测下一个 Token，把模型换成大规模 Transformer。

下一场我们就沿着最后这条线继续：

> 一个只被要求预测下一个 Token 的模型，为什么最后能够写作、问答、编程甚至解决推理问题？

### 结束语

今天我们没有讲任何算法公式，但已经建立了理解 LLM 最重要的地基：

**数据提供经验，模型承载规律，损失指出错误，训练调整参数，泛化决定模型是否真正有用。**
