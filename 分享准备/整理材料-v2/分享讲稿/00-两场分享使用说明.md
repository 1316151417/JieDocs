# 两场分享使用说明

## 1. 分享对象

默认听众：

- 没有机器学习背景。
- 不理解预训练、参数、损失和推理。
- 日常使用过 ChatGPT 或其他大模型产品。
- 希望理解 LLM 的核心原理，而不是学习数学推导或训练代码。

---

## 2. 两场分享的总目标

两场结束后，听众应当能够回答：

1. 机器学习和普通程序有什么区别？
2. 数据、模型、参数、损失和训练分别是什么？
3. 训练与推理有什么区别？
4. LLM 为什么可以通过预测下一个 Token 获得能力？
5. 预训练、SFT 和偏好对齐分别做了什么？
6. LLM 收到 Prompt 后怎样逐 Token 生成回答？
7. 为什么 LLM 会产生幻觉和其他错误？

不要求听众：

- 会写训练代码。
- 会推导梯度和反向传播。
- 理解 QKV 矩阵公式。
- 区分 PPO、DPO、GRPO 的数学细节。
- 掌握分布式训练和推理系统优化。

---

## 5. 每一页的使用方式

每页分为四部分：

### 页面上放什么

真正展示给听众的文字。

原则：

- 每页只表达一个结论。
- 不把讲稿全文堆在页面上。
- 优先使用流程图、对比和例子。

### 讲稿

可以直接照着说的口语化正文。

讲稿不需要逐字背诵，但不要随意加入目录中更深的技术细节。

### 互动

可选的现场提问、举手或小演示。

如果时间不足，可以跳过互动，不影响主线。

### 转场

当前页如何自然进入下一页。

## 6. 分享边界

正文只保留两条因果链。

### 机器学习链

**数据 → 模型 → 预测 → 比较目标 → 调整参数 → 泛化**

### LLM 链

**文本 → Token → Transformer → 下一个 Token 预测 → 预训练 → 后训练 → 自回归生成**

无法帮助解释这两条因果链的内容，均不进入正文。

---

## 7. 两场之间的间隔

建议间隔 2～7 天。

第二场开头会用约 3 分钟复习第一场，不要求听众在两场之间完成作业。

---

## 8. 最终原则

**完整笔记用于保证讲师不说错，主讲内容只用于帮助听众建立最小但正确的心智模型。**
