# LLM 核心知识总目录

## 1. 范围

这套笔记只覆盖两条主线：

1. 机器学习与深度学习的必要基础。
2. 从语言模型到现代 LLM 的模型、训练、推理与评测骨架。

不展开传统机器学习算法大全、计算机视觉、多模态、RAG、Agent、框架 API 和 Prompt 技巧。

---

## 2. 总主线

**任务与数据 → 模型 → 损失函数 → 优化 → 泛化 → 文本表示 → 语言模型 → Attention → Transformer → 预训练 → 后训练 → 解码与推理 → 评测**

## 8. 每章掌握标准

1. 它解决什么问题？
2. 它的输入、输出和参数是什么？
3. 它的核心计算或目标函数是什么？
4. 它如何训练？
5. 它在推理阶段如何工作？
6. 它解决了上一层的什么限制？
7. 它又留下了什么限制？
