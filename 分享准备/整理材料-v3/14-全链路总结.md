# 14. 全链路总结

## 一、整条演化链（最终版）

```text
机器学习
学会根据误差调整参数
    ↓  人工特征成为瓶颈
深度学习
学会形成中间表示（特征自动化）
    ↓  序列需要上下文，RNN 逐步传递成为瓶颈
Transformer
让 Token 动态汇总上下文（表示自动化）
    ↓  架构不等于能力，随机参数不懂语言
GPT / 预训练
用统一目标从海量文本获得通用能力
    ↓  有能力没行为，不听指令、不合偏好
现代 LLM
SFT + 偏好对齐 + 推理训练 + 工程优化
    ↓  模型只输出文本，无法执行真实任务
Agent
把模型放进带目标、工具、状态的执行循环（行动自动化）
```

## 二、每章一个问题（自测索引）

| 章   | 核心问题                  | 一句话答案                                           |
| --- | --------------------- | ----------------------------------------------- |
| 01  | 机器学习学到的到底是什么？         | 一组在新数据上仍然有效的参数                                  |
| 02  | 线性模型家族的共同本质？          | 全部建立在 Wx+b 上，表达能力止步于线性                          |
| 03  | 深度学习真正改变了什么？          | 特征学习：表示也交给机器自动学                                 |
| 04  | CNN/RNN 各自利用什么结构？     | 空间局部性 / 时间顺序                                    |
| 05  | Attention 改变了什么？      | 信息交互从固定路径变成内容驱动的动态连接                            |
| 06  | Transformer 的稳定骨架？    | Attention 通信 + FFN 加工 + 残差保底 + Norm 稳压，因果掩码通向生成 |
| 07  | 文本怎么进模型、概率怎么出模型？      | Tokenizer→ID→Embedding→Blocks→Logits→Softmax    |
| 08  | 为什么预测下一个 Token 能学到能力？ | 做好这个简单目标需要大量中间能力                                |
| 09  | 预训练模型是什么、不是什么？        | 有能力没行为的文本补全器                                    |
| 10  | SFT 和对齐分别改变什么？        | 行为方式与偏好倾向，不增加知识真值                               |
| 11  | Inference 和训练的根本区别？   | 参数不变，逐 Token 循环生成                               |
| 12  | 工程优化围绕哪三个字？           | 做大（MoE）、做长（GQA/Flash）、做快（量化）                    |
| 13  | Agent 和模型的边界？         | 模型决定，系统执行；Agent 不是新模型                           |

## 三、六个自动化（整条主线的最终压缩）

```text
规则自动化（传统程序把执行交给机器）
→ 参数自动化（机器学习把找参数交给机器）
→ 特征自动化（深度学习把设计特征交给机器）
→ 表示自动化（Transformer 把上下文建模交给机器）
→ 任务适配自动化（LLM 把任务适配从微调变成指令/上下文）
→ 行动自动化（Agent 把行动选择交给机器）
```

整场分享真正回答的不是"AI 技术有哪些"，而是：

**机器是如何一步步减少对人工规则、人工特征和任务专用开发的依赖，逐渐获得通用学习与行动能力的？**

## 四、五个判断问题（留给听众的框架）

听到新概念/新模型/新产品时：

1. 它改变的是模型结构、训练方式、Inference，还是模型外部系统？
2. 它使用了什么数据或反馈信号？
3. 它实际优化的目标是什么？
4. 能力来自模型参数，还是工具、上下文和工作流？
5. 它在哪些条件下有效，又不能保证什么？

## 五、易混概念速查

| 概念 | 主要职责 | 不等于 |
|---|---|---|
| 参数 | 训练得到的内部数值 | 人类可读规则 |
| 特征/表示 | 模型的内部表达 | 必然可命名的概念 |
| Token | Tokenizer 定义的离散单元 | 固定等于单词 |
| Embedding | Token 的初始向量 | 完整上下文语义 |
| Attention | 按内容匹配汇总信息 | 模型的思考过程 |
| Causal Mask | 禁止看未来 Token | 让模型事实正确 |
| Logit/概率 | 候选 Token 的分数 | 事实置信度 |
| 预训练 | 形成基础能力 | 天然服从用户 |
| SFT | 塑造指令响应行为 | 主要知识来源 |
| RLHF/DPO | 塑造偏好倾向 | 保证永远正确安全 |
| Inference | 运行模型生成输出 | Reasoning |
| Streaming | 逐步返回已生成 Token | 提升模型智能 |
| KV Cache | 复用历史 K/V | 增加知识 |
| Tool Call | 模型生成工具请求 | 工具已被执行 |
| MCP | 连接工具的协议 | Agent 或工作流 |
| Skill | 可复用任务知识 | 模型内部能力 |
| Agent | 组织模型+工具+循环的系统 | 新的模型架构 |

## 六、30 秒 / 3 分钟口述版

### 30 秒版

> LLM 底层仍然在预测下一个 Token。机器学习教会它根据误差调参数，深度学习让它自动学特征，Transformer 让每个词直接汇总上下文，海量文本预训练给了它语言和知识，SFT 和人类反馈让它学会当助手，推理时它逐 Token 生成，Agent 再把它和工具、状态组织成能完成真实任务的系统。

### 3 分钟版（每节一句话展开）

1. **机器学习**：规则写不完，就让机器从数据里找参数——预测、算损失、调参数的闭环，目标是在新数据上依然有效。
2. **深度学习**：线性模型叠再多层还是线性，加上非线性激活和反向传播，模型连特征都能自己学。
3. **CNN/RNN**：把数据的结构假设写进网络——空间局部性用共享检测器，序列顺序用流动的隐藏状态。
4. **Transformer**：RNN 传信息太慢太挤，Attention 让每个词按内容直接找相关的词，一步直达、可以并行；因果掩码让它只能看过去，于是能预测下一个 Token。
5. **GPT/预训练**：互联网文本天然提供答案，一个统一目标零标注；为了预测得准，语言、知识、推理模式被一起学了进去。
6. **现代 LLM**：SFT 教它按指令回答，偏好对齐教它回答得更好，推理模型教它把思考外化成步骤，工程优化让它做得大、长得长、跑得快。
7. **Agent**：模型只会生成文本；Tool Call、ReAct、规划、Skill、MCP 把它包进一个能真正执行、反馈、修正的系统。

**收尾句：真正令人惊讶的不是目标多复杂，而是当结构、数据、参数和计算扩到足够规模后，为了持续做好"预测下一个 Token"这件小事，机器形成了我们称之为智能的行为。**
