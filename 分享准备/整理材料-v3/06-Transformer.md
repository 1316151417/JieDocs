# 06. Transformer

## 0. 本章位置

上一章建立了 Attention 的直觉：按内容相关性动态汇总信息。本章把 Transformer 组装完整——它是现代 LLM 的直接骨架，也是整套分享最重要的结构转折。

本章只讲 Transformer 解决的结构问题，不急着讲 GPT 怎么用它获得语言能力。

---

# 1. Transformer

## 解决的问题

RNN 的三个结构限制（长距离路径长、难并行、压缩瓶颈），需要一个新的序列建模架构。

## 定义

**Transformer 是一种以 Self-Attention 为核心信息交互机制的神经网络架构。**

（出自 2017 年《Attention Is All You Need》，原为 Encoder-Decoder 结构；现代 LLM 主要用它的 Decoder 侧。）

## 核心本质

**让每个 Token 根据与整个序列的关系，动态汇总上下文信息，形成上下文相关表示。**

下面逐个拆解它的组成部件。

---

# 2. Q、K、V

## 解决的问题

"匹配相关性"具体怎么做？——用一个 Token 的"查询"去匹配另一个 Token 的"线索"。

## 定义

Self-Attention 中，每个位置的当前表示经过三组**学习到的**线性变换，产生三个向量：

- **Q（Query）**：当前位置正在寻找什么信息；
- **K（Key）**：每个位置提供什么匹配线索；
- **V（Value）**：匹配之后，真正被取回并汇总的内容。

## 核心机制

完整信息流：

```text
当前位置生成 Q
→ Q 与所有可见位置的 K 计算匹配分数
→ 匹配分数经 Softmax 变成注意力权重
→ 按权重汇总所有位置的 V
→ 得到新的上下文相关表示
```

公式（QA 级备用，正文不推导）：

\text{Attention}(Q,K,V)=\operatorname{Softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V

### 为什么必须分三个，而不直接用原始表示

因为**"用什么维度寻找信息""用什么维度参与匹配""匹配后传递什么内容"不一定是同一件事。**

例：找"银行"的词义时，我寻找的线索（Q）可能是"有没有水域名词"，别人提供的匹配线索（K）可能是"我是名词、和水域相关"，而真正取回的内容（V）是完整的语义信息。三个职责分开投影，模型才能为每个职责学习不同的表示空间。

### 必须避免的误解

- Q 不是一句自然语言问题；
- K 不是数据库主键；
- V 不是已经写好的答案；
- 它们都是训练得到的向量，不是人工预先定义的。

## 核心本质

**三个可学习的投影，把"寻找—匹配—取回"三个职责分开，让匹配和传递内容各自学到最优的表示空间。**

# 3. 多头注意力（Multi-Head Attention）

## 解决的问题

一组 QKV 只能在一个表示子空间里做一种匹配。语言里的关系是多样的：语法关系、指代关系、语义关联、位置邻近——一种视角不够用。

## 定义

**多头注意力是并行进行多组独立的 QKV 投影和注意力计算，再把结果合并的机制。**

## 核心机制

```text
同一批 Token 表示
→ 分成 h 组，每组独立做 Attention（每组一个"视角"）
→ 各自得到汇总结果
→ 拼接 + 线性变换，合并回统一表示
```

可以理解为：**对同一段上下文，同时使用多组不同的匹配视角。**

注意边界：某些头可能呈现局部语法、指代或位置模式，但**不要把每个头强行解释成一个固定的人类概念**——这种对应通常不稳定、不完备。

## 核心本质

**多组并行的匹配视角，让模型同时捕捉多种关系。**

---

# 4. 位置编码

## 解决的问题

Attention 主要依据**内容**计算关系，对顺序天然不敏感。但顺序是语言的核心结构：

```text
狗咬人 ≠ 人咬狗
```

Token 的集合相同、顺序不同，含义完全不同。不加入位置信息，模型无法区分它们。

## 定义

**位置编码是把每个 Token 的位置信息加入其表示（或注意力计算）的机制。**

## 核心机制

两条技术路线，知道定位即可：

- **绝对位置编码**（原始 Transformer）：每个位置学一个固定向量，加到 Token 的 Embedding 上；
- **RoPE 旋转位置编码**（现代 LLM 常用）：让位置信息进入 Q 和 K 的关系计算，使注意力天然感知**相对位置**。不展开旋转矩阵，只需知道它解决"让内容匹配同时感知顺序"。

## 核心本质

**给内容匹配补上顺序感：内容决定"关注谁"，位置帮助区分"怎样排列"。**

---

# 5. 因果掩码（Causal Mask）—— 通向 GPT 的桥

## 解决的问题

如果训练目标是"预测下一个 Token"，模型在预测当前位置时**不能看到未来的正确答案**。

## 定义

**因果掩码限制每个位置的可见范围：第 t 个位置只能看到自己及之前的 Token。**

## 核心机制

在图上是一个下三角可见区域：

```text
位置 1：只能看 1
位置 2：可以看 1、2
位置 3：可以看 1、2、3
位置 4：可以看 1、2、3、4
```

这座桥非常关键，两条因果链：

**训练侧：**

```text
不能看到未来 Token
→ 每个位置只能根据前文形成表示
→ 可以训练它预测下一个 Token
（完整文本已知，多个位置仍可在一次前向计算中并行训练）
```

**生成侧：**

```text
不能看到未来 Token
→ 生成时可以从左到右不断续写
（但下一个 Token 尚不存在，必须先生成再追加——生成本身仍是顺序过程）
```

## 核心本质

**因果掩码既防止训练时偷看答案，也建立了从左到右生成的结构约束——这是 Transformer 走向语言模型的关键一步。**

# 6. Transformer Block：整体信息流

## 解决的问题

Attention 只做"位置间信息交换"。一个完整可训练、可堆叠的单元还需要：逐位置变换、训练稳定性、信息保底通道。

## 定义

**Transformer Block 是"Attention + FFN + 残差连接 + Norm"组成的可堆叠基本单元。**

## 核心机制

一个简化的现代 Decoder Block：

```text
输入表示
→ Norm
→ Causal Self-Attention
→ 残差连接
→ Norm
→ Feed-Forward Network（FFN）
→ 残差连接
```

四个部件的职责：

| 部件 | 职责 |
|---|---|
| Self-Attention | 让 Token 之间交换上下文信息（唯一的跨位置 mixing） |
| FFN | 对**每个位置**的表示做进一步非线性变换；不跨位置传递信息，但承担大量表示变换和模型容量 |
| 残差连接 | 让子层学习"在已有表示上增加什么"；为信息和梯度提供更直接的通路 |
| Norm | 控制表示尺度，改善深层堆叠时的训练稳定性 |

几十上百个 Block 依次堆叠，每个 Token 的表示反复经历：

```text
汇总上下文 → 变换表示 → 保留并叠加已有信息 → 进入下一层
```

一个有用的分工记忆：**Attention 负责位置间通信，FFN 负责位置内加工。**

## 核心本质

**"通信（Attention）+ 加工（FFN）+ 保底（残差）+ 稳压（Norm）"的可堆叠单元。**

---

# 7. 三类 Transformer 架构（只做定位）

| 结构 | 直觉定位 | 典型用途 |
|---|---|---|
| Encoder-only | 每个位置读取完整输入，形成上下文表示 | 文本理解、分类（BERT 系） |
| Encoder-Decoder | Encoder 读取输入，Decoder 根据输入生成输出 | 翻译、摘要 |
| Decoder-only | 根据已有上下文持续生成后续 Token | GPT、LLaMA 系 LLM |

三者没有淘汰关系，只是面向不同任务组织信息流。**现代通用 LLM 的主线是 Decoder-only + Causal Attention + 自回归训练。**

## 核心本质

**同样的 Attention 原理，按"要不要看未来、要不要两段输入"组织成三种信息流。**

---

# 8. Transformer 的能力与边界

## 获得的新能力

1. 每个 Token 可以形成上下文相关表示；
2. 长距离信息直接交互（路径长度 1）；
3. 训练时序列各位置可以并行计算；
4. 同一套结构可以扩展到大规模训练。

## 边界

Transformer 本身只是一种网络架构，**它并不天然等于** GPT、聊天机器人、大语言模型或 Agent。一个随机初始化的 Transformer 完全不懂语言。

代价提示：标准全注意力对序列长度的时间和显存开销增长较快（O(n²)）——这是后续工程优化的伏笔。

---

# 9. 极简总结

**Transformer = Self-Attention 直接建立全局连接；QKV = 寻找/匹配/取回三个可学习投影；多头 = 多视角并行；位置编码 = 补上顺序；因果掩码 = 只看过去、可训练可生成；Block = 通信+加工+保底+稳压。**
