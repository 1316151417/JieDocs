# 08. 自回归语言模型与 GPT 路线

## 0. 本章位置

上一章打通了"文本 → Token → 向量 → 多层 Block → 下一个 Token 概率"的结构，但参数还是随机的。本章回答：用什么目标训练、能力怎么来、GPT-1/2/3 三步各证明了什么。

---

# 1. 语言模型与自回归生成

## 解决的问题

用什么统一的任务目标，让模型从文本中学习？

## 定义

**语言模型根据已有文本预测下一个 Token 的概率分布；自回归生成指把自己的输出追加回输入，逐 Token 续写。**

## 核心机制

```text
输入：今天天气很
预测：好 / 冷 / 热……（全词表概率分布）

生成："好"被选中 → 追加回上下文
    → "今天天气很好"
    → 继续预测下一个 Token
    → 循环，直到结束
```

"自回归"的含义：**用自己生成的结果，作为下一步的输入。**

## 核心本质

**把"理解语言"变成"逐 Token 的条件概率预测"。**

# 2. 预训练：统一目标，天然监督

## 解决的问题

去哪找海量监督信号？人工标注不可能覆盖互联网规模的文本。

## 定义

**预训练是在海量文本上，用"预测下一个 Token"这一个统一目标训练模型的过程。**

## 核心机制

关键洞察：**真实文本天然提供正确答案，不需要人工标注。**

假设训练文本是"机器学习可以从数据中学习参数"，切成 Token 后同时构造多组"前文—下一个 Token"关系：

```text
机器                → 学习
机器 学习           → 可以
机器 学习 可以      → 从
机器 学习 可以 从   → 数据
……
```

一段文本平移一位，输入是前缀、标签是下一个 Token——一个样本同时产生所有位置的监督信号。

极简训练循环：

```python
tokens = tokenize(text)
prediction = model(tokens[:-1])   # 因果掩码保证每位置只看过去
loss = compare(prediction, tokens[1:])  # 交叉熵
update_parameters(loss)           # 反向传播 + 优化器
```

## 核心本质

**互联网规模的文本 + 一个统一目标 + 零人工标注 = 预训练。**

# 3. 为什么预测下一个 Token 能学到广泛能力

## 问题

"预测下一个 Token"听起来太简单，为什么能产生语言、知识甚至推理能力？

## 核心解释

**因为准确预测后文，往往要求模型隐式掌握大量中间能力。**

预测这句话的后续：

```text
如果数据库连接池已经耗尽，那么新的请求通常会……
```

只知道局部词频不够，模型还需要利用：

- 词法和句法；
- 前后文的语义关系；
- 文档和代码的组织模式；
- 训练数据中反复出现的**事实关联**；
- 问题、推导步骤与答案之间的**模式**；
- 不同任务如何被表达成文本。

这些能力都能降低预测误差，所以模型有动力把它们压缩进参数。

必要的克制（表述边界）：

1. 我们能观察到模型形成了广泛能力；
2. 这些能力与数据、规模、架构和训练过程**共同**相关；
3. 不能断言每个参数保存了哪条知识，也不能断言模型以人类同样的方式理解世界。

## 核心本质

**下一个 Token 预测是统一训练目标；语言、知识和部分能力，是模型为优化这个目标而形成的内部表示与行为。**

# 4. GPT 三步：能力演化主线

不按论文逐篇讲，按"每一步证明了什么"讲。

## GPT-1（2018）：预训练能力可以迁移

**解决的问题**：能否先通过大量无标注文本学习通用语言表示，再适配具体任务？

```text
大规模生成式预训练
→ 针对下游任务微调
```

核心证明：**生成式预训练得到的语言能力，可以迁移到多个下游任务。**（"预训练 + 微调"范式）

## GPT-2（2019）：任务可以统一为文本生成

**解决的问题**：能否把不同语言任务统一成文本生成，而不是为每个任务单独设计模型？

核心证明：**很多任务不再需要独立的输出结构，都可以表达为"根据上下文继续生成文本"。** 初步展现 Zero-shot 能力，不再强调每个任务单独微调。

## GPT-3（2020）：新任务可以通过上下文适配

**解决的问题**：模型能否不修改参数，只通过上下文中的说明和示例完成新任务？

核心证明：**大模型可以把上下文本身当作临时任务说明和学习材料。** Zero-shot / One-shot / Few-shot（In-context Learning）。

## 三步压缩

```text
GPT-1：能力可以从预训练迁移（预训练 + 微调）
GPT-2：任务可以统一为文本生成
GPT-3：新任务可以通过上下文适配（In-context Learning）
```

最重要的不是参数量，而是**任务接口的逐渐统一**：

```text
每个任务单独训练
→ 许多任务统一成文本生成
→ 通过上下文临时说明任务
```

## In-context Learning 的关键澄清

**它不更新模型参数。** Few-shot 与传统机器学习训练的本质区别：示例只存在于上下文中，改变的是模型的"条件"，不是模型的"参数"。同一模型、不同上下文，行为不同——这就是"上下文适配"。

---

# 5. 极简总结

**语言模型 = 逐 Token 条件概率；预训练 = 海量文本自监督；能力的来源 = 做好简单目标需要大量中间能力；GPT 三步 = 迁移 → 统一 → 上下文适配。**

---

# 6. 遗留的问题

GPT-3 展现了通用能力，但明显问题仍在：

1. 它学的是"什么文本可能接着出现"，**不天然等于服从用户**——输入"请用三句话解释缓存击穿"，它可能续写出另一个相似问题；
2. 输出可能不符合人类偏好（冗长、格式混乱、有风险）；
3. 训练和推理成本很高，上下文长度有限。
