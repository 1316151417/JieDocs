# 01. 人工智能与机器学习

## 0. 本章位置

整套分享的起点。回答两个最基础的问题：什么是人工智能？机器学习是什么、解决什么问题、由什么构成？

---

# 1. 人工智能

**定义：使机器表现出智能行为。**

关系：是目标。

一个必须交代的争议：这个定义是长期研究实践中形成的宽泛领域共识，而不是某个权威一次性确定的正式定义。如果深究"什么是智能"，就进入了哲学、认知科学和意识研究，很难形成可操作的工程标准。所以现代 AI 更常采用**功能主义/行为主义式定义**：

**只要系统能够执行通常需要智能才能完成的任务，就把它视为人工智能系统。**

暂时不解决"智能本质是什么"，而研究怎样让机器做出那些如果由人完成、就会被认为需要智能的事情。

---

# 2. 机器学习

**定义：让机器从数据或经验中学习可泛化的规律，使其在特定任务上的表现不断改善。**

关系：是实现人工智能的一种方法。

## 2.1 解决的问题

现实世界大量任务的规则过于复杂，难以人工完整枚举和编写。

传统程序与机器学习的分工差异：

```text
传统程序：规则 + 输入 → 输出
机器学习：数据 + 正确答案 → 找到模型参数
          输入 + 学到的参数 → 预测
```

典型例子：人可以凭经验判断一封邮件是否是垃圾邮件，但很难穷举所有判断条件；即使写出几百条规则，也会遇到规则冲突、场景变化和大量漏网情况。

注意：机器学习不是"机器自己发现一切"。人仍然决定收集什么数据、选择什么模型形式、什么结果算好；机器主要完成的是**在这些约束下寻找参数**。

## 2.2 核心机制：四个组件

| 组件 | 定义 |
|---|---|
| 数据 | 模型学习规律所依据的经验来源 |
| 模型 | 承载所学习规律的计算结构与参数 |
| 损失函数 | 衡量模型输出与训练目标之间的差异 |
| 优化算法 | 根据损失函数产生的优化信号更新模型参数，使损失减小 |

四者构成训练闭环：

```text
给定参数
→ 进行预测
→ 计算误差（损失函数）
→ 调整参数（优化算法）
→ 再次预测
→ 重复
```

## 2.3 核心本质

**人提供数据、模型形式和优化目标，机器在约束下寻找参数。**

---

# 3. 泛化：机器学习真正的目标

## 解决的问题

训练结果好，不代表真实使用效果好——必须区分这两件事。

## 定义

**泛化指模型在没见过、但与真实使用场景相似的新数据上仍然有效的能力。**

## 核心机制

区分数据集职责：

| 数据集 | 职责 |
|---|---|
| 训练集 | 调整参数 |
| 验证集 | 选择方案 |
| 测试集 | 估计真实使用表现 |

训练损失很低可能有两种完全不同的含义：

1. 模型学到了能迁移到新样本的规律；
2. 模型容量足够大，记住了训练数据甚至噪声（过拟合）。

## 核心本质

**训练的目标不是把训练误差压到最低，而是在新数据上仍然有效；否则只是记忆，不是学习。**

---

# 4. 极简总结

**人工智能 = 目标；机器学习 = 方法；模型 = 规律载体；损失函数 = 衡量差异；优化算法 = 修改参数；泛化 = 真正的目标。**

- 什么才是有效特征？
