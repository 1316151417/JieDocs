# 00. 总目录与阅读说明

## 整套材料的主线

一条演化链，回答一个问题：

**机器是如何一步步减少对人工规则、人工特征和任务专用开发的依赖，逐渐获得通用学习与行动能力的？**

```text
机器学习：学习参数
    ↓
深度学习：学习特征（中间表示）
    ↓
Transformer：学习上下文关系
    ↓
GPT / 预训练：从海量文本中学习通用语言能力
    ↓
现代 LLM：让能力可用、可靠、高效（指令、偏好、推理、工程）
    ↓
Agent：从生成答案走向完成任务
```

每一步的驱动力都相同：**上一阶段把某些工作交给了机器，剩下的瓶颈变成了下一阶段要解决的问题。**

| 阶段 | 人主要提供 | 机器主要学习或完成 |
|---|---|---|
| 传统程序 | 明确规则 | 执行规则 |
| 机器学习 | 特征、模型形式、数据 | 参数 |
| 深度学习 | 网络结构、数据 | 特征与参数 |
| Transformer | 训练目标、数据 | 上下文表示 |
| GPT | 海量文本 | 通用语言能力 |
| 现代 LLM | 指令、偏好、反馈 | 任务适配与复杂推理 |
| Agent | 目标、工具、约束 | 规划和行动 |

## 两层材料的分工

- **01~14 是弹药库**：深度优先，供复习到脱稿、QA 被追问时使用；
- **15 是战场**：七步最小结构（机器学习→深度学习→Transformer→预训练→后训练→生成→Agent），只带脊干上山，细节按"承重测试 + 误导测试"原则删减进 QA。

## 三条阅读纪律

1. **先有地图，在能力边界扩张；真正卡住时，再向下补基础。**
2. 数学、论文细节、历史细节都是支撑材料，不是主线。
3. 完成标准不是"所有细节都理解了"，而是**能脱离资料，把每个节点清晰讲明白**。
