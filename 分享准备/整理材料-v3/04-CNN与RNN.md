# 04. CNN 与 RNN：利用数据结构的两种深度网络

## 0. 本章位置

上一章的 MLP 证明了"多层 + 非线性 = 自动学习特征"，但它是全连接的，没有对数据做任何结构假设：

- 图像：同一种局部模式可能出现在不同位置；
- 文本：当前词的含义可能依赖之前的信息。

CNN 和 RNN 分别为这两类数据加入结构假设。它们不是与深度学习并列的阶段，而是**深度学习如何利用数据结构的两个典型实例**。其中 RNN 直接引出 Transformer，是本章后半的重点。

---

# 1. CNN（卷积神经网络）

## 解决的问题

如何利用图像的**局部性和空间结构**来高效学习视觉特征？

全连接网络的两个浪费：

1. 参数爆炸：百万像素直接全连接，参数量不可接受；
2. 重复劳动：一个"边缘检测器"在图片左上角有用，在右下角同样有用——全连接却在每个位置单独学一遍。

## 定义

**CNN 是一种通过局部连接和参数共享，用共享的局部检测器在图像各处提取相同模式，并逐层组合成高级特征的深度网络。**

## 核心机制

三个核心思想：

### 局部连接

每个神经元只连接输入的一个局部区域（感受野）。图像的局部像素才构成有意义的模式（边缘、角点），远距离像素的直接关联弱。

### 参数共享

同一组卷积核（局部检测器的权重）在图像所有位置滑动使用。

```text
一个小窗口（卷积核）
→ 在图片不同位置移动
→ 寻找同一种局部模式
→ 输出一张"该模式在哪里出现"的特征图
```

### 层次化特征

与第 3 章的特征学习衔接：前层学边缘、方向、颜色变化；中层学纹理和局部形状；后层学物体部件和类别特征。

## 核心本质

**把"相同局部模式可能出现在不同位置"这一结构假设，通过局部连接和参数共享写进网络结构。**

> 定位提醒：CNN 在整套分享中只承担"深度学习能针对数据结构做设计"的证据，一条一句话定位即可，不是 LLM 主线。

# 2. RNN（循环神经网络）

## 解决的问题

如何处理**前后顺序有关**的序列数据？

关键洞察：**当前输入的含义可能依赖之前的信息。**

- "我没有说他偷了钱"——强调不同的词，含义不同；
- 一个代词指向谁，通常依赖前文；
- 一个词的含义可能需要结合几百个 Token 之前的信息。

MLP 每次只看固定输入，没有保存历史的机制。

## 定义

**RNN 是一种维护一个随序列不断更新的隐藏状态，用"当前输入 + 历史状态"生成新状态的深度网络。**

## 核心机制

```text
当前 Token + 上一步隐藏状态
        ↓
     新隐藏状态
        ↓
  传给下一个位置
```

具体例子，模型依次读到"我""喜欢""学习"：

```text
"我"        → 状态 h₁
"喜欢" + h₁ → 状态 h₂
"学习" + h₂ → 状态 h₃
```

要点：

1. 隐藏状态是对此前信息的**压缩摘要**，不是完整记忆；
2. 相同的一组参数在每个时间步重复使用，因此可以处理任意长度的序列。

把隐藏状态理解为"一份随阅读进度更新的摘要"，是理解 RNN 的关键。

## 核心本质

**用一个随序列逐步更新的压缩状态，承载历史信息。**

---

# 3. 本章合论：结构假设

| | CNN | RNN |
|---|---|---|
| 利用的结构 | 空间局部性 | 时间顺序 |
| 核心机制 | 局部连接 + 参数共享 | 隐藏状态逐步更新 |
| 证明的思想 | 面对不同数据，可以通过网络结构加入不同的归纳偏置 | 同左 |

深度学习的通用原理（多层 + 非线性 + 自动特征）不变；CNN 和 RNN 展示的是：**把对数据的理解写进结构，可以大幅提高学习效率。**

---

# 4. 极简总结

**CNN = 共享的局部检测器扫全图（利用空间结构）；RNN = 随序列更新的压缩状态（利用序列结构）；两者共同证明：结构假设让深度网络更高效。**

---

# 5. 遗留的问题

RNN 可以处理序列，但它有三个结构性限制，在序列变长、模型变大时全部恶化：

```text
A → B → C → D → E
```

1. **长距离路径长**：A 的信息要影响 E，必须依次经过 B、C、D 的状态更新。距离越远，路径越长，信息越容易被稀释（训练时表现为梯度消失/爆炸）；
2. **难以并行**：算第 100 个状态必须先算第 99 个，序列维度无法充分并行，训练效率低；
3. **压缩瓶颈**：不断增长的历史要压进固定维度的状态。

LSTM、GRU 改善了记忆和梯度传播，但没有改变"按顺序逐步计算"这个基本路径。

于是核心问题变成：**序列中的一个词，能否不经过层层传递，直接获取其他所有词的信息？**
