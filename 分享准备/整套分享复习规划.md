# **整套分享复习规划**

目标不是重新学习所有细节，而是形成三种能力：

1. 能解释每个阶段解决了什么问题。
2. 能说明为什么会演化到下一阶段。
3. 能用一条完整主线把机器学习、深度学习、Transformer、LLM、Agent 串起来。

最终验收标准：

不看资料，用 30 分钟向一个不了解 AI 的人完整讲清整套演化过程。

---

# **一、总体复习方法**

整套复习分为三轮。

## **第一轮：搭建知识主干**

目标：把每个阶段的核心逻辑想清楚，不深入公式和工程细节。

每个主题只回答五个问题：

```markdown
1. 它要解决什么问题？
2. 之前的方法为什么不够？
3. 它用了什么核心机制？
4. 它获得了什么新能力？
5. 它还有什么限制，为什么会出现下一阶段？
```

这一轮重点是“完整”，不追求特别深入。

## **第二轮：打磨关键机制**

目标：把分享中真正需要解释的关键点讲透。

只深入以下内容：

- 机器学习的训练闭环
- 非线性与多层神经网络
- 特征学习
- CNN 与 RNN 的设计动机
- Self-Attention
- GPT 的自回归预训练
- 指令微调和上下文学习
- Tool Call、ReAct、Agent

其他细节只保证知道定位，不进入分享主线。

## **第三轮：转化成分享表达**

目标：将知识转换成听众能理解的内容。

每个模块都要产出：

- 一句话结论
- 一个直观案例
- 一张核心图
- 一个承上启下的问题
- 三到五分钟口头讲解

# **二、具体复习顺序**

## **阶段一：机器如何从数据中学习**

你已经复习了机器学习概念，但需要补齐一个完整闭环。

### **需要想清楚的问题**

1. 人学习和机器学习有哪些相同与不同？
2. 传统程序和机器学习程序有什么区别？
3. 什么是样本、特征、标签、模型和参数？
4. 什么是预测？
5. 为什么需要损失函数？
6. 参数是如何被调整的？
7. 训练结果好，为什么不代表真实使用效果好？
8. 什么是泛化？
9. 回归与分类有什么本质区别？

### **使用的统一案例**

先使用单参数线性回归：

```text
输入：房屋面积
输出：房屋价格
模型：价格 = 参数 × 面积
```

暂时忽略截距，只保留一个参数，让听众看到机器学习最小闭环：

```text
给定参数
→ 进行预测
→ 计算误差
→ 调整参数
→ 再次预测
```

然后增加分类问题：

```text
根据客户行为，判断客户是否会成交。
```

需要讲清：

回归预测一个连续数值，分类预测不同类别的可能性。

### **本阶段产出**

写出一份不超过 800 字的说明，结构固定为：

```markdown
机器学习是什么
传统程序为什么不够
线性回归如何学习
分类问题有什么不同
什么是泛化
```

### **自测题**

- 为什么机器学习不能简单定义为“从数据中寻找规律”？
- 机器真正学习到的是什么？
- 损失函数和优化算法分别负责什么？
- 训练误差越低越好吗？
- 泛化为什么是机器学习真正的目标？

## **阶段二：机器如何自动学习特征**

核心主题：

从学习参数，演化到同时学习特征表示。

### **复习顺序**

```text
线性模型
→ 非线性问题
→ 激活函数
→ 多层神经网络
→ 层次化特征
→ CNN
→ RNN
```

### **需要想清楚的问题**

1. 线性模型的表达边界是什么？
2. 多个线性层叠加为什么仍然是线性的？
3. 激活函数到底增加了什么？
4. 多层网络为什么比单层网络表达能力更强？
5. 什么叫特征？
6. 什么叫自动学习特征？
7. 深度学习相比传统机器学习改变了什么？
8. CNN 为什么适合图像？
9. RNN 为什么适合序列？
10. CNN 和 RNN 分别加入了什么结构假设？

### **核心结论**

激活函数不要只讲“增加非线性”。

应该讲成：

激活函数让不同输入区域可以经过不同的组合方式处理，使网络能够表示弯曲、分段和复杂的决策边界。

多层网络不要只讲“逐层提取特征”。

应该讲成：

前层把原始输入转换成简单特征，后层继续组合这些特征，最终形成更抽象、更适合任务的表示。

CNN 的核心不是卷积计算本身，而是：

图像中同一种局部模式可能出现在不同位置，因此使用共享的局部检测器更有效。

RNN 的核心是：

当前输入的含义可能依赖之前的信息，因此模型需要保留一个随序列更新的状态。

### **本阶段产出**

制作一张演化图：

```text
人工设计特征
        ↓
神经网络自动学习特征
        ↓
CNN：利用空间结构
RNN：利用序列结构
```

并准备一个三分钟讲解。

### **自测题**

- 没有激活函数，十层网络和一层网络有什么区别？
- 深度学习为什么能减少人工特征工程？
- CNN 为什么不能简单理解为“专门处理图片的神经网络”？
- RNN 的隐藏状态本质是什么？
- CNN、RNN 是否完全不适用于其他数据？

## **阶段三：从 RNN 到 Transformer**

这是整套分享最重要的结构转折。

### **需要想清楚的问题**

1. 序列模型为什么需要上下文？
2. RNN 如何传递上下文？
3. 信息逐步传递有什么问题？
4. 什么是长距离依赖？
5. 为什么 RNN 难以并行？
6. Attention 改变了什么？
7. Self-Attention 中“自”是什么意思？
8. Q、K、V 分别承担什么作用？
9. 为什么不同 token 能获得不同的上下文表示？
10. 多头注意力为什么有意义？
11. Transformer 为什么还需要位置编码？
12. Attention 解决了什么，又没有解决什么？

### **推荐讲解路线**

先给一句话：

RNN 让信息沿序列逐步传递，Transformer 让每个位置直接从整个上下文中获取信息。

然后用一句有歧义的话：

```text
银行旁边有一条河。
我去银行取了钱。
```

说明同一个“银行”，需要根据上下文得到不同表示。

再进入 Attention：

```text
当前词提出问题
→ 与其他词匹配相关性
→ 按相关性汇总信息
→ 得到上下文表示
```

Q、K、V 可以先口语化解释为：

- Q：我当前需要寻找什么信息；
- K：我能提供什么匹配线索；
- V：真正需要被汇总的内容。

### **暂时排除的内容**

第一轮不复习：

- RoPE 数学推导
- FlashAttention 实现
- GQA、MQA
- RMSNorm
- SwiGLU
- Pre-LN 与 Post-LN
- Attention 的矩阵维度推导

这些内容放在第二轮补充定位。

### **本阶段产出**

完成三个版本：

1. 30 秒版本：一句话讲 Transformer。
2. 3 分钟版本：讲清 RNN 到 Attention 的转折。
3. 8 分钟版本：加入 QKV、多头、位置编码。

### **自测题**

- Transformer 为什么比 RNN 更容易并行？
- Attention 为什么能处理长距离关系？
- Q、K 为什么不直接使用原始 token 表示？
- V 为什么不能省略？
- 没有位置编码会发生什么？
- Attention 是否真正理解了语义？

## **阶段四：从 Transformer 到 GPT-1、GPT-2、GPT-3**

这一阶段不要按照论文逐篇复习，而是理解能力如何演化。

### **需要先讲清的基础**

1. 什么是语言模型？
2. 什么是自回归生成？
3. 为什么预测下一个 token 可以学到语言能力？
4. 什么是预训练？
5. 为什么预训练能力可以迁移到下游任务？

### **GPT-1**

核心问题：

能否先通过大量无标注文本学习通用语言表示，再适配具体任务？

需要理解：

- Transformer Decoder
- 自回归预训练
- 下游任务微调
- 预训练加微调范式

一句话：

GPT-1 证明了生成式预训练得到的语言能力，可以迁移到多个下游任务。

### **GPT-2**

核心问题：

是否可以把不同语言任务统一成文本生成，而不是为每个任务单独设计模型？

重点：

- 任务统一成语言建模
- Zero-shot 初步能力
- 更大的数据和模型
- 不再强调每个任务都进行监督微调

一句话：

GPT-2 开始证明，一个统一的语言模型可以通过文本形式处理多种任务。

### **GPT-3**

核心问题：

模型能否不修改参数，只通过上下文中的说明和示例完成新任务？

重点：

- Scaling
- Zero-shot
- One-shot
- Few-shot
- In-context Learning

一句话：

GPT-3 证明了大模型可以把上下文本身当作临时任务说明和学习材料。

### **本阶段主线**

```text
GPT-1：能力可以从预训练迁移
GPT-2：任务可以统一为文本生成
GPT-3：新任务可以通过上下文适配
```

### **本阶段产出**

制作一张三列表：

|**模型**|**关键问题**|**新能力**|
|---|---|---|
|GPT-1|预训练能否迁移|预训练加微调|
|GPT-2|能否统一任务|Zero-shot 生成|
|GPT-3|能否上下文适配|In-context Learning|

### **自测题**

- 预测下一个 token 为什么可能形成通用能力？
- 预训练和微调分别解决什么问题？
- GPT-2 与 GPT-1 的主要变化只是参数变大吗？
- GPT-3 的 Few-shot 与传统机器学习训练有什么不同？
- In-context Learning 是否真的更新了模型参数？

## **阶段五：从 GPT-3 到现代 LLM**

这一阶段不要按产品和公司复习，按能力模块复习。

### **模块一：预训练能力增强**

需要理解：

- 更大和更优质的数据
- 数据清洗与配比
- Scaling Law
- 更长上下文
- 架构和训练稳定性优化

核心结论：

现代 LLM 的基础能力首先仍来自大规模自监督预训练。

### **模块二：指令跟随**

需要理解：

- 预训练模型只预测合理的后续文本；
- 它不天然知道应该服从用户；
- 指令微调将任务描述、输入和理想回答组织成训练样本；
- 模型学会按照指令组织回答。

核心结论：

指令微调不是给模型注入所有知识，而是教模型如何调用已有能力完成用户任务。

### **模块三：偏好对齐**

只需理解：

- 同一个问题存在多种合理回答；
- 人类偏好无法完全写成明确规则；
- 需要使用偏好数据让模型倾向更有帮助、更安全的回答；
- RLHF、DPO 是实现方式。

不需要深入 PPO。

### **模块四：推理能力**

需要区分：

- 模型拥有知识；
- 模型能够调用知识进行多步推理；
- 模型通过生成中间步骤获得更大计算空间；
- 推理模型通过训练和推理时计算增强复杂问题处理能力。

### **模块五：工程效率**

只定位以下概念：

- KV Cache：复用历史计算；
- FlashAttention：提高注意力计算效率；
- GQA：降低 KV Cache 成本；
- MoE：增加模型容量而不让每次计算全部参数；
- 量化：降低推理资源需求。

这部分只做“现代模型为什么能做大、做长、做快”的补充。

### **本阶段产出**

将现代 LLM 总结成五个维度：

```text
基础能力：预训练
交互能力：指令微调
行为约束：偏好对齐
复杂任务：推理训练
可落地性：推理优化
```

### **自测题**

- 现代 LLM 和 GPT-3 的本质架构是否完全不同？
- 预训练模型为什么不一定听从指令？
- 指令微调是否主要增加知识？
- 对齐与能力增强有什么区别？
- 推理能力来自模型参数，还是来自生成过程？
- MoE 为什么可以增大容量但不同比例增加计算量？

## **阶段六：从 LLM 到 Agent**

这一阶段的核心是区分模型和系统。

### **第一步：明确 LLM 的边界**

LLM 的基础运行方式：

```text
接收上下文
→ 预测下一个 token
→ 持续生成
```

它天然不具备：

- 访问实时数据；
- 执行外部操作；
- 长期保存状态；
- 保证复杂任务按步骤完成；
- 验证最终结果。

### **第二步：Streaming**

需要理解：

- Streaming 改善的是用户感知延迟；
- 模型仍然按照 token 顺序生成；
- 它不提升模型能力；
- 它改变的是交互形式。

### **第三步：Tool Call**

需要理解完整闭环：

```text
用户提出任务
→ 模型判断需要工具
→ 输出结构化工具参数
→ 系统执行工具
→ 结果返回模型
→ 模型继续回答
```

关键结论：

模型不直接执行工具，它负责决定调用什么以及生成参数，外部系统负责真正执行。

### **第四步：ReAct**

需要讲清：

```text
观察当前状态
→ 推理下一步
→ 执行动作
→ 获得新结果
→ 再次推理
```

ReAct 的价值：

将一次性生成，变成基于环境反馈不断修正的循环。

### **第五步：规划模式**

需要区分：

- 边想边做；
- 先拆计划再执行；
- 计划可能需要动态调整；
- 规划器和执行器可以由同一个模型或不同模型承担。

### **第六步：Skill**

需要形成明确定位：

Skill 是针对某类任务封装的可复用执行知识，包括步骤、约束、工具和输出规范。

Skill 不是：

- 单纯提示词；
- 外部工具本身；
- 完整 Agent；
- 模型内部新增能力。

### **第七步：MCP**

只需理解：

MCP 统一了模型和外部工具、数据源之间的连接方式。

区分：

- Tool：具体能力；
- MCP：连接工具的协议；
- Skill：使用工具完成任务的方法；
- Agent：组织模型、工具、状态和流程的运行系统。

### **本阶段产出**

制作一张层级图：

```text
LLM
├── 负责理解和生成
│
Agent 系统
├── 状态
├── 循环
├── 规划
├── 工具调用
└── 结果校验

能力封装
├── Skill
└── 工作流

连接协议
└── MCP
```

### **自测题**

- Tool Call 与 Agent 有什么区别？
- Streaming 为什么不代表模型更智能？
- ReAct 和普通多轮对话有什么区别？
- Skill 和提示词有什么区别？
- MCP 与 Tool Call 有什么区别？
- Agent 是否是一种新的模型架构？

# **三、将六个阶段串成一条演化链**

完成分模块复习后，再进行一次跨模块复习。

每一步只回答：

```text
上一阶段把什么交给了机器？
这一阶段又把什么交给了机器？
```

最终应该得到：

|**阶段**|**交给机器的内容**|
|---|---|
|传统机器学习|从数据中寻找参数|
|深度学习|自动学习特征|
|Transformer|自动建立上下文关系|
|GPT|从海量文本中学习通用语言能力|
|现代 LLM|按指令迁移能力并进行复杂推理|
|Agent|根据目标选择行动并使用外部工具|

再进一步压缩：

```text
规则自动化
→ 参数自动化
→ 特征自动化
→ 表示自动化
→ 任务适配自动化
→ 行动自动化
```

这就是整套分享真正的骨架。

3. 哪些地方听众可能不知道为什么突然切到下一阶段？

然后只针对这三类问题补复习。

# **五、每次复习的固定流程**

每次控制在两小时。

## **前 20 分钟：闭卷复述**

不查资料，先写：

```markdown
是什么
解决什么问题
核心机制
带来什么能力
还存在什么限制
```

## **中间 40 分钟：查缺补漏**

只查询刚才无法回答或表达不清的问题。

不要重新从头阅读整篇资料。

## **接下来 30 分钟：压缩表达**

依次输出：

- 100 字版本；
- 300 字版本；
- 三分钟口述版本。

## **接下来 20 分钟：建立连接**

回答：

这个主题为什么出现在上一主题之后，又为什么会引出下一主题？

## **最后 10 分钟：录音复盘**

不看稿讲一次。

复盘只看三个维度：

- 是否准确；
- 是否清晰；
- 是否有冗余。

# **六、最终应该形成的材料**

整套复习结束时，不需要形成大量笔记，只保留四份材料。

## **1. 一页总览图**

展示完整演化链：

```text
机器学习
→ 深度学习
→ Transformer
→ GPT
→ 现代 LLM
→ Agent
```

每一步只写：

- 旧问题；
- 新机制；
- 新能力。

## **2. 六张模块卡片**

每个模块一张：

```markdown
核心问题：
一句话结论：
关键机制：
直观案例：
上一阶段限制：
下一阶段动机：
```

## **3. 一份完整口述稿**

不是逐字稿，而是每页三到五个提示词。

例如：

```markdown
Transformer

- RNN 顺序传递
- 长距离依赖
- 无法并行
- Attention 直接连接
- 上下文动态表示
```

## **4. 一份问题库**

保留你复习过程中真正卡住的问题，例如：

- 多层线性网络为什么仍然是线性？
- Q、K、V 为什么要分开？
- 下一个 token 预测为什么能学到通用能力？
- In-context Learning 为什么不需要更新参数？
- Agent 和普通 Tool Call 有什么边界？

这些问题将决定整场分享是否真正讲透。

# **七、复习过程中的取舍原则**

任何知识点都用下面的问题判断是否进入主分享：

它是否帮助听众理解“为什么会演化到下一阶段”？

应该重点讲：

- 泛化；
- 特征学习；
- 上下文；
- 预训练；
- 迁移；
- 指令适配；
- 工具使用。

应该弱化：

- 数学推导；
- 模型参数量；
- 论文发布时间；
- 具体模型排行榜；
- 训练工程细节；
- 各类架构缩写。

整套复习最终要回答的不是：

AI 技术有哪些？

而是：

**机器是如何一步步减少对人工规则、人工特征和任务专用开发的依赖，逐渐获得通用学习与行动能力的？**
