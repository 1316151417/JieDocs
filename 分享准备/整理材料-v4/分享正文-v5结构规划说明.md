## 一、主题与主线

- **主题**：《从人工规则到 LLM——智能的涌现》
- **主线问题**：机器是怎么一步步拿走人做的东西的？——拿走到哪一步时，「智能」出现了？
- **主线地图**（开场亮出，收尾复现）：

  传统程序（执行）→ 机器学习（找参数）→ 深度学习（学特征）→ Transformer（建上下文）→ LLM（统一任务 + 能力涌现）⇢ Agent（行动）【虚线，后续专场】

  实线五步是本场内容；第六步画成虚线并注明「后续分享」，既收住边界又留出口。
- **每一步的驱动力**：上一阶段交出一项工作后，剩下的瓶颈成为下一阶段的问题——每章的「局限性」字段都用这个句式。

## 二、编写原则

1. 先写分享 md 正文，不考虑 PPT；md 定稿后转 PPT。
2. **统一四模块骨架（章与节同构）**：**问题 → 定义 → 机制 → 局限性**。可视化 / 代码 / 实验不占独立模块，作为机制的附属标注（【可视化】【代码】【实验占位】）。
3. **定义必须可拆解**：定义里的每个关键词都对应本章的一个小节或机制——这是「以定义为核心」的落地检验（见各章「定义拆解」）。
4. 全文公式原则：完整讲的只有 ŷ = w·x + b 一条；Attention 公式允许「认脸」出现，不做推导；**交叉熵在第一章 Softmax 处讲清，第四章只回收**。
5. 术语首次出现给一句白话解释，之后直接使用。
6. **四字段纯度要求**（章节与子模块同此要求）：
   - **问题**：必须是痛点陈述（做不到 / 太贵 / 训不动 / 表达不了），不得写成数据特性或背景描述；
   - **定义**：教科书式清晰定义，不夹带自我理解；必须能回应前面的「问题」，并与后面的「机制」对应（「定义拆解」负责展示对应关系）；
   - **机制**：直给机制，不过多赘述；
   - **局限性**：末字段统一命名为「局限性」——它天然就是下一章（节）的问题，不再叫「交接句 / 去向」。
7. **节级四模块按需使用**：子模块仅当其必要性未被章级问题覆盖时才单列结构（判据：删掉这个问题，模块的登场就没了理由）；已继承问题的模块不套模板。
8. **呈现分层**：规划说明用显式字段；正文不加标签，但位置固定——首句立问题、定义加粗成句、中段机制、尾句局限性。

## 四、章节详细规划

### 〇、现象与主线（4'）

- **现象**：语音识别、图像识别、机器翻译——十年前后对比；再到现在每天在用的问答、写代码、总结文档。
- **立题**：这些能力从哪来？整场沿主线地图走一遍。
- **边界**：不讲工具技巧、模型新闻、数学推导；预告后续两场（工程实战 / Agent）。

### 一、机器学习（12'）

- **问题**：一大类任务人做得出来，规则写不出来（垃圾邮件 / 是不是猫 / 流失预测）。
- **定义**：让机器从数据或经验中学习可泛化的规律，使其在特定任务上的表现不断改善。
- **定义拆解**（关键词 ↔ 小节）：
  - 「数据」→ 组件① 数据
  - 「规律」→ 组件② 模型（规律的载体，参数所在）
  - 「学习」→ 组件③ 损失函数 + ④ 优化算法（衡量差距、按方向调整）
  - 「泛化」→ 泛化与数值稳定
  - 线性回归 / Softmax 回归 = 四组件在具体任务上的两个最小实例
- **机制**：
  1. **★四组件闭环**：数据 → 模型 → 损失函数 → 优化算法；循环图。后文所有模型都在这个闭环里。
  2. **★线性回归**：唯一公式 ŷ = w·x + b；**可视化**＝梯度下降演示（散点 + 拟合线 + 损失曲线，播放/单步/重置）；**代码**＝PyTorch 十行（四组件各占一行）；结论句：学到的是一组让误差变小的数字，不是规则。
  3. **带过：Softmax 回归**：线性分数 → Softmax 归一化成概率分布；**交叉熵在此讲清**——只罚「真实类别的概率不够高」，不展开推导；第四章回收：预训练损失 = 全词表交叉熵。
  4. **★泛化与数值稳定**（压缩讲）：欠拟合 / 过拟合；训练/验证/测试三分；**一句话：参数初始化**（初始值不合适 → 数值过大 → 训练不稳；「第三章 LayerNorm 回收这个主题」）。不做演示，避免注意偏移。
- **局限性**：特征仍由人挑选和设计——图片里「猫」的特征没人写得全，人工特征成为瓶颈。

### 二、深度学习（12'）

- **问题**：现实规律大量是非线性的；世界是层次化表达的。两条缺口，线性模型都过不去（叠线性仍线性的代数式一句带过）。
- **定义**：通过**多层非线性变换**，自动从原始数据中**逐层学习特征表示**的机器学习方法。
- **定义拆解**：
  - 「多层非线性变换」→ MLP（没有非线性的深度是假深度）
  - 「逐层学习特征表示」→ 特征学习（层次化表示，对应世界的层次结构）
- **机制**（2.1 继承章问题、不套节级模板；2.2–2.4 按需使用四模块）：

  **2.1 ★MLP**（继承章问题，不单列结构）
  - **定义**：由多个全连接层与非线性激活函数堆叠而成的前馈神经网络。
  - 机制：激活函数 = 让不同输入区域走不同加工路径；反向传播一句话（前向算值、反向算梯度，框架自动完成）。【可视化】圆 / 螺旋决策边界（Playground 或静态图，「圆不在直线的世界里」）；边界：能表达 ≠ 学得出来。
  - **局限性**：万能但低效——图像上全连接参数爆炸、同一模式每个位置重学；序列上无顺序、无记忆（→ 2.2 与 2.4 的问题来源）。点睛句：效率来自把数据结构写进网络——人设计结构，机器学特征。

  **2.2 带过：CNN**
  - **问题**：MLP 在图像上参数爆炸（1.5 亿 vs 几千）、同一模式每个位置重学——根因是无视图像结构。
  - **定义**：通过局部连接与参数共享（卷积运算）提取空间层次特征的深度神经网络。
  - **机制**：图像的两个先验作抓手——局部性 → 局部连接，平移不变性 → 参数共享；层次特征衔接特征学习。历史路标 LeNet（开山）→ AlexNet（ImageNet + GPU，引爆深度学习）。
  - **局限性**：一味加深 → 梯度消失 / 爆炸，训不动（→ 2.3）；且只适配空间结构，对序列的顺序与上下文无能为力（→ 2.4）。

  **2.3 ★ResNet**
  - **问题**：网络越深越强，但深到二三十层就训不动——**梯度消失 / 梯度爆炸在此正式讲**（梯度经多层逐步衰减或放大）。
  - **定义**：通过恒等捷径让各层学习残差映射 F(x) = H(x) − x 的深度网络架构。
  - **机制**：捷径让信号与梯度绕过变换层直通 → 可堆上百层（「深度学习的『深』，到 ResNet 才真正兑现」）；该机制后被 Transformer 原样沿用（伏笔链 3）。
  - **局限性**：解决的是「能堆深」，不改变对序列的无力——文本的上下文仍没有着落（→ 2.4）。

  **2.4 ★RNN**（本章收尾）
  - **问题**：MLP、CNN 都没有记忆——输入定长、无顺序概念，「当前词依赖前文」进不了模型。
  - **定义**：按序列顺序逐步处理输入、以循环更新的隐藏状态携带历史信息的神经网络。
  - **机制**：随阅读进度更新的「摘要」状态（读到「我」得 h₁，「喜欢」+ h₁ → h₂……）；同一组参数逐步复用，任意长度可处理。
  - **局限性**：三个天花板——长距离路径 O(n)（**回扣 2.3 的梯度消失**）、串行无法并行、固定维度瓶颈。
- **局限性（章级）**：RNN「按顺序逐步传递」的路线本身遇到天花板：远距离、串行、瓶颈（LSTM 缓解其一三，路线未变）——一个词能不能不走接力赛，直接找到它需要的那个词？（→ 第三章）

### 三、Transformer（15'）

- **问题**（承接第二章）：RNN 三问——远距离、并行、瓶颈。
- **定义**：完全基于自注意力机制、摒弃循环与卷积运算的序列建模架构（Vaswani et al., 2017，《Attention Is All You Need》）。
- **定义拆解**：
  - 「完全基于自注意力」→ 注意力机制（正/余弦直觉 → QKV）
  - 「摒弃循环」→ 直接回应 RNN 三问：路径长度 1、全并行、不压缩
  - 「序列建模」→ 文本进出模型：分词与向量化
  - 「架构（可堆叠）」→ 使其可训练、可堆叠的配套部件：位置编码、残差（回扣 ResNet）、LayerNorm（回扣数值稳定）→ 组装 Decoder Block
- **机制**：
  1. **★原始注意力直觉（正 / 余弦数值预测例子）**：只讲一个概念——加权平均，权重由相关性计算；全程不用矩阵记号、不提 QKV。桥接句：「刚才的权重由位置规则决定——如果权重不由规则定，而由模型根据内容自己学出来呢？」
  2. **★★文本注意力 QKV（全场重点）**：银行两句例句（含义在关系里）；Q（寻找）/ K（线索）/ V（内容）三职责；信息流 + 公式认脸 softmax(QKᵀ/√d)·V；**可视化**＝注意力热力图；多头一句话（多组视角并行，头 ≠ 人类概念）；误解澄清（Q/K/V 是训练出的向量，不是问题、主键、答案）。
  3. **带过：位置编码**：狗咬人 ≠ 人咬狗；RoPE 一句话（感知相对位置）。
  4. **带过：残差连接**：**回扣 ResNet**——同一个机制搬进 Transformer。
  5. **带过：LayerNorm**：**回扣第一章「数值稳定 / 初始化」**——让数值待在稳定区间，深层可训。
  6. **带过：分词与向量化**：文本 → Token（离散单元，不总等于词）→ ID → 查表得向量；不提 BPE 细节。
  7. **带过：组装 Decoder Block**：注意力（通信）+ FFN（加工）+ 残差 + Norm，堆几十上百层 = GPT / LLaMA 骨架；分工记法一句。
- **局限性**：参数全是随机数，一个字都不认识——架构 ≠ 能力，能力来源未解（→ 第四章）。

### 四、LLM（14'）

- **问题链（三问，开场即立）**：
  1. 监督学习需要标注，互联网有的是无标注文本——怎么用？
  2. NLP 任务千千万，每个任务训一个模型吗？
  3. 模型不断变大，会发生什么？
- **定义**：在互联网规模文本上，以「预测下一个 Token」为统一目标进行**自监督预训练**得到的大规模语言模型；通常再经**监督微调**与**偏好对齐**适配为助手。
- **定义拆解**：
  - 「自监督 + 预测下一个 Token」→ 预训练机制（文本自带答案、因果掩码、交叉熵回收）
  - 「互联网规模」→ GPT 三步与规模涌现（对应问题三）
  - 「监督微调」→ SFT
  - 「偏好对齐」→ 偏好排序 → 奖励模型 → RLHF / DPO
  - （配套）行为塑造的低成本实现 → LoRA；行为延伸 → Tool call / 思维链各一句
- **机制**：
  1. **★预训练**：文本自带答案（左移一位 = 全部位置的练习题，零标注）；**因果掩码在此讲**（防偷看 + 不牺牲并行；生成侧天然从左到右——「一石二鸟」）；损失 = 全词表交叉熵（**回收第一章，不再重讲**）。**实验占位**＝llama.c 预训练实录（内容待设计）。
  2. **★GPT 三步**：三步各有质变点——GPT-1 预训练+微调范式（能力可迁移）；GPT-2 任务统一成续写（去微调）；GPT-3 上下文学习（任务写在提示词里）。叙事框架「量变引起质变」可用，但要点明每步的质变不同，不能简化成「只是变大」。
  3. **★SFT**：会续写 ≠ 会当助手（缓存击穿续写例子）；数据分布换、目标不变；教行为不注知识。**实验占位**＝基座 vs 微调对比（内容待设计）。
  4. **带过：偏好对齐（一条线讲）**：偏好排序 → 奖励模型 → RLHF；DPO 一句话（跳过 RM 直接从偏好对学）；实证 13B InstructGPT 偏好 > 175B GPT-3；边界：对齐管倾向不管真值。
  5. **★LoRA + 实验**（节级四模块·**问题**：全参数微调太贵 / **定义**：冻结预训练权重，仅训练注入的低秩增量矩阵 / **局限性**：适合行为与领域适配，不适合灌知识）：机制＝冻结原参数、只训低秩增量；三段训练的成本特性对比（预训练：数据量最大 / 耗时最长 / 成本高；SFT：中等；LoRA：小 / 短 / 低，消费级显卡可做）；**实验占位**＝私有数据适配对比（内容待设计）。实验要支撑的结论：预训练给能力，后训练给行为——两个独立旋钮。
  6. **带过：训练 vs 推理（极简半页）**：对比表（答案 / 损失反传 / 产出）；逐 Token 生成三行伪代码；采样一句话（温度管风格不管对错）。不做「困惑解答」式包装。
  7. **一句话：延伸能力**：Tool call、思维链 = 后训练带来的行为延伸，机制展开留待后续专场。
- **局限性**：参数冻结、逐 Token 生成，只能输出文本——实时信息、长期记忆、真实执行都在模型之外（→ Agent 专场）。

### 收尾（3'）

- 主线复现：五步实线 + 虚线 Agent，每步一句承重句。
- 收尾句（回扣主题）：今天的大模型，底层仍然在预测下一个 Token——让人惊讶的不是目标多简单，而是结构、数据和规模足够大之后，为了做好这件小事，机器长出了我们称之为「智能」的行为。
- 两场预告：工程实战（PyTorch / llama.c / SFT-LoRA 全过程）；Agent（Tool Call / ReAct / LangChain / LangGraph）。

## 八、决策记录（讨论结论存档）

1. 第四章问题链收敛为三问：标注数据哪来 / 任务是否统一 / 变大会怎样。「图像还是文本」的路线之争只作一句背景，不当主问题。
2. GPT 三步 ≠ 单纯量变：各有质变点（能力迁移 / 任务统一 / 上下文学习），叙事用「量变引起质变」但须点明每步质变不同。
3. 第四章内容层次：偏好学习与强化学习合并为一条线（RLHF）；LoRA 定位为「低成本适配」，关联实验；Tool call / 思维链各一句。
4. 参数初始化：一句话带过，不做演示（避免注意偏移），挂在「泛化与数值稳定」小节。
5. 训练 vs 推理：保留极简版（表 + 伪代码 + 采样一句）。
6. 梯度消失 / 爆炸：主场放在第二章 CNN 的 ResNet 处（重要），RNN 与 Transformer 残差做回扣。
7. Agent 完全移除，后续单独成场（Tool Call / ReAct / LangChain / LangGraph）。
8. 交叉熵在第一章 Softmax 处讲清（概念讲透、不推导），第四章只做回收，不再当伏笔延后。
9. 四章定义全部采用「可拆解定义」：定义关键词与小节一一对应（机器学习采用「让机器从数据或经验中学习可泛化的规律，使其在特定任务上的表现不断改善」）。
10. 实验内容暂不展开描述，一律以【实验占位】标记，待设计后再补。
11. 深度学习定义收干净（多层非线性 + 逐层特征表示，教科书式充分必要定义）；「结构适配数据」的洞察保留，落在 2.1 局限 → CNN 的过渡处（点睛句：人设计结构、机器学特征），并作为暗线贯穿到第三章 Transformer。
12. 节级三拍（问题 → 方案 → 去向）按需使用：判据 = 子模块的必要性未被章级问题覆盖才单独立问题；呈现分层——规划显式字段、正文隐性同序（首句立问题、尾句交去向）。
13. ResNet 从 CNN 拆出独立成节（2.3）：CNN 保持快速带过（LeNet/AlexNet 路标），ResNet 承载梯度消失/爆炸主场与残差伏笔；MLP 的局限（图像参数爆炸 / 序列无记忆）作为 CNN、RNN 登场的问题来源。
14. 结构统一：章与节同用四模块（问题 / 定义 / 机制 / 局限性），取代「六拍 + 三拍」双轨。字段纯度：问题 = 痛点陈述（不得写成数据特性）；定义 = 教科书式，且与问题、机制双向对应；末字段统一命名「局限性」；原「交接句 / 去向」并入「局限性」。
