## 一、主题与主线

- **主题**：《从人工规则到 LLM——智能的涌现》
- **主线问题**：机器是怎么一步步拿走人做的东西的？——拿走到哪一步时，「智能」出现了？
- **主线地图**（开场亮出，收尾复现）：

  传统程序（执行）→ 机器学习（找参数）→ 深度学习（学特征）→ Transformer（建上下文）→ LLM（统一任务 + 能力涌现）⇢ Agent（行动）【虚线，后续专场】

  实线五步是本场内容；第六步画成虚线并注明「后续分享」，既收住边界又留出口。
- **每一步的驱动力**：上一阶段交出一项工作后，剩下的瓶颈成为下一阶段的问题——每章结尾的交接句都用这个句式。

## 二、编写原则

1. 先写分享 md 正文，不考虑 PPT；md 定稿后转 PPT。
2. 每章固定六拍，顺序不变：
   ① 以问题出发 → ② 以定义为核心 → ③ 由定义带出机制与内容 → ④ 可视化（帮助理解）→ ⑤ 代码（若有，给程序员熟悉感）→ ⑥ 实验（若有，作为证据）。
3. **定义必须可拆解**：定义里的每个关键词都对应本章的一个小节或机制——这是「以定义为核心」的落地检验（见各章「定义拆解」）。
4. 全文公式原则：完整讲的只有 ŷ = w·x + b 一条；Attention 公式允许「认脸」出现，不做推导；**交叉熵在第一章 Softmax 处讲清，第四章只回收**。
5. 术语首次出现给一句白话解释，之后直接使用。
6. 每章末尾必须有交接句（= 下一章的问题）。

## 四、章节详细规划

### 〇、现象与主线（4'）

- **现象**：语音识别、图像识别、机器翻译——十年前后对比；再到现在每天在用的问答、写代码、总结文档。
- **立题**：这些能力从哪来？整场沿主线地图走一遍。
- **边界**：不讲工具技巧、模型新闻、数学推导；预告后续两场（工程实战 / Agent）。

### 一、机器学习（12'）

- **问题**：一大类任务人做得出来，规则写不出来（垃圾邮件 / 是不是猫 / 流失预测）。
- **定义**：让机器从数据或经验中学习可泛化的规律，使其在特定任务上的表现不断改善。
- **定义拆解**（关键词 ↔ 小节）：
  - 「数据」→ 组件① 数据
  - 「规律」→ 组件② 模型（规律的载体，参数所在）
  - 「学习」→ 组件③ 损失函数 + ④ 优化算法（衡量差距、按方向调整）
  - 「泛化」→ 泛化与数值稳定
  - 线性回归 / Softmax 回归 = 四组件在具体任务上的两个最小实例
- **内容**：
  1. **★四组件闭环**：数据 → 模型 → 损失函数 → 优化算法；循环图。后文所有模型都在这个闭环里。
  2. **★线性回归**：唯一公式 ŷ = w·x + b；**可视化**＝梯度下降演示（散点 + 拟合线 + 损失曲线，播放/单步/重置）；**代码**＝PyTorch 十行（四组件各占一行）；结论句：学到的是一组让误差变小的数字，不是规则。
  3. **带过：Softmax 回归**：线性分数 → Softmax 归一化成概率分布；**交叉熵在此讲清**——只罚「真实类别的概率不够高」，不展开推导；第四章回收：预训练损失 = 全词表交叉熵。
  4. **★泛化与数值稳定**（压缩讲）：欠拟合 / 过拟合；训练/验证/测试三分；**一句话：参数初始化**（初始值不合适 → 数值过大 → 训练不稳；「第三章 LayerNorm 回收这个主题」）。不做演示，避免注意偏移。
- **交接句**：例子里「面积」是人挑的特征——图片里「猫」的特征没人写得全。

### 二、深度学习（12'）

- **问题**：现实规律大量是非线性的；世界是层次化表达的。两条缺口，线性模型都过不去（叠线性仍线性的代数式一句带过）。
- **定义**：通过**多层非线性变换**自动从原始数据中**逐层学习特征表示**，并**针对数据结构设计网络架构**。
- **定义拆解**：
  - 「多层非线性变换」→ MLP（没有非线性的深度是假深度）
  - 「逐层学习特征表示」→ 特征学习（层次化表示，对应世界的层次结构）
  - 「针对数据结构设计架构」→ CNN（空间局部性）/ RNN（时间顺序）
- **内容**：
  1. **★MLP**：激活函数 = 让不同输入区域走不同加工路径；**可视化**＝圆 / 螺旋决策边界（Playground 或静态图，「圆不在直线的世界里」）；反向传播一句话（前向算值、反向算梯度，框架自动完成）；边界：能表达 ≠ 学得出来。
  2. **带过：CNN**（快讲，列三个代表网络）：
     - LeNet——开山（卷积+池化的原型）
     - AlexNet——引爆深度学习（ImageNet + GPU）
     - **ResNet——把网络做深：★在这里正式讲梯度消失 / 梯度爆炸**（深层网络梯度逐层衰减或放大 → 太深训不动；残差连接让梯度有直通通路 → 可以堆上百层）。此处是梯度问题的主场，为第三章残差埋伏笔。
     - 卷积三件套（局部连接、参数共享、层次特征）一句话各带过。
  3. **★RNN**（本章收尾）：随阅读进度更新的「摘要」状态；三个天花板——长距离路径 O(n)（**回扣 ResNet 处的梯度消失**）、串行无法并行、固定维度瓶颈。
- **交接句**：一个词，能不能不走接力赛，直接找到它需要的那个词？

### 三、Transformer（15'）

- **问题**（承接第二章）：RNN 三问——远距离、并行、瓶颈。
- **定义**：**完全以注意力取代循环与卷积**的序列架构——每个位置按内容与全序列直接建立信息连接，辅以位置编码、残差与归一化，使注意力可以深层堆叠。
- **定义拆解**：
  - 「完全以注意力取代循环」→ 注意力机制（正/余弦直觉 → QKV），直接回应 RNN 三问
  - 「按内容直接连接」→ 权重由内容学出：路径长度 1、可并行
  - 「位置编码」→ 顺序信息（注意力本身不看顺序）
  - 「残差与归一化」→ 深层可训（回扣 ResNet / 数值稳定）
  - 「序列架构」→ 文本进出模型：分词与向量化
- **内容**：
  1. **★原始注意力直觉（正 / 余弦数值预测例子）**：只讲一个概念——加权平均，权重由相关性计算；全程不用矩阵记号、不提 QKV。桥接句：「刚才的权重由位置规则决定——如果权重不由规则定，而由模型根据内容自己学出来呢？」
  2. **★★文本注意力 QKV（全场重点）**：银行两句例句（含义在关系里）；Q（寻找）/ K（线索）/ V（内容）三职责；信息流 + 公式认脸 softmax(QKᵀ/√d)·V；**可视化**＝注意力热力图；多头一句话（多组视角并行，头 ≠ 人类概念）；误解澄清（Q/K/V 是训练出的向量，不是问题、主键、答案）。
  3. **带过：位置编码**：狗咬人 ≠ 人咬狗；RoPE 一句话（感知相对位置）。
  4. **带过：残差连接**：**回扣 ResNet**——同一个机制搬进 Transformer。
  5. **带过：LayerNorm**：**回扣第一章「数值稳定 / 初始化」**——让数值待在稳定区间，深层可训。
  6. **带过：分词与向量化**：文本 → Token（离散单元，不总等于词）→ ID → 查表得向量；不提 BPE 细节。
  7. **带过：组装 Decoder Block**：注意力（通信）+ FFN（加工）+ 残差 + Norm，堆几十上百层 = GPT / LLaMA 骨架；分工记法一句。
- **交接句**：此刻参数全是随机数，一个字都不认识——架构 ≠ 能力，能力从哪来？

### 四、LLM（14'）

- **问题链（三问，开场即立）**：
  1. 监督学习需要标注，互联网有的是无标注文本——怎么用？
  2. NLP 任务千千万，每个任务训一个模型吗？
  3. 模型不断变大，会发生什么？
- **定义**：在互联网规模文本上，以「预测下一个 Token」为统一目标做**自监督预训练**，随参数、数据与算力扩大**涌现**通用语言能力，再经**监督微调**与**偏好对齐**塑造助手行为。
- **定义拆解**：
  - 「自监督 + 预测下一个 Token」→ 预训练机制（文本自带答案、因果掩码、交叉熵回收）
  - 「扩大 + 涌现」→ GPT 三步（量变到质变）
  - 「监督微调」→ SFT
  - 「偏好对齐」→ 偏好排序 → 奖励模型 → RLHF / DPO
  - 行为塑造的低成本实现 → LoRA；行为延伸 → Tool call / 思维链各一句
- **内容**：
  1. **★预训练**：文本自带答案（左移一位 = 全部位置的练习题，零标注）；**因果掩码在此讲**（防偷看 + 不牺牲并行；生成侧天然从左到右——「一石二鸟」）；损失 = 全词表交叉熵（**回收第一章，不再重讲**）。**实验占位**＝llama.c 预训练实录（内容待设计）。
  2. **★GPT 三步**：三步各有质变点——GPT-1 预训练+微调范式（能力可迁移）；GPT-2 任务统一成续写（去微调）；GPT-3 上下文学习（任务写在提示词里）。叙事框架「量变引起质变」可用，但要点明每步的质变不同，不能简化成「只是变大」。
  3. **★SFT**：会续写 ≠ 会当助手（缓存击穿续写例子）；数据分布换、目标不变；教行为不注知识。**实验占位**＝基座 vs 微调对比（内容待设计）。
  4. **带过：偏好对齐（一条线讲）**：偏好排序 → 奖励模型 → RLHF；DPO 一句话（跳过 RM 直接从偏好对学）；实证 13B InstructGPT 偏好 > 175B GPT-3；边界：对齐管倾向不管真值。
  5. **★LoRA + 实验**：冻结原参数、只训低秩增量；三段训练的成本特性对比（预训练：数据量最大 / 耗时最长 / 成本高；SFT：中等；LoRA：小 / 短 / 低，消费级显卡可做）；**实验占位**＝私有数据适配对比（内容待设计）。实验要支撑的结论：预训练给能力，后训练给行为——两个独立旋钮。
  6. **带过：训练 vs 推理（极简半页）**：对比表（答案 / 损失反传 / 产出）；逐 Token 生成三行伪代码；采样一句话（温度管风格不管对错）。不做「困惑解答」式包装。
  7. **一句话：延伸能力**：Tool call、思维链 = 后训练带来的行为延伸，机制展开留待后续专场。
- **交接句**：无（进入收尾）。
