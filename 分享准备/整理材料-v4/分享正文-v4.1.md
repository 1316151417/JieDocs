# 它只会预测下一个 Token——大模型能力的来源与边界

## 〇、问题与主线

语音识别、图像识别、机器翻译，十年前做不好，现在随手可用。再到每天在用的问答、写代码、总结文档。往下追问一层：

- 模型的知识从哪来？
- 为什么它看得懂上下文？
- 它为什么听指令，而不是自顾自地说话？
- 按下回车之后，那段回答怎么出来的？

整场沿一条主线回答：**机器是怎么一步步把人做的东西拿走的。**

| 阶段          | 机器拿走了什么       |
| ----------- | ------------- |
| 传统程序        | 执行（人写规则，机器照办） |
| 机器学习        | 找参数           |
| 深度学习        | 设计特征          |
| Transformer | 上下文建模         |
| GPT 与后训练    | 任务适配          |
| Agent       | 行动选择          |

每一步的驱动力相同：上一阶段交出一项工作后，剩下的瓶颈成为下一阶段的问题。

边界：讲原理与判断方法，不讲工具技巧、模型新闻、数学推导；公式只有一条。

## 一、机器学习

### 1.1 写不出来的规则

传统程序：规则 + 输入 → 输出。规则写得清的问题（订单计价），传统程序就是最好的方案，无可替代。

但有一大类任务，人做得出来，规则写不出来：判断垃圾邮件、识别图片里的猫、预测客户流失。写出几百条规则，照样冲突、漏网、过时。人做得出来，说不清楚自己是怎么做的。

机器学习换一种分工：人提供数据、模型形式、目标；机器在约束里找参数。不是「机器自动发现一切」。

### 1.2 四个零件

1. **数据**：经验来源，如（面积, 价格）样本集
2. **模型**：承载规律的结构，含待调参数，如 ŷ = w·x + b
3. **损失函数**：衡量当前参数多差，如误差平方
4. **优化算法**：沿损失变小的方向调参数

循环：预测 → 算误差 → 调参数 → 再预测。后面所有模型都在这个闭环里，变的只是四个零件装的东西。

### 1.3 线性回归

全文唯一的公式：预测价格 ŷ = w × 面积 + b。

初始 w、b 随机。预测 100 平 = 100 万，真实 300 万——知道参数不对，也知道差多少。汇总误差得损失；优化算法朝损失变小的方向微调；循环几十轮，直线贴合数据。

**机器学到的是一组让误差变小的数字，不是人类可读的规律。**适用于所有模型，包括最大的那个。

```python
import torch
model = torch.nn.Linear(1, 1)                        # 模型：ŷ = w·x + b
opt   = torch.optim.SGD(model.parameters(), lr=0.1)  # 优化器
for x, y in loader:                                  # 数据
    loss = ((model(x) - y) ** 2).mean()              # 损失
    opt.zero_grad(); loss.backward(); opt.step()     # 反向传播 + 更新
```

实际运行：损失从 ~20 降到 <0.2，几十步收敛。四个零件各占一行。

### 1.4 Softmax 回归

分类任务：线性算各类别分数（logits），指数归一化成概率分布——猫 0.78、狗 0.21、鸟 0.01，总和为 1。损失用交叉熵，把真实类别的概率越推越高。

大模型的输出层，就是以全词表（五万多个候选）为类别的 Softmax 回归。

### 1.5 泛化

目标是新数据上依然准，不是训练数据上误差低。训练误差低有两种可能：学到可迁移的规律；或容量过大，把数据连同噪声背下来（过拟合）。模型太弱、训练不够，连训练数据都拟合不好（欠拟合）。

纪律：训练集调参数、验证集选方案、测试集估真实表现；评估只看新数据。

瓶颈：例子里「面积」是人挑的。图片里「猫」的特征没人写得全——人工特征成了新瓶颈。

## 二、深度学习

### 2.1 两条缺口

一，世界大量规律是非线性的：一类数据包围另一类、螺旋缠绕，直线分不开。多叠几层线性也不行——W₂(W₁x+b₁)+b₂ = W′x+b′，叠十层等于一层。

二，世界是层次化表达的：像素→边缘→纹理→部件→物体。线性回归把所有细节压在一层加权求和上，不符合层次结构的高效组织。

### 2.2 MLP

配方：多个线性层，层间夹非线性激活（如 ReLU：负数归零、正数保留）。有了非线性折叠，各层无法合并成一次线性，才能表示弯曲的、分段的边界。

激活函数的作用：**让不同输入区域走不同的加工路径。**每个隐藏神经元是一条直线分割，后层把分割组合起来，围出任意形状的区域。

反向传播一句话：前向算值，反向用链式法则把损失对每个参数的梯度逐层算回来，照旧梯度下降更新。工程上框架自动完成。

深度学习把「设计特征」交给机器：前层学简单模式，后层组合成抽象概念。「深」就是逐层组合——这是与传统机器学习的分界线。训练闭环本身没变。

边界：**能表达 ≠ 学得出来。**换初始化、换学习率可能训崩。

### 2.3 圆与螺旋

Playground 实验：蓝点居中、橙点在外围。

无隐藏层：无论训练多久只能画直线——它的表达形式里不存在圆形边界，直尺画不了圆。加一层隐藏层 + 激活：每个神经元学一条直线分割，后层组合，边界变圆。**加隐藏层之前，圆不在它的世界里；加了之后，圆成了可组合的结果。**

两股螺旋要更深、更宽才能盘进去。

### 2.4 CNN

深度学习的第一个黄金时代（2012 年起）属于图像，主角是 CNN。利用图像的两个结构先验，在 MLP 上做结构优化：

- 局部相关性：有意义的模式由相邻像素构成 → 局部连接
- 平移不变性：左上角和右下角的同一种边缘是同一模式 → 参数共享（同一组卷积核权重扫全图）

参数量：224×224 输入，全连接第一层约 1.5 亿，卷积只要几千，相差约三万倍。层层堆叠自然形成「边缘→纹理→部件→物体」的层次特征。

它在这里只证明一件事：把对数据的理解写进结构，能大幅提升学习效率。

## 三、大模型：训练出能力，推理出回答

### 3.1 文本难在哪

「我没有说他偷了钱」——重音落在不同字上，意思不同。代词指谁看前文；一个词的含义可能取决于几百字前的伏笔。处理序列必须记住前文，MLP 没有记忆。

RNN：维护一份随阅读进度更新的摘要。读到「我」得到 h₁，「喜欢」+ h₁ → h₂，以此类推。同一组参数逐步复用，任意长度可处理。LSTM 是它的著名改良。

### 3.2 RNN 的三个天花板

1. **长距离路径 O(n)**：第 1 个词影响第 100 个词，要穿过中间每次状态更新，越远损耗越大——训练上是梯度消失，使用上是「前面说的后面忘了」
2. **串行**：算第 100 个状态必须等第 99 个——大模型最需要的是大规模并行训练
3. **固定瓶颈**：十个词和一万个词都压进同一个固定长度向量

LSTM 缓解一和三，「按顺序逐步计算」没变。问题升级成：**一个词，能不能不走接力赛，直接找到它需要的那个词？**

### 3.3 注意力

「银行旁边有一条河」→ 河岸；「我去银行取了钱」→ 金融机构。查字典区分不了——**词的含义不在词本身，在它和上下文的关系里。**注意力热力图上能看到：第一句「银行」的权重大量落在「河」，第二句大量落在「取了钱」。

Attention：按内容相关程度动态加权汇总——相关的多取，不相关的少取。任意两词路径长度 1、全并行、不压缩历史，三个天花板同时解决。

工程实现用三个可学习的投影，职责分开：

- **Q（Query）**：我在找什么信息
- **K（Key）**：我能提供什么匹配线索
- **V（Value）**：匹配之后真正递过来的内容

每个位置拿自己的 Q 和所有位置的 K 算匹配分，归一化成权重，按权重汇总 V。公式：Attention(Q,K,V) = softmax(QKᵀ/√d)·V。Q/K/V 都是训练出来的向量，不是人写的问题和关键词。

### 3.4 Transformer 与因果掩码

Decoder Block 的四个部件：

- 注意力：跨位置通信（唯一的跨位置信息交换）
- FFN：位置内加工，模型大部分容量在这里
- 残差连接：信息只增不减，深层训得动
- Norm：稳住数值尺度，深层不发散

分工记法：**注意力管通信，FFN 管加工。**这样的块堆几十上百层，就是 GPT、LLaMA 的骨架。

因果掩码：训练「预测下一个词」不能偷看答案。第 t 个位置只能看第 1 到第 t 个词，未来位置的匹配分数加 −∞，softmax 后归零。一石二鸟：

- 训练时：整段文本已知，所有位置在一次前向里并行练习「只看过去预测下一个」——防偷看，不牺牲并行
- 生成时：本来就只有过去——天然从左到右续写，写一个、追加一个

此刻参数仍是随机数，架构 ≠ 能力。

### 3.5 文本怎么进出模型

输入侧：字符串 → Tokenizer 切成 Token（可能是整词、词片段、汉字、字节，不总等于词）→ 映射成整数 ID → Embedding 查表得向量。同一个「银行」初始向量相同，含义分化发生在后面几十层注意力的加工里。Tokenizer 不理解语义，只是映射规则。

输出侧：最后位置的向量 → 输出层 → 全词表 logits → Softmax → 概率分布。这就是 1.4 的 Softmax 回归，类别换成全词表。**一次前向只输出下一个 Token 的分布，不输出整句话。**

### 3.6 预训练

监督信号哪来？文本自己就是答案。一句训练语料「机器学习可以从数据中学习参数」左移一位，得到所有位置的练习题：「机器 → 学习」「机器 学习 → 可以」……零人工标注。

把整个互联网的文本这样喂进去，反复预测下一个 Token、错了调参数——预训练。GPT 路线三步：GPT-1 证明预训练能力可迁移；GPT-2 证明任务可统一成续写；GPT-3 证明新任务不用训练、任务写在上下文里。合起来：任务接口在统一——每个任务训一个模型 → 一个模型，任务写在提示词里。

### 3.7 能力从哪来

实验：补完「如果数据库连接池已经耗尽，那么新的请求通常会——」。排队、超时、被拒绝。补得出来，是因为懂连接池。

在互联网文本上预测准下一个词，光背词频不够：语法、指代、事实关联、代码结构、推导步骤都能降误差，于是被一起压进参数。**能力是优化这个目标的副产品，不是设计出来的。**

两条边界：

- **模型不是数据库**：知识分布式压在参数里，不是可查、可溯源的记录——「参数里有但说不准」「流畅但不对」
- **数据决定上限**：没有的、过时的、矛盾的，要么不会要么瞎编；知识有截止时间

### 3.8 预训练实录

用 llama.c 从零跑过一次小规模预训练：初始化时输出纯乱码；训练几小时后 loss 持续下降，输出从乱码变成局部通顺的词组，再到成段合理的文本。所谓能力，就是损失降下来的过程。（附图：训练曲线与各阶段生成样本）

训练是工程：学习率、稳定性、数据配比，任何一环不对都可能训崩——呼应 2.2 的边界。

### 3.9 SFT

基座模型的行为：输入「请用三句话解释缓存击穿」，它续写出另一个相似的问题，或把这句当网页标题往下编。因为训练数据里「问题后面还是问题」——它学的是「什么文本可能接着出现」，没人教它「看到请求要像助手回答」。**会续写 ≠ 会当助手；能力是预训练给的，行为要有人教。**

SFT：用「指令 + 人写的理想回答」继续训练。底层没变，仍是预测下一个 Token，变的只是数据分布——从全网文本换成高质量问答。行为随分布改变：识别任务、遵守格式、控制篇幅、助手身份。工程细节：只在回答 Token 上计算损失，指令部分屏蔽。

类比：预训练是读十年书，SFT 是上岗前一周的示范培训。**SFT 教行为，不注知识。**

### 3.10 SFT + LoRA 实验

对比一（指令遵循）：同一个问题。基座输出「续写体」——重复问题、生成一堆没人要的相关内容；微调后按指令回答：定义、机制、边界，格式稳定。行为变了，知识没变多。

对比二（私有数据）：问只存在于内部资料里的问题。基座不知道，或编一个像模像样的错误答案；微调后能正确回答。（附图：两组对比截图）

LoRA：冻结原参数，只额外训练一小块低秩增量矩阵，训练量降几个数量级，消费级显卡可做。预训练给能力、后训练给行为——两个独立的旋钮，这里拧的是后面那个。

### 3.11 偏好对齐

SFT 之后的问题：几个回答都「对」但质量不同——准但啰嗦、简洁但漏边界、自信但没验证。「哪种更好」写不成规则，改成人做选择题：同一问题出四个回答，人排序。做比较比写答案容易十倍，可规模化。

几十万条排序训一个奖励模型（替人打分），再用强化学习让高分回答更常出现——RLHF；DPO 简化成直接从偏好对学习。实证：130 亿参数的 InstructGPT，人类偏好评分超过 1750 亿参数的原始 GPT-3——能力大小和行为是否合意图是两个独立维度。

边界：奖励模型只是偏好的近似，可能被钻空子；人更偏好 ≠ 更真实。**对齐管倾向，不管真值。**

### 3.12 推理：只做前向

| | 训练 | 推理 |
|---|---|---|
| 正确答案 | 有 | 没有 |
| 算损失、调参数 | 是 | 否 |
| 产出 | 一组参数 | 下一个 Token |

**使用阶段，参数是冻结的。**

推理的前向和训练的前向一模一样：Token → Embedding → 几十层 Block → logits → 概率分布。区别在下一步：训练拿预测比答案、反传、更新参数；推理只挑出下一个 Token。同一架构，训练带答案学习，推理不带答案作答。

两个阶段：Prefill 并行处理全部输入上下文（首字延迟主要在这）；Decode 逐个生成，下一个依赖上一个，只能顺序——因果掩码的兑现：训练并行、生成顺序。

### 3.13 生成循环与采样

```
while 没结束:
    算出全词表每个 Token 的概率
    按概率挑一个，追加到上下文末尾，再来
```

整段回答是一次一个 Token 循环出来的，不是先打好草稿再逐字念。

采样策略：

- 贪心：永远选最高分。稳定，但呆板、易重复
- 温度：logits 先除以 T 再 Softmax。T→0 退化成贪心；T=1 原生分布；T>1 抹平差距，更发散
- Top-k：只在概率最高的 k 个候选里采样，截断长尾
- Top-p：只保留累计概率达阈值（如 0.9）的最小候选集，候选数随分布自适应伸缩

两条边界：**采样参数管选词风格，不注入知识**——top-1 本身是错的，低温只会更稳定地错；流式输出只是把已生成的 Token 尽早推给你，不是「边想边说」。

### 3.14 推理优化：KV Cache 与量化

生成第 500 个 Token 时，前 499 个 Token 的 K、V 和上一步完全相同。KV Cache：把历史 K/V 缓存起来，每步只算新位置的 QKV，再与整段缓存做注意力。缓存只增不改——自回归生成的关键效率机制。

代价在显存：缓存随上下文长度线性膨胀。实算：7B 模型（32 层 × 32 头 × 每头 128 维，FP16）每 Token 约 0.5 MB——4K 上下文约 2 GB，32K 约 16 GB，比模型权重还大。推理优化大多围绕它：

- **KV Cache 量化**：FP16 → INT8 / INT4，缓存显存减半或降到四分之一，精度损失很小
- **GQA**：多组 Q 共享少量 KV 头，从模型结构上减小缓存（现代模型标配）
- 权重量化（7B：FP16 的 14 GB → INT4 的 3.5 GB）、算子融合、连续批处理

这些优化改变成本与速度，不改变模型的任何能力。

### 3.15 三个日常困惑，作答

1. **为什么新开对话它就忘了？**使用阶段参数冻结。你教的只活在当前上下文里，对话一关就没了——没有进入模型的脑子，只是出现在模型的眼前。产品的「记忆」功能是外部存储做的。
2. **流式输出是不是边想边说？**不是。逐 Token 生成是结构属性；采样参数只管风格，救不了知识错误。
3. **为什么会一本正经地胡说？**优化目标是「什么话最可能出现」，从头到尾没有环节验证事实（来源即 3.7 两条边界）。治标：给上下文、接检索（RAG）、接工具、要引用、关键输出加校验——让它基于给定材料说话。

最后一个边界：模型能生成查询语句、邮件正文，但不能真的查监控、发邮件、确认结果。**它只能输出文本——LLM 是生成器，不是执行器。**

## 四、Agent

### 4.1 Tool Call

消息流看一遍就懂：

```
用户：      查一下 order-api 最近 30 分钟的异常指标
模型输出：  tool_calls: { "tool": "query_metrics",
            "arguments": { "service": "order-api", "window": "30m" } }
外部系统：  执行查询，把结果 JSON 拼回上下文
模型输出：  错误率 3.2%、P99 840ms，疑似连接池耗尽，建议……
```

**模型只生成调用请求（工具名 + 参数的 JSON），执行、鉴权、错误处理全在外部系统。**「会调用工具」是训练（SFT + 强化学习）教出来的能力，但执行权从不在模型手里。对后端：这就是一个由模型驱动的 RPC。

### 4.2 思维链

直接回答只有一次前向计算；先写推导再回答，每生成一个 Token 都是一次新的前向——**思考的步数和生成的长度挂钩。**训练侧教它怎么想（在推理轨迹上做微调与强化学习），使用侧给更长的思考预算。边界：更长 ≠ 更对；推理消耗大量 Token，成本高、延迟大。

### 4.3 ReAct

一次性生成无法根据执行结果修正，错了就一路错到底。ReAct 把它变成循环：**观察 → 思考（还缺什么信息）→ 行动（调工具）→ 新观察 → ……直到答案。**

与多轮对话的区别在驱动力：多轮靠用户追问，ReAct 靠环境反馈——单次任务内自我推进。排障例子：查指标（错误率高）→ 查日志（连接池告警）→ 定位根因 → 建工单、通知负责人。

### 4.4 现代 Agent 生态

- **MCP**：工具连接的标准协议。M 个应用 × N 个工具的逐对对接（M×N），变成 M+N——换模型、换工具，协议不变
- **Skill**：把「某类任务怎么做」（步骤、约束、模板、异常处理）固化成可复用知识，同类任务不再重复犯错
- **子 Agent**：用循环编排 LLM 本身，大任务拆给多个小 Agent 协作

共同点：都没有改变模型，改变的都是外面的系统。

### 4.5 Agent 是系统，不是模型

分层：LLM（理解与决策）/ Harness（执行循环、状态、权限、校验）/ Skill 与工作流（稳定任务知识）/ MCP（标准连接）。

Agent = LLM + 目标 + 状态 + 工具 + 循环。它不是新的基础模型——预测下一个 Token 的机制没变，变的是组织方式。看到产品「能干活」，先问：能力在参数里，还是系统里？

## 五、回到主线

1. **机器学习**：预测 → 误差 → 调整；学到的是数字，不是规则；要新数据上依然有效
2. **深度学习**：非线性 + 多层，特征自己学
3. **Transformer**：按内容直达上下文；因果掩码只看过去
4. **预训练**：能力是被目标逼出来的副产品；接口统一成提示词
5. **后训练**：SFT 教形式、偏好教倾向；能力和行为是两回事
6. **生成与 Agent**：参数冻结，逐 Token 循环；模型决定、系统执行

再压缩：人把东西一样样交给机器——规则、参数、特征、表示、任务适配、行动。

五个判断问题，面对任何 AI 新概念时先问：

1. 它改的是模型结构、训练方式、生成过程，还是外部系统？
2. 它用了什么数据或反馈信号？
3. 它实际在优化什么目标？
4. 能力来自模型参数，还是工具和工作流？
5. 它什么条件下有效，不能保证什么？

收尾：今天的大模型，底层仍然在预测下一个 Token。让人惊讶的不是这个目标多简单，而是当结构、数据和规模足够大之后，为了持续做好这件小事，机器长出了我们称之为「智能」的行为。
