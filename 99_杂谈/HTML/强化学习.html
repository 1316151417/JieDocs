01 — 地基
第一性原理拆解：强化学习到底在解决什么问题？
建筑师不从屋顶开始。我们要回到最根本的问题——如果世界上不存在"强化学习"这个概念，我们会如何重新发明它？
01

最根本的问题：序贯决策（Sequential Decision Making）

一个主体必须在不确定的环境中，通过一系列行动来最大化长期累积收益。这就是一切的起点——不是"学习"，不是"奖励"，而是"在时间中做选择"。棋手走棋、机器人行走、自动驾驶避障，本质上都是同一类问题。

02

核心矛盾：探索与利用的权衡（Exploration vs. Exploitation）

你面前有10家餐厅，去过3家。是去已知最好那家（利用），还是尝试新餐厅（探索）？这不是策略问题，这是数学上可以证明的——纯粹的贪婪和纯粹的随机都会导致长期收益次优。这个问题没有解析解，只有渐进最优策略。

03

时间的维度：延迟奖励（Delayed Reward）

今天的投资，十年后才有回报。棋盘上一步棋的好坏，可能要等30步后才显现。这意味着我们不能只看即时反馈，必须建模"未来的未来"。这是强化学习与监督学习的本质区别——没有逐样本的标签，只有稀疏的、延迟的、有时甚至是噪声的反馈信号。

04

涌现的复杂性：环境的非平稳性

当你改变了策略，环境对你的"分布"也变了。你不再是观察一个固定世界，而是参与了一个动态博弈。这导致了一个深层难题：你用过去数据学出的策略，在新策略下收集的数据上可能完全失效。这与物理实验根本不同——观察者改变了自己的行为。

// 核心伪代码 — 马尔可夫决策过程 (MDP)
Initialize state s₀ from environment
for each timestep t = 0, 1, 2, ... :
  Agent selects action aₜ ~ π(a | sₜ)
  Environment returns reward rₜ and next state sₜ₊₁
  Agent updates policy π based on (sₜ, aₜ, rₜ, sₜ₊₁)
  // Goal: maximize E[∑ γᵗ · rₜ] where γ ∈ [0,1)
Gₜ = rₜ + γ·rₜ₊₁ + γ²·rₜ₊₂ + ... = Σₖ₌₀^∞ γᵏ·rₜ₊ₖ
折扣回报 (Discounted Return)：γ 控制"近视"还是"远视"。γ→0 只看眼前；γ→1 着眼长远。 这不是随意设定的超参数——它编码了我们对未来的不确定性：未来的奖励可能无法兑现。
🎯

策略 π (Policy)

从状态到行动的映射。可以是确定性的 (s→a)，也可以是随机的 (s→P(a))。 策略是建筑师的设计蓝图——它决定了一切行为的框架。所有学习的目标，最终都收敛为一个好策略。

CORE OBJECTIVE
📈

价值函数 V(s) / Q(s,a)

V(s) 评估一个状态"有多好"；Q(s,a) 评估在某状态下做某动作"有多好"。 它们是建筑师的结构计算——告诉你这根梁能不能承重，这块地基值不值得投入。

EVALUATION
🧠

模型 (Optional)

对环境动态 P(s'|s,a) 和奖励 R(s,a) 的估计。有模型就能"规划"（在脑中模拟）， 无模型则只能"试错"。这是建筑沙盘 vs. 真实建造的区别——有沙盘当然更好，但建一个准确的沙盘本身就很难。

03 — 算法蓝图
关键算法族谱与技术选型
没有一种材料能解决所有建筑问题。同样，没有一种算法能解决所有RL问题。理解每种方法的受力结构，才能做出正确选型。
Algorithm Type Core Idea Strength Limitation
Q-Learning Value 用表格记录每个(s,a)的Q值，通过TD更新 简单、收敛有保证 状态空间爆炸（维度灾难）
DQN Value 用神经网络逼近Q函数 + 经验回放 + 目标网络 处理高维输入（图像） 仅限离散动作空间
REINFORCE Policy 直接参数化策略，用蒙特卡洛采样估计梯度 可处理连续动作 高方差、训练不稳定
PPO Policy 裁剪目标函数限制策略更新幅度 稳定、通用、工程友好 可能收敛到局部最优
SAC Actor-Critic 最大熵框架：在最大化回报的同时最大化策略熵 探索性强、鲁棒 超参数敏感、计算开销大
TD3 Actor-Critic 双Q网络 + 延迟策略更新 + 动作噪声裁剪 缓解Q值过估计 离散动作不如DQN高效
MCTS + NN Model-based 蒙特卡洛树搜索 + 神经网络引导（AlphaZero架构） 棋类超人表现 需要完美环境模拟器
World Models Model-based 学一个环境的压缩表示，在"梦境"中训练策略 样本效率极高 模型误差累积

Value-Based 方法

先评估，再决策
  • 学习 Q(s,a) 或 V(s)，然后据此推导策略
  • 天然适合离散动作空间
  • 代表：Q-Learning, DQN, Double DQN
  • 建筑师类比：先做力学计算（评估），再决定结构形式（策略）

Policy-Based 方法

直接学习策略
  • 参数化策略 π(a|s;θ)，直接优化期望回报
  • 天然支持连续动作空间和随机策略
  • 代表：REINFORCE, PPO, TRPO
  • 建筑师类比：直接优化设计本身，边建造边优化
04 — 实验室 I
互动实验：多臂老虎机
10台老虎机，每台的真实胜率未知。你的任务：通过有限次数的拉动，找到最好的那台。 这是强化学习最纯净的形式——没有状态转移，只有探索与利用的博弈。
