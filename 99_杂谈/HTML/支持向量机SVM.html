Section 01

第一性原理拆解

不从公式出发，而是从最根本的问题开始：我们到底在解决什么？每一个假设是否站得住脚？

最本质的问题是什么？

我们有一堆数据点，它们分属两个类别。我们需要在它们之间画一条"线"， 把两类分开。这不是一个统计问题——这是一个几何问题。 核心问题是：在无穷多种可能的分界线中，哪一条是最好的？

什么叫做"最好"？

直觉告诉我们：最好的分界线应该离两类数据都尽可能远。就像建筑师在两栋建筑之间规划道路—— 我们要最大化道路的宽度。这个宽度，在SVM中叫做 margin（间隔）。 最大化间隔，就是SVM的唯一目标。

哪些点决定了这条路？

不是所有的数据点都有用。只有那些站在最边缘、最靠近分界线的点才决定了间隔的宽度。 这些点就叫做 支持向量（Support Vectors）——它们是唯一重要的点， 其余的点即使被移除，也不会改变最终的分界线。

如果不是线性可分的呢？

现实数据很少是完美线性可分的。这里有一个天才的想法： 把数据映射到更高维度的空间。在低维空间中纠缠不清的数据， 到了高维空间可能就一目了然了。而"核技巧"让我们不需要真的去做这个映射， 只需要计算高维空间中的内积——这极大地降低了计算成本。

允许犯错，但要惩罚

即使在高维空间，噪声和异常值仍然存在。与其追求完美分类，不如允许一些点越过边界， 但对越界行为施加惩罚。惩罚的力度由参数 C 控制。 C 大 → 不容忍错误（可能过拟合）；C 小 → 更宽容（更鲁棒）。

建筑师洞察

SVM 的哲学本质是结构性风险管理。就像建筑师设计一座桥梁——不是让它在完美条件下最好， 而是让它在最恶劣条件下仍然安全。最大化间隔 = 最大化结构的安全冗余。 支持向量 = 关键承重节点。核技巧 = 用高维结构解决低维的困境。

Section 02

数学基石

建筑需要蓝图。SVM的数学推导就是这座建筑的结构力学——每一步都有明确的物理含义。

超平面与间隔最大化

对于线性可分的数据，超平面定义为 w·x + b = 0。 点到超平面的距离为 |w·x + b| / ||w||。 通过缩放使得支持向量满足 |w·x + b| = 1， 间隔宽度 = 2/||w||。

原始优化问题 min (1/2) ||w||²
s.t. yᵢ(w · xᵢ + b) ≥ 1, ∀i = 1, ..., n

// 最小化 ||w||² 等价于最大化间隔 2/||w||
// 约束条件：每个点都在间隔边界之外

拉格朗日对偶

通过引入拉格朗日乘子 αᵢ ≥ 0，将带约束的优化问题转化为无约束问题。 对偶形式的妙处在于：数据只以内积 xᵢ·xⱼ 的形式出现——这为核技巧埋下伏笔。

对偶问题 max Σαᵢ - (1/2) ΣΣ αᵢαⱼyᵢyⱼ(xᵢ · xⱼ)
s.t. Σαᵢyᵢ = 0, αᵢ ≥ 0

// w* = Σ αᵢyᵢxᵢ （w 是支持向量的线性组合）
// 只有 αᵢ > 0 的点才是支持向量

KKT 互补松弛条件

KKT条件告诉我们：只有支持向量的 α 才非零。 这就是为什么SVM是"稀疏"的——决策边界只由少数关键点决定。

KKT 条件 αᵢ ≥ 0
yᵢ(w · xᵢ + b) - 1 ≥ 0
αᵢ [yᵢ(w · xᵢ + b) - 1] = 0 ← 互补松弛

// 若 αᵢ > 0 → yᵢ(w·xᵢ+b) = 1 → xᵢ 是支持向量
// 若 αᵢ = 0 → 该点对决策边界无影响

软间隔（Soft Margin）

引入松弛变量 ξᵢ ≥ 0，允许部分数据点违反间隔约束。 参数 C 控制"违反约束的惩罚"与"间隔宽度"之间的权衡。

软间隔 SVM min (1/2) ||w||² + C Σξᵢ
s.t. yᵢ(w · xᵢ + b) ≥ 1 - ξᵢ, ξᵢ ≥ 0

// C 大 → 惩罚重 → 间隔窄 → 对训练数据拟合更紧
// C 小 → 惩罚轻 → 间隔宽 → 泛化能力可能更强
// ξᵢ > 1 的点被误分类

Section 04

核函数宇宙

核技巧是SVM最优雅的设计——它让计算在低维完成，效果却在高维生效。 选择核函数，就像选择建筑材料——不同的场景需要不同的材料。

Linear
K(x, x') = x · x'
线性核。最简单也最快速。适用于线性可分或高维稀疏数据（如文本分类）。
Polynomial
K(x, x') = (γx·x' + r)^d
多项式核。可以捕获特征间的交互关系。d 控制复杂度，过高的 d 可能过拟合。
RBF (Gaussian)
K(x, x') = exp(-γ||x-x'||²)
径向基核。最常用的核函数。理论上可以映射到无限维。γ 控制"影响半径"。
Sigmoid
K(x, x') = tanh(γx·x' + r)
Sigmoid 核。类似神经网络。并非总是正定核，需谨慎使用。

Section 05

对比分析与历史

好的建筑师不仅懂自己的结构，还要了解整个城市的格局。

1963
Vapnik & Lerner 提出广义肖像法（Generalized Portrait），SVM 的前身。
1992
Boser, Guyon, Vapnik 发表"最优间隔分类"论文，核技巧正式引入。
1995
Cortes & Vapnik 提出软间隔 SVM，处理非线性可分数据。
2000s
SVM 在手写识别、文本分类、生物信息学领域大放异彩。深度学习崛起前的"分类之王"。

建筑师洞察

SVM 在"中小规模 + 高维度 + 理论保证"场景下几乎是无敌的选择。 但当数据量达到百万级、或者需要自动学习特征表示时，深度学习更有优势。 关键不在于"谁更好"，而在于了解每种工具的最佳施工场景。

Section 06

实战指导手册

从理论到落地的每一步——什么时候用、怎么调、怎么避坑。

01 — 适用场景
什么时候该用 SVM？
推荐 样本量 ≤ 10 万、特征维度高（文本/基因数据）、需要理论保证、二分类问题。

慎用 样本量 > 100 万（训练时间 O(n²)~O(n³)）、多分类（需 one-vs-one/one-vs-all）、需要概率输出、实时在线学习。
02 — 数据预处理
施工前的准备工作
必须 特征缩放——SVM 基于距离计算，不缩放的特征会让某些维度主导。StandardScaler 或 MinMaxScaler 是标配。

建议 处理缺失值和异常值。SVM 对异常值敏感（尤其是线性核）。考虑使用软间隔来缓解。
03 — 核函数选择
选择正确的建筑材料
经验法则：先试线性核（尤其是特征数 > 样本数时）。线性核不行再试 RBF。 RBF 是"万金油"，大多数场景表现不错。多项式核在特定领域（图像）有奇效。

警告 不要在没有交叉验证的情况下随意选择核函数和参数。
04 — 调参策略
精密的参数调试
对于 RBF 核，核心参数是 C 和 γ (gamma)。

C 的搜索范围：10⁻³ ~ 10³（对数间隔）
γ 的搜索范围：10⁻⁹ ~ 10³（对数间隔）

使用 GridSearchCV 或 RandomizedSearchCV。 先粗搜再细搜，分层 K 折交叉验证。
05 — 多分类策略
扩展到多类别问题
OvR (One-vs-Rest)：训练 K 个分类器，每个区分"该类 vs 其余"。 速度快，但可能类别不平衡。

OvO (One-vs-One)：训练 K(K-1)/2 个分类器，每两个类别之间训练一个。 训练多但每个简单。多数库默认使用此策略。
06 — 常见陷阱
避坑清单
陷阱 1 忘记特征缩放 → 结果很差
陷阱 2 C 过大 → 过拟合，训练准确率 100% 但测试很差
陷阱 3 γ 过大 → 决策边界过于复杂
陷阱 4 样本太少就用 RBF → 噪声都被记住了
陷阱 5 不做交叉验证 → 参数选择随机
