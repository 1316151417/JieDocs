# 第8章 反向传播与优化算法

> **核心问题**：如何高效训练神经网络？为什么基于梯度的优化是不可替代的？

## 8.1 反向传播算法详解

### 8.1.1 核心思想

反向传播（Backpropagation）是计算梯度的高效算法，其根本原理建立在微积分的链式法则之上。可以通过实值电路分析和梯度流模式来理解反向传播。

> CS231n课程将反向传播描述为"通过递归应用链式法则来计算表达式梯度的方法"，并提出了"反向传播作为实值电路中的反向流"这一较少被展开的视角。
> — Stanford CS231n (cs231n.github.io)

**关键洞察**：利用链式法则，从输出层向输入层逐层计算梯度

**复杂度**：前向传播O(n)，反向传播O(n)，总共O(n)
- 如果用数值微分，复杂度是O(n^2)

### 8.1.2 梯度流模式

反向传播中的不同门类型有不同的梯度流模式：
- **加法门**：均匀分配梯度
- **Max门**：将梯度不变地传递给一个输入
- **乘法门**：使用输入值来缩放梯度

### 8.1.3 计算图

**前向传播**：
```
x -> [*w] -> [+b] -> [ReLU] -> [*w2] -> [+b2] -> [MSE Loss]
```

**反向传播**：
```
1 <- [dL/doutput] <- [doutput/dpre_relu] <- [dpre_relu/dz] <- ...
```

### 8.1.4 链式法则的应用

**单变量**：
```
如果 y = f(g(x))，则 dy/dx = f'(g(x)) * g'(x)
```

**多变量**：
```
如果 z = f(u, v)，u = g(x)，v = h(x)
则 dz/dx = (dz/du)(du/dx) + (dz/dv)(dv/dx)
```

### 8.1.5 反向传播的步骤

**步骤1：前向传播**
```
z1 = W1*x + b1
a1 = f(z1)
z2 = W2*a1 + b2
a2 = f(z2)
...
```

**步骤2：计算损失**
```
L = Loss(y, a_n)
```

**步骤3：反向传播**
```
dL/da_n = dLoss/da_n
dL/dz_n = dL/da_n * f'(z_n)
dL/dW_n = dL/dz_n * a_{n-1}^T
dL/db_n = dL/dz_n
dL/da_{n-1} = W_n^T * dL/dz_n
...
```

## 8.2 损失景观与优化挑战

### 8.2.1 线性分类器的损失景观

以CIFAR-10数据集为例，线性分类器的权重矩阵为10x3073（3072个像素特征加1个偏置），共30,730个参数。

**SVM损失函数的结构**：

SVM损失（不含正则化）呈现分段线性（piecewise-linear）结构，因为每一项都是关于W的零阈值线性函数（由max(0,.)算子导致）。当多个训练样本的损失取平均后，损失景观呈现碗状（bowl-shaped），即凸函数的特征。

> CS231n课程指出："每个样本的数据损失是W的（由max(0,-)函数零阈值化的）线性函数之和。"多个样本的损失取平均后，"右边的碗形是许多分段线性碗的平均"，并且"你可能已经从碗状外观猜到，SVM代价函数是凸函数的一个例子。"
> — Stanford CS231n (cs231n.github.io/optimization-1/)

**神经网络的非凸损失景观**：

然而，一旦将评分函数扩展为神经网络，目标函数就变为非凸，具有复杂的崎岖地形（complex, bumpy terrains），不再是碗状。

> "Once we extend our score functions f to Neural Networks our objective functions will become non-convex, and the visualizations above will not feature bowls but complex, bumpy terrains."
> — Stanford CS231n (cs231n.github.io/optimization-1/)

### 8.2.2 为什么不能用随机搜索

随机搜索和随机局部搜索在实践中效果极差，这证明了基于梯度的迭代优化是深度学习训练的核心原则。

**在CIFAR-10上的实验结果**：

| 方法 | 评估次数 | 测试准确率 | 说明 |
|------|----------|-----------|------|
| 随机猜测 | - | 10% | 基线 |
| 随机搜索 | 多次 | ~15.5% | 仅略高于随机猜测 |
| 随机局部搜索 | 1000次 | 21.4% | 优于随机搜索，但计算浪费 |
| 梯度下降 | 远少于上述 | 远高于上述 | 实际使用的方法 |

> "For CIFAR-10, this achieved roughly 15.5% test accuracy -- marginally above random guessing at 10%." 以及 "With 1,000 evaluations this reached 21.4% accuracy -- better than pure random search but still computationally wasteful."
> — Stanford CS231n (cs231n.github.io/optimization-1/)

## 8.3 梯度计算：数值方法 vs 解析方法

### 8.3.1 数值梯度（有限差分法）

数值梯度通过有限差分来近似导数：
```
df/dx = (f(x+h) - f(x)) / h    （前向差分）
df/dx = (f(x+h) - f(x-h)) / 2h （中心差分，更精确）
```

**致命缺陷**：计算复杂度与参数数量成线性关系。对于30,730个参数的线性分类器，每次参数更新需要评估损失函数30,731次。对于现代拥有数千万参数的网络，这完全不可行。

> "Complexity is linear in the number of parameters." "In our example we had 30730 parameters in total and therefore had to perform 30,731 evaluations of the loss function." "This problem only gets worse, since modern Neural Networks can easily have tens of millions of parameters." "Clearly, this strategy is not scalable."
> — Stanford CS231n (cs231n.github.io/optimization-1/)

### 8.3.2 解析梯度

**解决方案**：通过微积分推导梯度的闭式表达式（解析梯度），计算复杂度与前向传播相同。

**梯度检验**（Gradient Checking）：使用数值梯度来验证解析梯度的正确性，这是调试反向传播实现的标准做法。

**实践建议**：
1. 先用解析梯度实现反向传播
2. 用数值梯度进行梯度检验
3. 确认无误后，在训练中只使用解析梯度

## 8.4 学习率：最重要的超参数

### 8.4.1 学习率的三个区间

学习率（learning rate）是最重要的超参数之一，选择不当会导致训练失败。

| 区间 | 行为 | 结果 |
|------|------|------|
| 步长太小 | 损失改善微乎其微 | 收敛极慢 |
| 最优中间值 | 最佳下降 | 理想训练 |
| 步长太大 | 过冲（overshooting） | 损失增加，训练不稳定 |

> CS231n课程明确指出："步长（也称为学习率）将成为最重要（也最令人头疼）的超参数设置之一。"小步长带来"一致但非常小的进展"，最优中间值给出最佳下降，"在某一点上，更大的步长会导致更高的损失，因为我们'过冲'了。"
> — Stanford CS231n (cs231n.github.io/optimization-1/)

### 8.4.2 学习率选择实践

**经验法则**：
- Adam优化器：从0.001开始
- SGD：从0.1开始
- 使用学习率查找器（LR Finder）
- 观察训练曲线判断

**现代自适应优化器的缓解作用**：
Adam、AdamW等自适应学习率优化器可以降低学习率的敏感性（相比 vanilla SGD），但学习率仍然是影响训练效果的关键超参数。

## 8.5 梯度问题

### 8.5.1 梯度消失

**问题**：深层网络中，梯度逐层衰减

**原因**：
- 使用Sigmoid/Tanh激活函数
- 这些函数的导数最大值<1
- 连续相乘导致梯度指数衰减

**例子**：
```
Sigmoid导数：sigma'(x) = sigma(x)(1-sigma(x))，最大值为0.25
10层网络：梯度衰减到0.25^10 约 10^-6
```

**解决方案**：
- 使用ReLU激活函数
- 残差连接
- 批量归一化
- 合适的权重初始化

### 8.5.2 梯度爆炸

**问题**：梯度指数增长

**原因**：
- 权重矩阵特征值>1
- 学习率过大

**解决方案**：
- 梯度裁剪（Gradient Clipping）
- 权重正则化
- 合适的学习率

**梯度裁剪实现**：
```python
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
```

### 8.5.3 鞍点问题

**问题**：高维空间中鞍点比局部最优更常见

**鞍点特点**：
- 某些方向是局部最小
- 其他方向是局部最大
- 梯度为零，但不是最优解

**解决方案**：
- 使用动量（Momentum）
- 使用自适应学习率（Adam）
- 随机梯度下降的噪声帮助逃离鞍点

## 8.6 基础优化算法

### 8.6.1 随机梯度下降（SGD）

**基本形式**：
```
theta <- theta - eta * grad_L(theta)
```

**小批量SGD**：
```
theta <- theta - eta * (1/|B|) Sigma_{i in B} grad_L_i(theta)
```

**优势**：
- 计算效率高
- 可以逃离局部最优
- 内存需求小

**劣势**：
- 收敛慢
- 震荡
- 对学习率敏感

### 8.6.2 动量（Momentum）

**核心思想**：积累历史梯度，加速收敛

```
v <- beta * v + (1-beta) * grad_L(theta)
theta <- theta - eta * v
```

**优势**：
- 加速收敛
- 减少震荡
- 帮助逃离局部最优

### 8.6.3 Nesterov动量

**改进**：先"预测"下一步的位置，再计算梯度

```
v <- beta * v + (1-beta) * grad_L(theta - eta * beta * v)
theta <- theta - eta * v
```

**优势**：
- 更快的收敛速度
- 更好的稳定性

---

## 8.7 自适应学习率算法

### 8.7.1 AdaGrad

**核心思想**：对每个参数自适应调整学习率

```
G <- G + (grad_L)^2
theta <- theta - eta / (sqrt(G) + epsilon) * grad_L
```

**优势**：
- 自动调整学习率
- 适合稀疏数据

**劣势**：
- 学习率单调递减
- 可能过早停止学习

### 8.7.2 RMSProp

**改进**：使用指数移动平均代替累加

```
G <- beta * G + (1-beta) * (grad_L)^2
theta <- theta - eta / (sqrt(G) + epsilon) * grad_L
```

**优势**：
- 解决AdaGrad学习率衰减问题
- 更稳定

### 8.7.3 Adam

**核心思想**：结合动量和自适应学习率

```
m <- beta1 * m + (1-beta1) * grad_L       # 一阶矩估计
v <- beta2 * v + (1-beta2) * (grad_L)^2    # 二阶矩估计

m_hat = m / (1 - beta1^t)  # 偏差修正
v_hat = v / (1 - beta2^t)  # 偏差修正

theta <- theta - eta / (sqrt(v_hat) + epsilon) * m_hat
```

**默认参数**：
- beta1 = 0.9
- beta2 = 0.999
- epsilon = 1e-8
- eta = 0.001

**优势**：
- 收敛快
- 对超参数不敏感
- 适合大多数任务

### 8.7.4 AdamW

**改进**：解耦权重衰减

```
theta <- theta - eta * (grad_L / (sqrt(v_hat) + epsilon) * m_hat + lambda * theta)
```

**优势**：
- 更好的泛化
- 正则化效果更稳定

## 8.8 学习率调度

### 8.8.1 为什么需要学习率调度

**问题**：
- 大学习率：训练快但不稳定
- 小学习率：稳定但慢

**解决方案**：动态调整学习率

### 8.8.2 常见调度策略

**阶梯衰减**：
```
每N个epoch，学习率乘以gamma
```

**指数衰减**：
```
eta_t = eta_0 * gamma^t
```

**余弦退火**：
```
eta_t = eta_min + 0.5 * (eta_max - eta_min) * (1 + cos(pi*t/T))
```

**warmup + 余弦退火**：
```
if t < warmup_steps:
    eta = t / warmup_steps * eta_max
else:
    eta = eta_min + 0.5 * (eta_max - eta_min) * (1 + cos(pi(t-warmup)/(T-warmup)))
```

### 8.8.3 warmup的重要性

**问题**：训练初期梯度不稳定

**解决方案**：先用小学习率，逐渐增加

**典型设置**：
- warmup_steps = 1000-5000
- 然后使用余弦退火

## 8.9 梯度累积

### 8.9.1 核心思想

**问题**：GPU内存有限，无法使用大batch

**解决方案**：累积多个小batch的梯度

```python
optimizer.zero_grad()
for i in range(accumulation_steps):
    outputs = model(inputs[i])
    loss = criterion(outputs, targets[i])
    loss = loss / accumulation_steps
    loss.backward()
optimizer.step()
```

### 8.9.2 效果

- 等效于使用大batch训练
- 保持小batch的内存需求
- 训练更稳定

## 8.10 混合精度训练

### 8.10.1 核心思想

**问题**：FP32计算慢，内存占用大

**解决方案**：混合使用FP16和FP32

**前向传播**：FP16（更快）
**反向传播**：FP16（更快）
**参数更新**：FP32（更精确）

### 8.10.2 实现

```python
from torch.cuda.amp import autocast, GradScaler

scaler = GradScaler()

for inputs, targets in dataloader:
    optimizer.zero_grad()

    with autocast():
        outputs = model(inputs)
        loss = criterion(outputs, targets)

    scaler.scale(loss).backward()
    scaler.step(optimizer)
    scaler.update()
```

### 8.10.3 损失缩放

**问题**：FP16梯度可能下溢

**解决方案**：放大损失，使梯度在FP16范围内

```python
loss = loss * scale_factor
loss.backward()
# 更新时再除以scale_factor
```

## 8.11 实践建议

### 8.11.1 优化器选择

| 场景 | 推荐优化器 | 原因 |
|------|-----------|------|
| 训练初期探索 | Adam/AdamW | 收敛快，对超参数不敏感 |
| 精细调优 | SGD + Momentum | 泛化更好 |
| 大模型训练 | AdamW + warmup | 稳定，效果好 |
| 微调预训练模型 | AdamW + 小学习率 | 避免灾难性遗忘 |

### 8.11.2 学习率选择

**经验法则**：
- 从0.001开始（Adam）
- 使用学习率查找器
- 观察训练曲线

**学习率查找器**：
```python
# 逐渐增加学习率，找到损失下降最快的点
for lr in np.logspace(-7, 0, 100):
    optimizer = torch.optim.Adam(model.parameters(), lr=lr)
    train_one_epoch()
    record_loss()
```

### 8.11.3 批量大小选择

**权衡**：
- 大batch：训练快，泛化差
- 小batch：训练慢，泛化好

**经验法则**：
- 图像分类：32-256
- 语言模型：根据GPU内存调整
- 使用梯度累积模拟大batch
