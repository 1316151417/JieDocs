**一、领域本质**

深度学习基础，本质上是在研究：**如何让机器用可训练的多层函数，从数据中自动学习表示、规律与决策规则，并且能在未知数据上稳定工作。**

换句话说，它不是先问“有哪些模型”，而是先问：

> 我们如何把现实问题变成数据？  
> 如何定义一个可学习的函数？  
> 如何让这个函数变好？  
> 如何判断它真的学会了，而不是记住了？  
> 如何把它扩展到图像等高维结构化数据？  
> 如何让复杂模型可以稳定、可复现、可工程化地训练？

**三、问题之间的关系**

**最基础的问题是：如何把学习变成可计算过程。**

这对应前两部分：

- 数据操作、数据预处理：解决“学习材料从哪里来，如何表示”
- 线性代数、矩阵计算：解决“如何高效表达批量计算”
- 自动求导：解决“如何知道参数该怎么改”
- 框架核心功能：解决“如何把这些机制稳定封装起来”

这些是所有深度学习模型的底座。

**第二层问题是：如何定义一个可以训练的模型。**

线性回归、Softmax 回归、感知机、多层感知机分别回答：

- 如何预测连续值？
- 如何做多分类？
- 如何用线性边界做判断？
- 如何通过隐藏层和激活函数表达非线性？

这里的发展路径是：

```text
线性函数
→ 可以学习简单规律
→ 但表达能力不足
→ 引入多层结构和非线性
→ 模型更强
→ 但训练和泛化更难
```

**第三层问题是：模型强大以后，如何防止它学坏。**

模型选择、欠拟合、过拟合、权重衰减、Dropout 共同解决：

- 模型是否太简单？
- 模型是否太复杂？
- 训练误差和测试误差为什么不同？
- 如何让模型在未知数据上可靠？

这条线是深度学习从“能拟合”走向“能泛化”的关键。

**第四层问题是：深层模型为什么难训练，如何训练得动。**

数值稳定性、初始化、激活函数、批量归一化、ResNet 都在解决一个核心问题：

> 网络越深，表达能力越强，但优化路径越复杂，信号和梯度越容易失控。

所以深度学习并不是简单“堆层数”，而是围绕“如何让深层函数可训练”不断发展。

**第五层问题是：如何把通用神经网络适配到图像。**

CNN 的出现，是因为图像不是普通向量，而是有空间结构：

```text
图像有局部性
→ 用卷积提取局部模式
→ 图像模式可平移
→ 用权重共享减少参数
→ 图像特征有层级
→ 用多层卷积从边缘到物体逐级抽象
```

LeNet、AlexNet、VGG、NiN、GoogLeNet、ResNet 的演化，本质不是“网络名字越来越多”，而是围绕几个问题：

- 如何更深？
- 如何更宽？
- 如何多尺度？
- 如何降低计算量？
- 如何稳定训练？
- 如何提升泛化？

**四、领域演化主线**

```text
现实任务无法手写规则
→ 让机器从数据中学习函数
→ 需要表示数据
→ 张量、矩阵、批量计算成为基础

有了数据表示
→ 需要定义模型输出
→ 线性回归用于连续预测，Softmax 回归用于分类

有了模型
→ 需要知道模型错在哪里
→ 损失函数把错误变成可优化目标

有了损失
→ 需要让参数自动改进
→ 梯度下降和自动求导成为训练核心

线性模型能训练
→ 但只能表达简单关系
→ 引入感知机、多层感知机、激活函数

多层模型表达能力增强
→ 但更容易过拟合
→ 引入训练集/验证集/测试集、模型选择、正则化、Dropout

模型更深
→ 但数值不稳定、梯度难传播
→ 引入合理初始化、激活函数选择、批量归一化、残差连接

通用神经网络用于图像
→ 参数太多，忽略空间结构
→ 引入卷积、填充、步幅、通道、池化

CNN 可处理图像
→ 但还要更深、更强、更高效
→ LeNet 证明可行
→ AlexNet 扩大规模
→ VGG 模块化加深
→ NiN 增强局部表达
→ GoogLeNet 多尺度并行
→ ResNet 解决深层退化和训练困难

模型、训练、数据、工程都具备
→ 进入 Kaggle 房价预测、图片分类等实践
→ 学会从问题定义、数据处理、模型选择、训练调优到结果提交的完整闭环
```

**一句话总图**

```text
深度学习基础的主线不是“学一堆模型”，而是：

如何把现实问题表示成数据
→ 如何构造可训练函数
→ 如何用损失和梯度优化函数
→ 如何让函数表达复杂规律
→ 如何防止函数只记住训练集
→ 如何让深层函数稳定训练
→ 如何利用图像结构设计 CNN
→ 如何把模型训练变成可复现、可调优、可提交的工程流程
```

这部分学完后，你真正获得的不是“线性回归、MLP、CNN 这些名词”，而是一套深度学习的基本思维框架：

> 数据是输入，模型是假设空间，损失定义目标，优化寻找参数，正则化控制泛化，结构设计利用先验，工程能力保证这一切能在真实任务中跑起来。
