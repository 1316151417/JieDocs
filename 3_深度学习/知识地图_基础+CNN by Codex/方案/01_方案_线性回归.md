**一、核心机制**

线性回归真正起作用的机制是：

> 用一条“可调的直线/平面/超平面”，去逼近输入特征和连续数值目标之间的关系。

它假设很多现实问题可以近似成：

```text
预测值 = 各个特征的加权求和 + 一个整体偏移
```

比如预测房价：

```text
房价 ≈ 面积的影响 + 房龄的影响 + 地段的影响 + 基础房价偏移
```

线性回归做的事，就是不断调整这些“影响权重”，让预测结果尽量接近真实答案。

---

**二、工作流程**

```text
输入特征 x
↓
用权重 w 衡量每个特征的重要性
↓
把所有特征影响加起来
↓
加上偏置 b
↓
得到预测值 y_hat
↓
和真实值 y 比较，计算误差
↓
根据误差调整 w 和 b
↓
重复很多次，直到预测变准
```

更具体：

```text
样本数据
↓
模型预测
↓
计算损失
↓
反向传播求梯度
↓
优化器更新参数
↓
得到更好的模型
```

---

**三、关键组成部分**

**1. 特征 x**

特征是模型用来做判断的信息。

例如预测房价：

```text
x = [面积, 房龄, 卧室数]
```

模型不会直接“理解房子”，它只看到这些数字。

**2. 权重 w**

权重表示每个特征对预测结果的影响强度。

```text
面积权重大：面积对房价影响大
房龄权重为负：房龄越高，房价可能越低
卧室数权重较小：影响存在，但可能没面积大
```

权重是模型要学习的核心参数。

**3. 偏置 b**

偏置表示即使所有特征为 0，也存在的基础预测值。

直觉上，它是整体基准线。

```text
预测房价 = 特征影响总和 + 基础房价
```

**4. 预测函数**

线性回归的预测函数是：

```text
y_hat = w1*x1 + w2*x2 + ... + wn*xn + b
```

它的本质是“加权求和”。

**5. 损失函数**

损失函数用来衡量预测错得多严重。

线性回归通常用平方损失：

```text
loss = 1/2 * (y_hat - y)^2
```

为什么平方？

- 误差为正或负都算错
- 大误差会被惩罚得更重
- 平方函数可导，方便优化

**6. 优化器**

优化器负责根据错误调整参数。

最典型的是梯度下降：

```text
如果某个参数让误差变大，就往反方向调
如果某个参数让误差变小，就继续往那个方向调
```

---

**四、数学原理**

单个样本的线性回归公式：

```text
y_hat = w^T x + b
```

含义是：

- `x`：输入特征向量，比如 `[面积, 房龄]`
- `w`：权重向量，比如 `[面积权重, 房龄权重]`
- `b`：偏置
- `y_hat`：模型预测值
- `w^T x`：把每个特征和对应权重相乘后求和

展开就是：

```text
y_hat = w1*x1 + w2*x2 + b
```

损失函数：

```text
L = 1/2 * (y_hat - y)^2
```

含义是：

- `y_hat`：预测值
- `y`：真实值
- `y_hat - y`：预测误差
- 平方：把误差变成非负，并放大大误差
- `1/2`：为了求导后抵消平方带来的系数 2，计算更简洁

训练目标：

```text
找到一组 w 和 b，让所有样本的平均损失最小
```

也就是：

```text
minimize 平均预测错误
```

梯度下降更新：

```text
w = w - learning_rate * ∂L/∂w
b = b - learning_rate * ∂L/∂b
```

直觉解释：

- `∂L/∂w` 表示损失对权重的敏感程度
- 如果梯度为正，说明权重变大会让损失变大，所以要减小权重
- 如果梯度为负，说明权重变大会让损失变小，所以要增大权重
- `learning_rate` 控制每次调整的步子大小

**五、具体案例**

假设我们用房屋面积预测房价。

训练样本：

```text
面积 x = 100
真实房价 y = 300
```

假设模型初始参数：

```text
w = 2
b = 20
```

模型预测：

```text
y_hat = w*x + b
      = 2*100 + 20
      = 220
```

真实值是 300，所以误差：

```text
y_hat - y = 220 - 300 = -80
```

损失：

```text
L = 1/2 * (-80)^2 = 3200
```

说明预测低了。

因为面积是正的，模型预测偏低，直觉上应该：

```text
增大 w
或增大 b
```

梯度会告诉模型这个方向。

对 `w` 的梯度：

```text
∂L/∂w = (y_hat - y) * x
      = -80 * 100
      = -8000
```

对 `b` 的梯度：

```text
∂L/∂b = y_hat - y
      = -80
```

假设学习率是 `0.0001`：

```text
w_new = w - 0.0001 * (-8000)
      = 2 + 0.8
      = 2.8

b_new = b - 0.0001 * (-80)
      = 20 + 0.008
      = 20.008
```

更新后再预测：

```text
y_hat = 2.8*100 + 20.008
      = 300.008
```

预测已经非常接近 300。

这就是线性回归的核心训练过程：**预测，犯错，根据错误方向调整参数，再预测。**

**六、实现细节**

线性回归训练通常包含这些步骤：

```python
# 1. 初始化参数
w = random small values
b = 0

# 2. 重复训练
for batch in data:
    # 预测
    y_hat = X @ w + b

    # 计算损失
    loss = ((y_hat - y) ** 2).mean() / 2

    # 自动求导
    loss.backward()

    # 更新参数
    w = w - lr * w.grad
    b = b - lr * b.grad

    # 清空梯度
    w.grad.zero_()
    b.grad.zero_()
```

在 PyTorch 里，简洁实现通常是：

```python
net = nn.Linear(num_inputs, 1)
loss = nn.MSELoss()
trainer = torch.optim.SGD(net.parameters(), lr=0.03)
```

训练循环：

```python
for X, y in data_iter:
    y_hat = net(X)
    l = loss(y_hat, y)
    trainer.zero_grad()
    l.backward()
    trainer.step()
```

这里框架帮你做了几件事：

- `nn.Linear`：封装 `X @ w + b`
- `MSELoss`：封装平方损失
- `backward()`：自动求梯度
- `SGD`：自动更新参数
- `zero_grad()`：清空上一轮梯度，避免累加

性能上，线性回归非常高效，因为它主要是矩阵乘法：

```text
一批样本 X
乘以参数矩阵 w
得到一批预测结果
```

这很适合 GPU 或高性能矩阵库并行计算。

---

**七、本质总结**

如果只保留一句话：

> 线性回归就是让模型学习一组“特征权重”，通过加权求和预测连续值，并用预测误差不断反向调整这些权重。

它看似简单，但它包含了深度学习最基础的完整闭环：

```text
模型
→ 预测
→ 损失
→ 梯度
→ 参数更新
→ 更好的模型
```

后面的 Softmax 回归、多层感知机、CNN，本质上都在扩展这个闭环：模型结构更复杂，损失形式更适配任务，参数更多，但核心训练逻辑仍然是一脉相承的。
