**一、核心机制**

CNN 的核心机制是：**用一组可学习的小窗口，在图像上滑动，反复检测局部模式，并把低级模式逐层组合成高级语义。**

它真正起作用的地方有三个：

1. **局部感受野**  
   图像里的有意义结构通常是局部的，比如边缘、角点、纹理、眼睛、轮廓。CNN 不需要一开始就看整张图，而是先看局部小区域。

2. **权重共享**  
   同一个卷积核在整张图上反复使用。  
   这意味着：如果一个卷积核学会了检测“竖直边缘”，它可以在图像左上角、右下角、任何位置检测同一种模式。

3. **层级组合**  
   第一层检测边缘、颜色变化；中间层组合成纹理、局部形状；高层组合成物体部件甚至类别语义。  
   所以 CNN 不是一次性理解图像，而是逐层构造理解。

---

**二、工作流程**

以图片分类为例：

```text
输入图像
比如 224 × 224 × 3 的 RGB 图片
↓
卷积层
用多个小卷积核扫描图像，提取局部特征
↓
激活函数
引入非线性，让模型能表达复杂模式
↓
池化层 / 下采样
降低空间尺寸，保留重要响应，减少计算
↓
多层卷积重复
从边缘 → 纹理 → 部件 → 物体语义
↓
展平或全局平均池化
把空间特征变成分类用的向量
↓
全连接层 / 分类头
输出每个类别的得分
↓
Softmax
转成类别概率
↓
预测结果
比如 “猫”“狗”“汽车”
```

CNN 的信息流可以理解为：

```text
像素
↓
局部视觉模式
↓
局部形状
↓
物体部件
↓
整体类别
```

---

**三、关键组成部分**

**1. 卷积核**

卷积核是 CNN 最核心的组件。

它是一个小矩阵，比如 `3 × 3` 或 `5 × 5`。它在图像上滑动，每次看一个小区域，然后计算这个区域和卷积核的匹配程度。

直觉上：

```text
卷积核 = 一个模式检测器
```

不同卷积核可以学到不同东西：

```text
卷积核 A：检测竖直边缘
卷积核 B：检测水平边缘
卷积核 C：检测斜线
卷积核 D：检测颜色变化
```

训练前，卷积核参数是随机的；训练后，它们会变成对任务有用的特征检测器。

---

**2. 特征图**

卷积核扫完整张图后，会得到一张新的二维图，叫特征图。

特征图上的每个值表示：

```text
某个位置是否出现了某种特征
```

例如，一个检测竖直边缘的卷积核输出的特征图中，数值大的位置代表那里很像竖直边缘。

如果有 64 个卷积核，就会得到 64 张特征图。每张图负责一种特征。

---

**3. 通道**

原始 RGB 图像有 3 个通道：

```text
红色通道
绿色通道
蓝色通道
```

卷积层输出后，通道数通常变成卷积核数量。

例如：

```text
输入：224 × 224 × 3
使用 64 个卷积核
输出：224 × 224 × 64
```

这里的 `64` 不再是颜色通道，而是 64 种学到的视觉特征。

---

**4. 填充 Padding**

卷积会让图像变小。比如 `5 × 5` 图像用 `3 × 3` 卷积核，如果不填充，输出会变成 `3 × 3`。

Padding 的作用是给图像边缘补零，让输出尺寸可控。

为什么需要它？

```text
没有 Padding：
边缘像素被看到的次数少，信息容易丢失

有 Padding：
边缘信息也能参与卷积，输出尺寸也更容易控制
```

---

**5. 步幅 Stride**

步幅表示卷积核每次滑动几格。

```text
stride = 1：每次移动一格，输出更细
stride = 2：每次移动两格，输出更小
```

步幅越大，输出尺寸越小，计算量越低，但细节损失也越多。

---

**6. 池化 Pooling**

池化层通常用于压缩空间尺寸。

最常见的是最大池化：

```text
在一个小区域里，只保留最大值
```

直觉上，它保留“这个区域里有没有强特征”，而不太关心特征的精确位置。

例如：

```text
左上角有一条边缘
稍微偏右一点还是同一条边缘
```

池化让模型对小幅平移更不敏感。

---

**7. 激活函数**

卷积本身是线性操作。没有激活函数，多层卷积叠加起来仍然只是线性变换。

ReLU 这类激活函数会引入非线性：

```text
ReLU(x) = max(0, x)
```

含义很简单：

```text
检测到特征：保留响应
没有检测到：压成 0
```

这让网络可以组合出复杂形状和复杂决策边界。

---

**四、数学原理**

先看二维单通道卷积。

假设输入图像是 `X`，卷积核是 `K`，输出特征图是 `Y`。

某个位置的输出：

```text
Y[i, j] = Σ Σ X[i + a, j + b] · K[a, b]
```

这句话的物理意义是：

```text
拿卷积核覆盖输入图像的一个局部区域
把对应位置逐个相乘
再全部加起来
得到这个位置的特征响应
```

其中：

```text
X[i + a, j + b]：图像局部区域里的像素值
K[a, b]：卷积核里的权重
Y[i, j]：该位置和这个卷积核模式的匹配程度
```

如果输出值大，说明这个局部区域很符合卷积核要检测的模式。

---

多通道卷积时，公式变成：

```text
Y[o, i, j] = Σc Σa Σb X[c, i + a, j + b] · K[o, c, a, b]
```

变量含义：

```text
c：输入通道，比如 RGB 或上一层的特征通道
o：输出通道，也就是第几个卷积核
a, b：卷积核内部的位置
i, j：输出特征图上的空间位置
```

这表示：

```text
每个输出通道都有一个卷积核组
它会同时看所有输入通道
然后把所有通道的局部响应加起来
得到一个新的特征图
```

所以 CNN 不是只在二维平面上滑动，它是在：

```text
空间维度上滑动
通道维度上融合
```

---

输出尺寸公式：

```text
输出高度 = floor((输入高度 + 2 × padding - kernel_size) / stride) + 1
```

例如：

```text
输入高度 H = 32
卷积核 K = 3
填充 P = 1
步幅 S = 1

输出高度 = (32 + 2×1 - 3) / 1 + 1 = 32
```

所以 `3 × 3` 卷积加 `padding=1`、`stride=1`，可以保持空间尺寸不变。

**五、具体案例**

假设有一张灰度图的一小块：

```text
输入区域 X：

0 0 0
1 1 1
0 0 0
```

现在有一个卷积核 K：

```text
-1 -1 -1
 2  2  2
-1 -1 -1
```

这个卷积核像是在检测“水平亮线”。

计算：

```text
0×(-1) + 0×(-1) + 0×(-1)
+ 1×2 + 1×2 + 1×2
+ 0×(-1) + 0×(-1) + 0×(-1)
= 6
```

输出很大，说明这个区域很像水平线。

如果输入区域变成：

```text
1 0 0
1 0 0
1 0 0
```

再用同一个卷积核计算：

```text
1×(-1) + 0×(-1) + 0×(-1)
+ 1×2 + 0×2 + 0×2
+ 1×(-1) + 0×(-1) + 0×(-1)
= 0
```

输出不强，说明它不像水平线。

这就是卷积核的本质：

```text
不是直接理解图像
而是在每个位置问：
“这里像不像我学到的某种模式？”
```

训练时，CNN 会自动学出很多这样的模式检测器。

**六、实现细节**

在 PyTorch 中，一个典型卷积层是：

```python
import torch
from torch import nn

conv = nn.Conv2d(
    in_channels=3,
    out_channels=64,
    kernel_size=3,
    stride=1,
    padding=1,
)
```

含义是：

```text
输入有 3 个通道
输出 64 个通道
每个卷积核大小是 3 × 3
每次滑动 1 格
边缘补 1 圈零
```

如果输入是：

```python
x = torch.randn(32, 3, 224, 224)
```

形状含义：

```text
32：batch size
3：RGB 通道
224：高度
224：宽度
```

经过卷积后：

```python
y = conv(x)
print(y.shape)
```

输出是：

```text
32 × 64 × 224 × 224
```

也就是：

```text
32 张图
每张图被提取出 64 种空间特征
空间尺寸仍然是 224 × 224
```

---

一个简单 CNN 可以写成：

```python
model = nn.Sequential(
    nn.Conv2d(3, 32, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.MaxPool2d(kernel_size=2),

    nn.Conv2d(32, 64, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.MaxPool2d(kernel_size=2),

    nn.Flatten(),
    nn.Linear(64 * 56 * 56, 10),
)
```

如果输入是 `224 × 224`：

```text
输入：3 × 224 × 224
↓
Conv：32 × 224 × 224
↓
MaxPool：32 × 112 × 112
↓
Conv：64 × 112 × 112
↓
MaxPool：64 × 56 × 56
↓
Flatten：64 * 56 * 56
↓
Linear：10 类得分
```

训练过程：

```text
前向传播：
图像经过卷积、激活、池化，得到类别预测

计算损失：
预测结果和真实标签比较，比如交叉熵损失

反向传播：
自动求导计算每个卷积核参数的梯度

参数更新：
优化器调整卷积核，让它们更擅长提取有用特征
```

重要的是：卷积核不是人工设计好的，而是通过损失函数和反向传播学出来的。

---

**性能特点**

CNN 高效，主要因为参数少。

如果用全连接层处理一张 `224 × 224 × 3` 图片，输入维度是：

```text
224 × 224 × 3 = 150528
```

如果连接到 1000 个隐藏单元，参数量约为：

```text
150528 × 1000 = 150,528,000
```

非常大。

但如果用 64 个 `3 × 3` 卷积核：

```text
64 × 3 × 3 × 3 = 1728
```

参数量小得多。

CNN 之所以能用少量参数做图像任务，是因为它利用了图像的结构先验：

```text
局部性
权重共享
空间层级
平移等变
```

这不是“模型偷懒”，而是把图像任务中非常合理的假设写进了模型结构。

---

**七、本质总结**

如果只保留一句话：

> CNN 的本质是：用可学习的局部模式检测器在图像上共享地滑动，逐层把像素组合成边缘、纹理、部件和语义，从而高效理解具有空间结构的数据。
