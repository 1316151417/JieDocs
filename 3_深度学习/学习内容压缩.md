# 一、Transformer

## 极简总结
### 是什么
Transformer 是一种以注意力为核心、可并行处理序列的神经网络架构。

### 为什么
RNN 必须按顺序处理 token，难以并行；相距较远的信息还要经过多步传递，容易损失。

### 怎么做
每个 token 根据相关性对同一序列中其他 token 的信息加权汇总，直接获得上下文；多头注意力学习不同关系，位置编码补充顺序信息。

### 一句话
Transformer 是一种以自注意力为核心的神经网络架构。它让每个 token 直接按相关性汇总序列中其他 token 的信息，从而建立上下文关系，避免 RNN 的逐步传递并支持并行计算；位置编码则用于补充顺序信息。


## 展开1-自注意力
- 是什么：让同一序列中的每个 Token 动态聚合其他 Token 信息的机制。
- 为什么：使 Token 无需经过递归传递，就能直接获取上下文、建立远距离联系并支持并行计算。
- 怎么做：将 Token 转换为 Q、K、V → 用 Q 与各 K 计算相关性 → 按相关性加权汇总 V → 得到包含上下文的新表示。
