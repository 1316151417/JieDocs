# 第11章 自监督与对比学习

> **核心问题**：如何利用大量无标注数据？如何学习通用表示？

---

## 11.1 自监督学习概述

### 11.1.1 什么是自监督学习

**定义**：从数据本身构造监督信号，无需人工标注

**核心思想**：设计预训练任务（Pretext Task），让模型学习有用的表示

**与无监督学习的区别**：
- 无监督学习：发现数据结构（聚类、降维）
- 自监督学习：构造伪标签进行监督学习

### 11.1.2 为什么需要自监督学习

**问题**：
- 标注数据昂贵且稀缺
- 无标注数据大量存在
- 预训练表示可以迁移到下游任务

**优势**：
- 利用海量无标注数据
- 学习通用表示
- 减少对标注数据的依赖

## 11.2 对比学习

### 11.2.1 核心思想

**目标**：让相似样本的表示接近，不相似样本的表示远离

**InfoNCE损失**：
```
L = -log [exp(sim(zᵢ, zⱼ)/τ) / Σₖ exp(sim(zᵢ, zₖ)/τ)]
```

其中：
- zᵢ, zⱼ：正样本对
- zₖ：负样本
- τ：温度参数

### 11.2.2 SimCLR

**框架**：
```
图像 → [数据增强1] → [编码器] → [投影头] → z₁
图像 → [数据增强2] → [编码器] → [投影头] → z₂
```

**关键组件**：
1. **数据增强**：随机裁剪、颜色抖动、高斯模糊等
2. **编码器**：ResNet等骨干网络
3. **投影头**：MLP，将表示投影到对比空间

**训练过程**：
1. 对同一图像生成两个增强视图
2. 最大化同一图像不同视图的相似度
3. 最小化不同图像的相似度

**关键发现**：
- 数据增强的选择至关重要
- 投影头对性能有重要影响
- 大batch size效果更好

### 11.2.3 MoCo

**核心思想**：使用动量编码器维护一致的负样本队列

**架构**：
```
查询编码器（快速更新）→ q
动量编码器（慢速更新）→ k
负样本队列 → {k₁, k₂, ...}
```

**优势**：
- 不需要超大batch size
- 负样本数量大
- 训练稳定

### 11.2.4 BYOL

**核心思想**：不需要负样本的对比学习

**架构**：
```
在线网络：编码器 → 投影头 → 预测头 → y
目标网络：编码器 → 投影头 → z
```

**关键**：目标网络使用动量更新

**为什么不需要负样本**：
- 预测头打破了对称性
- 动量更新提供了稳定性

## 11.3 预训练语言模型

### 11.3.1 掩码语言模型（MLM）

**BERT的预训练任务**：

**输入**：`The [MASK] sat on the [MASK]`
**目标**：预测被遮罩的词

**实现**：
- 随机遮罩15%的token
- 80%替换为[MASK]
- 10%替换为随机词
- 10%保持不变

**损失函数**：
```
L = -Σ log P(x_mask | x_context)
```

### 11.3.2 下一句预测（NSP）

**任务**：判断两个句子是否是连续的

**正样本**：连续的两个句子
**负样本**：随机拼接的两个句子

**作用**：学习句子间的关系

### 11.3.3 自回归语言模型

**GPT的预训练任务**：

**输入**：`The cat sat on the`
**目标**：预测下一个词 `mat`

**损失函数**：
```
L = -Σ log P(xₜ | x_{<t})
```

**优势**：
- 适合生成任务
- 可以自然地生成文本

### 11.3.4 BERT vs GPT

| 特性 | BERT | GPT |
|------|------|-----|
| 注意力方向 | 双向 | 单向（从左到右） |
| 预训练任务 | MLM + NSP | 自回归LM |
| 适合任务 | 理解任务 | 生成任务 |
| 微调方式 | 添加任务头 | Prompt |

## 11.4 视觉-语言预训练

### 11.4.1 CLIP

**核心思想**：对比学习连接图像和文本

**架构**：
```
图像 → [图像编码器] → v
文本 → [文本编码器] → t
```

**训练目标**：
- 匹配的图像-文本对相似度高
- 不匹配的相似度低

**零样本能力**：
```
图像特征与"A photo of a cat"的相似度
图像特征与"A photo of a dog"的相似度
→ 选择相似度高的类别
```

### 11.4.2 ALIGN

**特点**：
- 使用大规模噪声图像-文本对
- 简单的对比学习框架
- 数据规模弥补数据质量

### 11.4.3 BLIP

**创新**：
- 统一的理解-生成框架
- 自举的字幕生成
- 过滤噪声数据

---

## 11.5 视觉自监督学习

### 11.5.1 MAE（Masked Autoencoder）

**核心思想**：遮罩图像的大部分区域，让模型重建

**架构**：
```
输入图像 → [遮罩75%] → [编码器] → [解码器] → 重建图像
```

**关键发现**：
- 遮罩比例可以很高（75%）
- 编码器只处理可见patches
- 解码器重建被遮罩的patches

### 11.5.2 DINO

**核心思想**：自蒸馏，不需要负样本

**架构**：
```
学生网络 → [增强视图1] → p_s
教师网络 → [增强视图2] → p_t
```

**损失函数**：
```
L = -p_t log p_s
```

**特点**：
- 教师网络使用动量更新
- 中心化防止模式崩溃
- 学习到语义特征

### 11.5.3 DINOv2

**改进**：
- 更大规模数据
- 更好的数据清洗
- 更强的视觉表示

## 11.6 预训练-微调范式

### 11.6.1 两阶段范式

**阶段1：预训练**
- 在大规模无标注数据上训练
- 学习通用表示

**阶段2：微调**
- 在下游任务有标注数据上训练
- 适应特定任务

### 11.6.2 预训练的优势

1. **数据效率**：减少下游任务的标注需求
2. **泛化能力**：学到的表示更通用
3. **收敛速度**：微调收敛更快

### 11.6.3 微调策略

**全量微调**：更新所有参数
**部分微调**：只更新部分层
**适配器**：添加少量新参数

## 11.7 实践建议

### 11.7.1 预训练任务选择

| 任务类型 | 推荐预训练任务 |
|----------|---------------|
| 文本理解 | MLM（BERT） |
| 文本生成 | 自回归LM（GPT） |
| 图像理解 | MAE、DINO |
| 图像-文本 | CLIP |

### 11.7.2 数据增强策略

**图像**：
- 随机裁剪 + 翻转
- 颜色抖动
- 高斯模糊
- Solarization

**文本**：
- 随机遮罩
- 同义词替换
- 回译

### 11.7.3 训练技巧

1. **大batch size**：对比学习需要大量负样本
2. **长训练**：自监督学习需要更多epoch
3. **温度参数**：对比学习中很重要
4. **投影头**：对性能有重要影响
