# 线性神经网络

## 背景

在深度学习的发展历程中，研究者需要一个**结构清晰、理论完备**的起点来理解神经网络的训练机制。**线性模型**——包括线性回归和Softmax回归——恰好扮演了这个角色。它们既是最古老的统计学习工具，又可以被重新诠释为最简单的神经网络。通过将线性模型纳入神经网络的统一框架，我们能在最简结构中完整走通**模型定义、损失计算、优化更新、泛化评估**的全链路，为后续理解深层网络奠定不可替代的基础。

## 问题

- 如何用**线性关系**对连续值进行预测？
- 损失函数的**数学本质**是什么，为什么选择它？
- 如何高效地在大规模数据上**迭代优化**模型参数？
- 如何将线性模型推广到**多分类**任务？
- 如何量化模型的**泛化能力**而非仅仅拟合训练数据？

## 解决方案

### 线性回归：最浅的神经网络

线性回归的本质是**仿射变换**——输入特征的加权和加上偏置。从神经网络视角看，它就是一个**单层全连接网络**，每个输入通过一个权重连接到输出。这个等价关系意义重大：它说明神经网络并非全新的范式，而是经典统计模型的自然延伸。

损失函数的选择并非随意。**平方误差**损失与假设噪声服从**正态分布**时的极大似然估计等价——这一联系揭示了损失函数背后有深层的概率论动机，而非仅仅是工程上的便利。

### 小批量随机梯度下降

训练的核心是**小批量随机梯度下降（Mini-batch SGD）**。其思想是：每次从数据中随机抽取一小批样本，计算这批样本上的梯度，沿负梯度方向更新参数。

三个要素共同决定训练行为：
- **批量大小**：影响梯度估计的噪声水平和计算效率的平衡
- **学习率**：控制每步更新的幅度，过大会震荡，过小会收敛缓慢
- **迭代轮数**：决定在数据集上遍历的次数

这种方法避免了全量梯度计算的高昂代价，同时保留了随机性带来的探索能力。

### Softmax回归：线性模型的分类推广

将线性模型从回归推广到分类，核心挑战在于输出的**解释方式**不同：回归输出是实数，分类输出需要是**概率分布**。

解决路径如下：

```mermaid
flowchart LR
    A[原始输入] --> B[仿射变换\n得到 logits]
    B --> C[Softmax 运算\n转化为概率]
    C --> D[交叉熵损失\n衡量预测质量]
```

**Softmax运算**将任意实数向量映射为合法的概率分布：对每个分量求指数确保非负，再除以总和实现归一化。它不改变原始输出的排序关系，因此预测时可直接取argmax。

**交叉熵损失**衡量模型预测分布与真实标签分布之间的差异。由于标签采用**独热编码**，损失简化为对真实类别对应概率取负对数。从信息论视角，交叉熵表示"用模型分布去编码真实分布时的额外代价"——当两者一致时代价最小。

### 评估：从训练损失到泛化能力

模型在训练集上的表现只是手段，真正的目标是**泛化**——在未见过的数据上同样表现良好。**分类精度**是评估预测质量的直观指标，而通过在独立的**验证集**上调优超参数（如学习率、批量大小），可以避免过拟合训练集。

## 效果

线性神经网络虽然表达能力有限，但它实现了三个本质性贡献：

- **统一了传统统计模型与神经网络**：线性回归和Softmax回归被证明分别等价于单层回归网络和单层分类网络，消除了"机器学习"与"深度学习"之间的人为割裂
- **建立了完整的训练范式**：数据处理 -> 模型定义 -> 损失函数 -> 优化算法 -> 训练迭代 -> 泛化评估，这一流程贯穿整个深度学习
- **揭示了关键设计原则**：损失函数不是随意选择的，而是与数据的概率假设紧密耦合；优化不是穷举，而是在噪声梯度引导下的高效近似；训练损失下降不等于模型好用，泛化才是最终衡量标准

这些洞见在深层网络中同样成立，线性模型因此不仅是起点，更是理解整个深度学习体系的**参照系**。
