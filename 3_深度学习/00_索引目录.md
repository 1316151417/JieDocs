## 核心发现摘要

本报告的知识体系基于以下经过验证的核心发现：

### 深度学习的本质与成功因素
1. **深度学习的定义**：模型由多层连续数据变换层层串联组成（d2l.ai）
2. **大数据驱动**：从小数据到大数据的范式转变是现代深度学习成功的主要因素（d2l.ai）
3. **层次化抽象**：多层处理层学习多级抽象的数据表示，在语音、视觉、药物发现等领域带来突破（LeCun, Bengio & Hinton, Nature 2015）

### 优化与训练
4. **梯度优化不可替代**：随机搜索在CIFAR-10上仅达15.5%准确率，梯度方法远优（CS231n）
5. **解析梯度必须使用**：数值梯度O(N)复杂度不可行，30,730参数需30,731次损失评估（CS231n）
6. **学习率是最关键超参数**：过小、最优、过大三种行为决定训练成败（CS231n）

### 关键架构突破
7. **残差学习**：解决深层网络退化问题（非过拟合），ResNet-152达3.57% top-5错误率，ILSVRC 2015冠军，COCO检测/分割冠军（He et al., CVPR 2016）
8. **Transformer**：纯注意力机制超越RNN/CNN编码器-解码器，WMT 2014 EN-DE达28.4 BLEU（Vaswani et al., NeurIPS 2017）
9. **注意力机制**：解决Seq2Seq的固定长度向量信息瓶颈问题（Bahdanau et al., ICLR 2015）

## 术语表

| 术语 | 英文 | 定义 |
|------|------|------|
| 深度学习 | Deep Learning | 多层连续数据变换层层串联，自动学习层次化表示 |
| 反向传播 | Backpropagation | 通过链式法则递归计算梯度的算法 |
| 残差学习 | Residual Learning | 学习相对于输入的残差函数，解决深层网络退化问题 |
| 注意力机制 | Attention | 动态加权不同位置信息的机制 |
| 退化问题 | Degradation Problem | 深层网络训练误差高于浅层网络（非过拟合），由优化困难导致 |
| 信息瓶颈 | Information Bottleneck | 将变长序列压缩到固定长度向量导致的信息损失 |
| 预训练 | Pre-training | 在大规模无标注数据上学习通用表示 |
| 微调 | Fine-tuning | 在下游任务上调整预训练模型参数 |
| 梯度消失 | Vanishing Gradient | 深层网络中梯度逐层衰减的问题 |
| 过拟合 | Overfitting | 模型在训练集上表现好但泛化差 |
| 分段线性 | Piecewise-linear | 由max(0,.)等算子导致的损失函数结构 |
