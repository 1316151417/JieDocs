# 《深度学习基础》问题驱动知识地图

## 一、领域本质

**深度学习本质在研究：如何让计算机从原始数据中自动学习出多层次的抽象表示，从而解决复杂的预测与决策问题？**

传统编程需要人明确写出规则（if-else），但面对图像识别、语音理解、自然语言处理等问题时，人类自己也不知道规则是什么——我们识别一张猫的图片靠的是直觉而非明确的公式。深度学习的核心突破在于：**不写规则，而是让计算机从大量例子中自己"悟出"规则**。而随着层数加深，网络能自动从像素→边缘→纹理→部件→物体这样的层次结构中提取越来越抽象的特征，这就是"深度"学习的根本意义。

---

## 二、核心问题树

```
深度学习试图回答的根本问题：
如何让计算机从原始数据中自动学习，做出准确预测？
│
├── Q1: 数据如何进入计算机？【数据层】
│   ├── 现实世界的数据（图像、文本、表格）如何表示为数学对象？
│   │   └── 张量（Tensor）—— N维数组，统一所有数据形态
│   ├── 原始数据不干净、格式不统一怎么办？
│   │   └── 数据预处理：缺失值填充、标准化、类别编码
│   └── 后续所有数学运算（尤其是求导）如何自动化？
│       └── 自动求导机制（Autograd）—— 计算图 + 链式法则
│
├── Q2: 什么是"学习"？如何让模型从数据中学到东西？【学习机制】
│   ├── 如何衡量模型预测的好坏？
│   │   └── 损失函数（Loss Function）：L2损失（回归）、交叉熵（分类）
│   ├── 如何根据好坏程度调整模型？
│   │   └── 梯度下降（Gradient Descent）：沿 loss 下降方向更新参数
│   └── 如何高效计算所有参数的梯度？
│       └── 反向传播 + 自动求导
│
├── Q3: 最简单的模型能做什么？不能做什么？【模型能力起点】
│   ├── 预测连续数值（房价、温度）→ 线性回归
│   │   └── 局限：只能表达线性关系 y = wx + b
│   ├── 预测离散类别（猫vs狗、数字0-9）→ Softmax回归
│   │   └── 输出变成概率分布，用交叉熵衡量差距
│   │   └── 局限：决策边界仍然是线性的
│   └── 核心矛盾：现实世界的关系几乎都是非线性的——
│       单层模型表达能力严重不足
│
├── Q4: 如何突破线性限制，表达复杂模式？【引入非线性】
│   ├── 堆叠多层（多层感知机）= 多个线性变换组合
│   │   └── 问题：多层线性叠加仍然是线性
│   ├── 解决方案：在层间插入非线性激活函数（Sigmoid、Tanh、ReLU）
│   │   └── ReLU 成为主流：缓解梯度消失 + 计算简单
│   └── 新问题：层数越多、参数越多，训练越困难
│       └── → 引出 Q5（泛化）和 Q6（稳定性）
│
├── Q5: 模型能力变强了，但它是在"学"还是在"背"？【泛化问题】
│   ├── 问题本质：模型参数远多于训练样本时→ 过拟合
│   │   ├── 模型把训练数据的噪声也记住了
│   │   └── 在训练集上完美，在新数据上一塌糊涂
│   ├── 如何判断是否过拟合？
│   │   └── 划分训练集/验证集/测试集，观察学习曲线
│   ├── 如何限制模型不要学得"太细"？
│   │   ├── 权重衰减（L2正则化）：让权重尽量小，使模型更平滑
│   │   ├── Dropout：训练时随机丢弃部分神经元，强迫网络冗余表达
│   │   └── 本质：降低模型有效容量
│   └── 反向问题：模型太简单→欠拟合→需要增加容量
│       └── 关键洞察：模型容量要与数据复杂度匹配
│
├── Q6: 网络越深训练越不稳定，如何驯服深层网络？【训练稳定性】
│   ├── 深层网络的核心问题：
│   │   ├── 梯度消失：浅层权重几乎不更新（Sigmoid 的饱和区）
│   │   ├── 梯度爆炸：梯度指数级放大，参数直接崩掉
│   │   └── 根本原因：链式法则连乘导致梯度指数级变化
│   ├── 对策一：合理的权重初始化
│   │   └── Xavier / He 初始化：让每层输出的方差保持稳定
│   ├── 对策二：ReLU 替代 Sigmoid
│   │   └── 正区间梯度恒为1，不衰减
│   ├── 对策三：批量归一化（Batch Normalization）
│   │   └── 每层输入强行拉回均值为0、方差为1的正态分布
│   │   └── 作用：允许更大学习率、减少对初始化的依赖、轻微正则化
│   └── 对策四：残差连接（ResNet）
│       └── 让网络学习"残差" H(x) - x 而非直接学习 H(x)
│       └── 核心洞见：恒等映射至少不会让效果变差，层可以"选择"跳过
│
├── Q7: 当输入变为图像（高维且有空间结构），怎么办？【针对特定数据】
│   ├── 全连接层处理图像的致命缺陷：
│   │   ├── 参数爆炸：256x256图像→65536维输入，第一层就可能上亿参数
│   │   └── 丢失空间结构：像素展平后，"相邻"信息丢失
│   ├── 核心思路：利用图像的局部性和平移不变性
│   │   ├── 局部连接：每个神经元只看图像的一个小区域（卷积核）
│   │   ├── 权值共享：同一个卷积核滑过整张图，参数量极大减少
│   │   └── 这就是卷积操作（Convolution）的本质
│   ├── 如何控制卷积输出的尺寸？
│   │   ├── 填充（Padding）：边缘补零，保持空间尺寸
│   │   ├── 步幅（Stride）：控制滑动的步长，下采样
│   │   └── 多通道：用多个卷积核捕捉不同特征
│   ├── 如何进一步降低对精确位置的敏感度？
│   │   └── 池化层（Pooling）：取区域最大值/平均值
│   └── 这就构成了完整的 CNN 基本单元：卷积→激活→池化
│
├── Q8: CNN 架构如何一步步变强？【架构进化】── 每一个新架构都在解决前一个的遗留问题
│   ├── LeNet（1998）：验证了"卷积+池化+全连接"这个范式的可行性
│   ├── AlexNet（2012）：更大（5卷积+3全连接）、ReLU、GPU、Dropout
│   │   └── 解决了"数据量大、网络大时如何训练"的问题
│   ├── VGG（2014）：用3x3小卷积核重复堆叠，形成统一"块"结构
│   │   └── 解决了"如何让架构设计变得简洁规范"的问题
│   ├── NiN（2014）：引入1x1卷积做跨通道信息融合 + MLP卷积
│   │   └── 解决了"如何在不增加太多参数的情况下增强表达能力"
│   ├── GoogLeNet（2014）：Inception模块，同一层并行多种尺寸卷积
│   │   └── 解决了"如何在同一层捕获不同尺度的特征"
│   └── ResNet（2015）：残差连接 + Batch Normalization
│       └── 最终解决了"网络到底能有多深"的问题（152层！）
│
└── Q9: 如何在真实项目中组织管理这一切？【工程落地】
    ├── 如何灵活构建网络？→ 模块化构造（类似搭积木的 Block 接口）
    ├── 如何管理成千上万的参数？→ 参数管理 API（访问、初始化、共享）
    ├── 如何保存训练结果？→ 文件读写（模型序列化、加载）
    └── 如何加速训练？→ GPU 使用（CPU→GPU数据传输、并行计算）
```

## 三、问题之间的关系

### 基础问题（起点）

**Q1（数据表示）和 Q2（学习机制）是整个领域的基石。** 没有张量就无法表示数据，没有自动求导和梯度下降就无从"学习"。这两个问题解决后，才能讨论"模型能学什么"。

### 派生关系链

整个课程的问题链是一个**层层递进、环环相扣**的关系：

```
Q1（数据表示）→  Q2（学习机制）→  Q3（简单模型）→  Q4（非线性）
                                                      │
                                                    ┌─┘
                                                    ▼
                          Q4 解决了表达能力，却引发了：
                          ├── Q5（泛化问题）：表达能力越强 → 过拟合风险越大
                          └── Q6（稳定性问题）：层数越深 → 训练越不稳定
                                │
                                └── Q6 解决后，网络可以更深了 → 才有能力处理复杂数据
                                      │
                                      ▼
                                Q7（图像数据）：有了深层网络 → 才有实际能力处理图像
                                      │
                                      ▼
                                Q8（架构进化）：处理图像的过程中不断发现问题、提出新架构
                                      │
                                      ▼
                                Q9（工程落地）：所有理论都需要工程工具来支撑实践
```

### 关键交叉点

- **Q5 和 Q6 是深度学习的核心矛盾：** 既要模型足够复杂以拟合复杂数据（推动更深），又要模型足够简单以泛化（正则化），还要训练过程稳定可控（初始化、归一化）。这三个目标之间存在张力，几乎所有技术都是在这个三角张力中找平衡。

- **Q7 和 Q8 的关系不是线性的：** 卷积解决了全连接层处理图像的参数爆炸和空间信息丢失问题，但每个新架构（AlexNet→VGG→NiN→GoogLeNet→ResNet）暴露了前一个架构的新瓶颈，每一次进化都是在"如何更深更强"这条主线上解决一个具体障碍。

- **Q9（工程）不是最后才关心的：** 在课程中工程技能穿插在各阶段，因为深度学习是高度工程化的学科——理解了原理不意味着能跑出结果，参数管理、GPU加速、模型保存/加载是动手实践的前提。

## 四、领域演化主线

用 **"问题 → 解决方案 → 新问题 → 新解决方案"** 的链条描述整个领域的发展逻辑：

### 主线一：基础框架的建立

```
问题：如何让计算机"学会"而非"被编程"？
  → 解决方案：建立"数据表示 + 可微分模型 + 梯度下降"的学习范式
    → 新问题：手工算梯度太麻烦，多层网络链式法则几乎不可手工操作
      → 解决方案：计算图 + 自动求导（Autograd）
        → 奠定一切后续发展的基础
```

### 主线二：模型表达能力的跃升

```
问题：线性模型只能拟合直线，而现实世界是非线性的
  → 解决方案：堆叠多层 + 非线性激活函数（多层感知机）
    → 新问题1：模型变强了 → 开始死记硬背（过拟合）
      → 解决方案：正则化（权重衰减、Dropout）
    → 新问题2：模型变深了 → 梯度消失/爆炸，训练不动
      → 解决方案：ReLU + 合理初始化 → 批量归一化 → 残差连接
        → 最终突破深层网络的训练瓶颈
```

### 主线三：从通用到特定（图像处理）

```
问题：全连接层处理高维图像 → 参数爆炸 + 丢失空间信息
  → 解决方案：卷积操作（局部连接 + 权值共享）
    → 新问题：卷积后尺寸变化，特征位置敏感
      → 解决方案：填充/步幅控制尺寸 + 池化增加平移不变性
    → 形成基本卷积块：Conv → Activation → Pooling
```

### 主线四：CNN 架构的迭代进化

```
LeNet 证明了"卷积+池化+全连接"范式的可行性
  ↓
问题：LeNet 在手写数字上可以，但在大规模图像（ImageNet）上不行
  → AlexNet：更深（5卷积层）、ReLU、GPU加速、Dropout正则化
    ↓
问题：AlexNet 各层参数配置像手工调出来的，缺乏设计原则
  → VGG：用 3x3 卷积块规范堆叠，"块"的思想诞生
    ↓
问题：VGG 每一层只用一个尺寸的卷积核，多尺度特征捕捉不足
  → GoogLeNet：Inception 模块并行不同尺寸卷积
    ↓
同时期另一条线：NiN 解决了"全连接层作为分类头参数太多"
  → 1x1 卷积降维 + 全局平均池化替代全连接

问题贯穿始终：到底能堆多深？
  → ResNet：残差连接让训练 152 层成为可能
  → 回答了"深度"学习的终极追问：网络越深，表示能力越强，
    而残差结构让更深网络的训练不再退化
```

### 总结：一条贯穿始终的主线

整个课程六大部分，实际上围绕**一个根本张力**展开：

> **模型能力 vs 模型可控性**

| 想要更强 | 代价 | 对策 |
|---------|------|------|
| 从线性→非线性 | 过拟合 | 正则化 |
| 从浅层→深层 | 梯度不稳定 | 初始化、BN、ResNet |
| 从通用全连接→图像专用 | 设计复杂度 | 架构演变（LeNet→ResNet） |
| 从理论→实践 | 工程复杂度 | 模块化、参数管理、GPU |

**每一次突破都在解决一个由"前一次成功"带来的新问题。** 这不仅是课程内容的组织逻辑，也是整个深度学习领域的内在发展规律。
