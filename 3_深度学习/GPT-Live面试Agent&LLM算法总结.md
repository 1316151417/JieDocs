## **3、Q、K、V 为什么存在？**

### **你的回答**

你讲成了：

Q 查询

K 匹配

V 输出

这是流程。

但是没有回答：

**为什么要设计成三个矩阵？**

---

### **推荐回答**

一句话：

Q、K、V 的目的，是把”查询”“匹配”“信息传递”拆成三个可学习空间，提高表达能力。

然后解释：

Q：

我要找什么。

K：

我能提供什么。

V：

找到以后应该带走什么信息。

最后一句：

如果直接用输入向量计算，相当于把三种能力绑定在一起，表达能力会下降。

基本正确。

K 用来计算 Attention，V 用来传递信息，所以最后一定乘 V。

一句话结束。

## **5、LayerNorm 为什么存在？**

### **你的回答**

主要意思：

训练稳定。

这个方向正确。

但是：

你说成了：

每层都会指数增长。

这一句不准确。

---

### **推荐回答**

一句话：

LayerNorm 的作用是稳定每一层的数据分布，提高训练稳定性。

然后解释：

避免：

- 数值过大
- 数值过小
- 梯度不稳定

---

## **6、为什么 RMSNorm 可以去掉均值？**

### **你的回答**

方向正确。

但是最后：

bias 可以学回来

这一句不准确。

因为 LLaMA 的 RMSNorm 本身没有 bias。

---

### **推荐回答**

一句话：

RMSNorm 发现真正影响训练稳定性的主要是向量尺度，而不是均值。

因此：

去掉减均值。

只保留 RMS。

训练几乎没有影响。

计算更简单。

---

## **7、KV Cache 是什么？**

### **你的回答**

基本正确。

讲到了：

- K
- V
- RoPE
- 不重复计算

不错。

---

### **推荐一句话**

KV Cache 缓存历史 Token 的 K 和 V，避免每生成一个 Token 都重新计算历史信息。

然后一句：

推理复杂度因此大幅降低。

---

## **问题一：没有先说结论**

你的回答经常是：

```

```

建议改成：

```
一句话结论

↓

```

为什么 KV Cache？

错误：

K…

V…

KV Cache 的目的，是避免重复计算历史 Token。

很多问题：

其实一句话可以回答。

一个头只能学习一种关系，多头可以学习多种关系。

## **问题三：没有总结句**

很多回答结束时：

```

所以...

然后...

```

建议固定一句：

所以它真正解决的是 ______。

例如：

QKV。

最后一句：

所以 QKV 本质是在提升模型表达能力。

# **四、建议的面试回答模板（推荐长期训练）**

以后任何问题，都按照固定模板回答。

```
第一句：

一句话回答本质。

↓

第二句：

为什么这样设计。

↓

第三句：

带来了什么收益。

↓

第四句（可选）：

举一个简单例子。
```

例如：

为什么 RMSNorm？

第一句：

RMSNorm 的目标，是稳定训练，同时减少 LayerNorm 中不必要的计算。

第二句：

它发现真正重要的是控制向量尺度，而不是减均值。

第三句：

所以训练效果几乎不变，但速度更快。

结束。
