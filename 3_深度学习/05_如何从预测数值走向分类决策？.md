**一、问题定义**

“从预测数值走向分类决策”要解决的问题是：

> 模型原本只能输出一个连续数值，比如房价、温度、销量；但很多任务需要它做出离散判断，比如“这张图是 T 恤、鞋子还是包”。

也就是说，问题从：

```text
输入 → 输出一个数值
```

变成：

```text
输入 → 在多个类别中做选择
```

这很重要，因为现实中的大量智能任务本质都是分类决策：

```text
图片识别：这是什么物体？
文本分类：这句话表达什么情绪？
医疗诊断：是否患病？
风控判断：是否高风险？
推荐系统：用户会不会点击？
```

分类问题的关键，不只是“输出一个类别”，而是：

> 模型如何表达它对每个类别的信心，并根据这种信心做决策？

---

**二、问题产生原因**

最初的线性回归适合解决“预测数值”的问题：

```text
房屋面积、房龄、位置 → 房价
```

它的输出可以是任意连续值：

```text
382.6 万
17.3 度
0.82 秒
```

但分类任务不一样。比如识别图片类别：

```text
图片 → T恤 / 裤子 / 鞋 / 包
```

这里有三个根本矛盾。

**第一个矛盾：类别不是连续数值。**

如果模型输出：

```text
0.2
1.7
3.4
```

这些数值本身没有天然的分类含义。

比如类别编号：

```text
0 = T恤
1 = 裤子
2 = 鞋子
```

编号只是人为标签，不代表“鞋子比裤子大 1”，也不代表“T恤和裤子之间有数值距离”。

所以直接用回归预测类别编号是不合理的。

**第二个矛盾：分类需要比较多个可能性。**

分类不是只问：

```text
这个输入对应一个数值是多少？
```

而是问：

```text
它更像哪一类？
它属于每一类的可能性分别是多少？
```

因此模型不能只输出一个数，而应该输出一组分数：

```text
T恤：2.1
裤子：0.4
鞋子：5.7
包：1.3
```

然后再根据这些分数做选择。

**第三个矛盾：训练时不能只知道选对没选对。**

如果只看最终类别是否正确，会丢掉很多信息。

例如真实类别是“鞋子”：

```text
模型 A：鞋子得分 5.7，包得分 1.2
模型 B：鞋子得分 5.7，包得分 5.6
```

它们都预测对了，但 A 明显更确定，B 很危险。

分类模型需要一种训练信号，不仅告诉它：

```text
你选错了
```

还要告诉它：

```text
你对正确类别的信心不够
你对错误类别的信心太高
```

这就是为什么原来的数值回归方法不够用了。

---

**三、解决思路**

核心思想是：

> 不再让模型直接输出一个类别，而是先让模型为每个类别打分，再把这些分数转成“可比较的概率分布”，最后选择概率最高的类别。

也就是三步：

```text
输入
→ 每个类别一个分数
→ 每个类别一个概率
→ 选择概率最高的类别
```

这就是 Softmax 回归的基本思想。

它解决了三个问题：

```text
类别无法用单个连续值表示
→ 改为每个类别一个输出

多个类别需要相互比较
→ 用 Softmax 把分数变成概率分布

训练需要知道信心是否合理
→ 用交叉熵衡量预测分布和真实类别之间的差距
```

这里的重点不是公式，而是结构变化：

```text
回归：输出一个数值
分类：输出一组类别信心
```

---

**四、方案框架**

```text
问题
↓
模型只能预测连续数值，但分类任务需要在多个离散类别中做决策
```

```text
核心思想
↓
把“预测一个数”改成“为每个类别打一个分”，再把分数解释成类别概率
```

```text
关键机制
↓
1. 多输出
   每个类别对应一个输出分数

2. Softmax
   把任意分数转换成概率分布

3. 最大概率决策
   选择概率最高的类别作为预测结果

4. 交叉熵损失
   惩罚模型对正确类别信心不足、对错误类别信心过高
```

```text
最终效果
↓
模型可以从“数值预测器”变成“分类决策器”
既能输出最终类别，也能表达对各类别的信心
```

可以把它理解成：

```text
线性回归：
输入 → 一个预测值

Softmax 回归：
输入 → 多个类别分数 → 类别概率分布 → 分类决策
```

---

**五、与其它方案比较**

**为什么不是直接回归类别编号？**

因为类别编号没有数值意义。

```text
0 = 猫
1 = 狗
2 = 鸟
```

不能说明：

```text
狗比猫大 1
鸟比狗大 1
鸟比猫大 2
```

如果用回归去预测编号，模型会误以为类别之间存在连续距离关系，这会扭曲问题本质。

---

**为什么不是只输出最大分数类别？**

如果只输出最终类别，训练信号太粗糙。

分类模型不仅需要知道“选了谁”，还需要知道：

```text
对正确类别有多自信？
对错误类别有没有过度自信？
不同类别之间差距有多大？
```

所以需要先输出一组分数，再转成概率分布。

---

**为什么需要 Softmax？**

因为原始分数不好直接解释。

模型可能输出：

```text
T恤：3.2
鞋子：7.8
包：-1.4
```

这些只是相对分数，不是概率。

Softmax 的作用是把它们变成：

```text
T恤：较小概率
鞋子：最大概率
包：很小概率
```

并且所有类别概率加起来为 1。

这样分类决策就变成：

```text
选择概率最高的类别
```

---

**为什么需要交叉熵？**

分类任务真正关心的是：

> 模型是否把足够高的概率分给了正确类别。

交叉熵正好衡量这个问题。

如果正确类别概率高，损失低；如果正确类别概率低，损失高。它让训练目标和分类目标对齐。

---

**这个方案解决了什么？**

它完成了一个关键转换：

```text
连续数值预测
→ 多类别概率建模
→ 离散分类决策
```

所以 Softmax 回归是深度学习分类任务的基础模板。后面的 MLP、CNN、Transformer 做分类时，最后常常仍然遵循这个结构：

```text
前面的网络负责提取特征
最后一层负责输出类别分数
Softmax / 交叉熵负责分类训练
```

---

**它又带来了什么新问题？**

Softmax 回归虽然能分类，但它本身仍然是线性模型。

这意味着它能解决：

```text
类别之间大致可以用线性边界区分的问题
```

但面对复杂图像、复杂语义时会遇到限制：

```text
像素和类别之间不是简单线性关系
图像中的形状、纹理、局部结构需要更复杂的特征
线性分类器无法自动学习高级表示
```

于是新的问题出现了：

```text
如何先学出更好的特征表示，再做分类？
```

这就推动了后续模型：

```text
Softmax 回归
→ 多层感知机
→ 卷积神经网络 CNN
→ 更深、更复杂的分类模型
```

**一句话总结**

从预测数值走向分类决策，本质上是把模型输出从“一个连续值”改造成“一个类别概率分布”：

```text
不是问：这个输入对应多少？
而是问：这个输入分别属于每个类别的可能性是多少？
```

Softmax 回归的价值就在这里：它为深度学习中的分类任务建立了最基本的决策框架。
