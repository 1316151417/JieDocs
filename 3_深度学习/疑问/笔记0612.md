# **传统程序 → 传统机器学习 → 深度学习**

## **1. 三种范式的本质区别**

### **传统程序**

```text
数据 + 人工规则 → 结果
```

例如：

```python
if age >= 18:
    return 成人
```

本质：

人负责发现规律，机器负责执行规律。

---

### **传统机器学习**

```text
数据 + 人工特征 → 模型学习规则 → 结果
```

例如：

```text
房屋面积
房龄
楼层
朝向
```

这些特征由人设计。

模型：

- 逻辑回归
- 决策树
- 随机森林
- GBDT
- XGBoost
- SVM

本质：

人负责告诉机器看什么，机器负责决定如何判断。

---

### **深度学习**

```text
原始数据 → 神经网络 → 结果
```

例如：

```text
图片 → CNN → 猫
```

模型自动学习：

```text
边缘
↓
纹理
↓
局部结构
↓
物体
↓
分类
```

本质：

机器同时学习特征和规则。

---

# **2. 传统机器学习到底是什么**

主要包括：

```text
线性模型
├─ 线性回归
└─ 逻辑回归

树模型
├─ 决策树
├─ 随机森林
├─ GBDT
└─ XGBoost

核方法
└─ SVM
```

---

## **线性模型**

本质：

寻找一个超平面进行分类。

w^Tx+b=0

特点：

- 简单
- 可解释
- 表达能力有限

---

## **决策树**

本质：

```text
if ...
    if ...
        if ...
```

不断切分特征空间。

特点：

- 易解释
- 易过拟合

---

## **随机森林 / GBDT / XGBoost**

本质：

多棵树协同工作。

工业界表格数据长期霸主。

---

## **SVM**

本质：

找到分类间隔最大的决策边界。

核心思想：

```text
分类正确
+
间隔最大
```

特点：

- 小数据表现优秀
- 理论优雅
- 大规模时代逐渐被深度学习替代

---

# **3. MLP属于传统机器学习还是深度学习？**

答案：

两者都可以。

取决于它在系统中的角色。

---

## **传统机器学习时代**

```text
人工特征
↓
MLP
↓
分类
```

此时：

MLP只是分类器。

属于传统机器学习体系。

---

## **深度学习时代**

```text
原始数据
↓
MLP/CNN/Transformer
↓
结果
```

此时：

MLP负责自动学习特征。

属于深度学习体系。

---

# **4. 深度学习不是因为发明了反向传播**

很多人误解：

```text
反向传播
↓
深度学习诞生
```

实际上错误。

---

这些东西早就存在：

```text
线性回归
梯度下降
链式求导
反向传播
MLP
```

80~90年代就有。

---

真正缺少的是：

```text
海量数据
+
强大算力
+
训练技巧
+
模型设计技巧
```

例如：

- GPU
- ReLU
- Dropout
- BatchNorm
- 残差连接

---

# **5. 深度学习真正的突破是什么**

不是：

```text
梯度下降
```

不是：

```text
反向传播
```

不是：

```text
神经网络
```

这些早就存在。

---

真正的突破：

自动特征学习。

过去：

```text
图片
↓
人工设计SIFT/HOG特征
↓
SVM
```

现在：

```text
图片
↓
神经网络
↓
结果
```

特征自动产生。

---

# **6. CNN的本质**

很多人误以为：

CNN赋予了神经网络特征学习能力。

实际上：

MLP本身就有特征学习能力。

---

CNN真正做的是：

向模型注入图像领域先验知识。

即：

```text
局部相关
空间结构
平移不变
```

---

CNN核心思想：

### **局部连接**

只看局部区域：

```text
3×3
5×5
7×7
```

---

### **权重共享**

同一个边缘检测器：

```text
左上角可用
右下角也可用
```

---

收益：

```text
参数更少
训练更快
泛化更强
```

---

# **7. CNN不是特征学习的来源**

证明：

后来出现：

- MLP-Mixer
- gMLP
- Vision Transformer（ViT）

这些模型：

```text
没有卷积
```

依然可以学习图像特征。

甚至超过CNN。

---

说明：

特征学习能力来自深层神经网络本身，而非卷积。

---

# **8. 为什么CNN在当年如此重要**

假设：

```text
224×224×3 图片
```

输入维度：

```text
150,528
```

直接接MLP：

第一层参数：

```text
150,528 × 1000
≈ 1.5亿
```

极难训练。

---

CNN利用图像先验：

```text
局部连接
+
权重共享
```

参数量骤降。

因此：

```text
更容易训练
更省数据
更省算力
```

---

# **9. AlexNet成功的真正原因**

不是：

```text
因为CNN
```

CNN早在90年代就存在。

---

AlexNet成功：

```text
CNN
+
GPU
+
ReLU
+
Dropout
+
ImageNet大规模数据
```

共同作用。

# **10. AI发展的两条路线**

## **路线一：增加先验**

```text
专家规则
↓
特征工程
↓
CNN
↓
专用模型
```

核心思想：

```text
人告诉模型应该怎么学
```

---

## **路线二：增加规模**

```text
更多数据
+
更多参数
+
更多算力
```

核心思想：

```text
少加人为假设
让模型自己学
```

---

近十年主流趋势：

```text
减少人工先验
增加模型规模
```

最终走向：

```text
Transformer
+
海量数据
+
超大参数
```

即今天的大模型路线。

---

# **最终总结（一句话版）**

**传统机器学习的本质是“人工设计特征，机器学习规则”；深度学习的本质是“机器同时学习特征和规则”。CNN不是特征学习能力的来源，而是把图像领域的先验知识注入神经网络，使其在有限数据和算力下更高效地学习；随着数据、算力和训练技术的发展，深层神经网络本身已经能够通过规模化训练自动学习越来越通用的特征表示，这最终演化为今天的大模型。**
