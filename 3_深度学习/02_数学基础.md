# 第2章 数学基础

> **核心问题**：深度学习需要哪些数学知识？为什么这些数学工具如此重要？

---

## 2.1 线性代数基础

### 2.1.1 标量、向量、矩阵和张量

深度学习中的基本数据结构：

| 类型 | 定义 | 示例 | 记号 |
|------|------|------|------|
| 标量（Scalar） | 单个数值 | 学习率 λ = 0.001 | 小写斜体 |
| 向量（Vector） | 一维数组 | 输入特征 x = [1, 2, 3] | 小写粗体 |
| 矩阵（Matrix） | 二维数组 | 权重矩阵 W | 大写粗体 |
| 张量（Tensor） | 多维数组 | 图像数据（高度×宽度×通道） | - |

### 2.1.2 矩阵运算

**矩阵乘法**：
```
C = AB
C[i,j] = Σ_k A[i,k] * B[k,j]
```

**转置**：
```
(A^T)[i,j] = A[j,i]
```

**逆矩阵**：
```
A * A^{-1} = I
```

### 2.1.3 特征分解

对于方阵 A，如果存在标量 λ 和非零向量 v 使得：
```
Av = λv
```
则 λ 是 A 的**特征值**，v 是对应的**特征向量**。

**在深度学习中的应用**：
- 主成分分析（PCA）用于降维
- Hessian矩阵的特征值分析用于优化
- 理解梯度的传播行为

### 2.1.4 奇异值分解（SVD）

任何矩阵 A 可以分解为：
```
A = UΣV^T
```
其中：
- U：左奇异向量矩阵
- Σ：奇异值对角矩阵
- V：右奇异向量矩阵

**应用**：
- 矩阵低秩近似
- 模型压缩
- 推荐系统中的协同过滤

## 2.2 微积分基础

### 2.2.1 导数与梯度

**导数**：函数在某点的变化率
```
f'(x) = lim_{h→0} [f(x+h) - f(x)] / h
```

**梯度**：多元函数的导数向量
```
∇f(x) = [∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂xₙ]
```

**梯度的意义**：
- 指向函数值增长最快的方向
- 梯度的反方向是函数值下降最快的方向
- 这是梯度下降算法的基础

### 2.2.2 链式法则

**单变量链式法则**：
```
如果 y = f(g(x))，则 dy/dx = f'(g(x)) * g'(x)
```

**多变量链式法则**：
```
如果 z = f(u, v)，u = g(x)，v = h(x)
则 dz/dx = (∂z/∂u)(du/dx) + (∂z/∂v)(dv/dx)
```

**在深度学习中的核心地位**：
- 反向传播算法就是链式法则的系统应用
- 用于计算损失函数对每个参数的梯度

### 2.2.3 偏导数与方向导数

**偏导数**：固定其他变量，对某一变量求导
```
∂f/∂xᵢ = lim_{h→0} [f(x + heᵢ) - f(x)] / h
```

**方向导数**：沿任意方向的导数
```
D_uf(x) = ∇f(x) · u
```

### 2.2.4 雅可比矩阵和海森矩阵

**雅可比矩阵（Jacobian）**：
- 向量函数的一阶导数矩阵
- J[i,j] = ∂fᵢ/∂xⱼ

**海森矩阵（Hessian）**：
- 标量函数的二阶导数矩阵
- H[i,j] = ∂²f/∂xᵢ∂xⱼ

**应用**：
- 雅可比矩阵用于反向传播中的梯度计算
- 海森矩阵用于优化算法（如牛顿法）和分析损失曲面

## 2.3 概率论与信息论

### 2.3.1 基本概率概念

**概率分布**：
- 离散：概率质量函数（PMF）P(X = x)
- 连续：概率密度函数（PDF）p(x)

**常见分布**：
| 分布 | 类型 | 应用场景 |
|------|------|----------|
| 伯努利分布 | 离散 | 二分类标签 |
| 高斯分布 | 连续 | 噪声建模、权重初始化 |
| 均匀分布 | 连续 | 随机采样、初始化 |
| Softmax分布 | 离散 | 多分类输出 |

### 2.3.2 贝叶斯定理

```
P(A|B) = P(B|A) * P(A) / P(B)
```

**在深度学习中的应用**：
- 贝叶斯神经网络
- 变分推断（VAE的理论基础）
- 模型选择和正则化

### 2.3.3 信息论基础

**信息熵**（Entropy）：
```
H(X) = -Σ P(x) log P(x)
```
衡量随机变量的不确定性

**交叉熵**（Cross-Entropy）：
```
H(p, q) = -Σ p(x) log q(x)
```
衡量两个分布的差异，是分类任务中最常用的损失函数

**KL散度**（Kullback-Leibler Divergence）：
```
D_KL(p || q) = Σ p(x) log[p(x)/q(x)]
```
衡量用分布 q 近似分布 p 时的信息损失

**重要性质**：
```
H(p, q) = H(p) + D_KL(p || q)
```
当 p 是真实分布时，最小化交叉熵等价于最小化KL散度

### 2.3.4 最大似然估计

**目标**：找到使观测数据出现概率最大的参数
```
θ* = argmax_θ P(Data | θ)
```

**对数似然**：
```
θ* = argmax_θ Σ log P(xᵢ | θ)
```

**与交叉熵的关系**：
- 最大化对数似然 = 最小化负对数似然
- 负对数似然 = 交叉熵损失

## 2.4 优化基础

### 2.4.1 凸优化 vs 非凸优化

**凸优化**：
- 凸函数的局部最优就是全局最优
- 有成熟的优化算法

**非凸优化**：
- 深度学习的损失函数通常是非凸的
- 存在大量局部最优和鞍点
- 但实践中SGD等方法仍能取得好效果

### 2.4.2 梯度下降

**基本形式**：
```
θ ← θ - η * ∇L(θ)
```

**变体**：
| 方法 | 特点 |
|------|------|
| 批量梯度下降 | 使用全部数据，稳定但慢 |
| 随机梯度下降（SGD） | 使用单个样本，快但噪声大 |
| 小批量梯度下降 | 折中方案，实践中最常用 |

### 2.4.3 拉格朗日乘数法

用于求解带约束的优化问题：
```
min f(x)  s.t.  g(x) = 0
L(x, λ) = f(x) + λ * g(x)
```

**应用**：
- 支持向量机（SVM）
- 正则化的理论解释
- 对偶问题

## 2.5 数值计算注意事项

### 2.5.1 数值稳定性

**问题**：
- 浮点数精度有限
- 梯度消失和梯度爆炸
- 上溢和下溢

**解决方案**：
- 使用Log-Sum-Exp技巧：`log(Σ exp(xᵢ)) = max(x) + log(Σ exp(xᵢ - max(x)))`
- 使用数值稳定的Softmax实现
- 梯度裁剪（Gradient Clipping）

### 2.5.2 条件数

矩阵的条件数衡量其对输入扰动的敏感程度：
```
κ(A) = ||A|| * ||A^{-1}||
```
- 条件数大：矩阵病态，优化困难
- 条件数小：矩阵良态，优化稳定
