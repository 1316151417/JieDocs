# 第9章 正则化与归一化

> **核心问题**：如何防止过拟合？如何加速训练？

---

## 9.1 过拟合问题

### 9.1.1 什么是过拟合

**定义**：模型在训练集上表现好，但在测试集上表现差

**表现**：
- 训练损失持续下降
- 验证损失先降后升
- 模型记住了训练数据的噪声

### 9.1.2 过拟合的原因

1. **模型太复杂**：参数量远大于数据量
2. **数据太少**：无法覆盖数据分布
3. **训练太久**：模型逐渐记住训练数据
4. **特征太多**：包含无关特征

### 9.1.3 偏差-方差权衡

**偏差（Bias）**：模型预测与真实值的系统性偏差
**方差（Variance）：模型对不同训练数据的敏感程度

**权衡**：
- 简单模型：高偏差，低方差（欠拟合）
- 复杂模型：低偏差，高方差（过拟合）
- 理想模型：平衡偏差和方差

## 9.2 L1和L2正则化

### 9.2.1 L2正则化（权重衰减）

**目标函数**：
```
L_total = L_data + λ * Σ w²
```

**梯度更新**：
```
w ← w - η * (∂L_data/∂w + 2λw)
w ← (1 - 2ηλ) * w - η * ∂L_data/∂w
```

**效果**：
- 权重趋向于小值
- 防止某个权重过大
- 使模型更平滑

### 9.2.2 L1正则化

**目标函数**：
```
L_total = L_data + λ * Σ |w|
```

**效果**：
- 产生稀疏解（很多权重为0）
- 自动特征选择
- 模型更简洁

### 9.2.3 L1 vs L2

| 特性 | L1 | L2 |
|------|----|----|
| 解的稀疏性 | 稀疏 | 非稀疏 |
| 特征选择 | 自动 | 不自动 |
| 计算效率 | 低（不可导） | 高 |
| 适用场景 | 特征多但相关特征少 | 一般情况 |

## 9.3 Dropout

### 9.3.1 核心思想

**训练时**：随机将一部分神经元置为0
```
mask = Bernoulli(p)
output = input * mask / p
```

**测试时**：使用所有神经元，但输出乘以p
```
output = input * p
```

### 9.3.2 为什么Dropout有效

**集成学习视角**：
- 每次训练相当于训练一个子网络
- 测试时相当于集成所有子网络

**防止共适应**：
- 神经元不能依赖其他特定神经元
- 每个神经元必须学到更鲁棒的特征

### 9.3.3 Dropout的实现

```python
class Dropout(nn.Module):
    def __init__(self, p=0.5):
        super().__init__()
        self.p = p
    
    def forward(self, x):
        if self.training:
            mask = torch.bernoulli(torch.ones_like(x) * (1 - self.p))
            return x * mask / (1 - self.p)
        return x
```

### 9.3.4 Dropout的变体

**Spatial Dropout**：丢弃整个通道
**DropConnect**：丢弃连接而非神经元
**Concrete Dropout**：自动学习dropout率

## 9.4 批量归一化（Batch Normalization）

### 9.4.1 核心思想

**问题**：内部协变量偏移（Internal Covariate Shift）

**解决方案**：对每一层的输入进行归一化

**步骤**：
```
μ = (1/m) Σ xᵢ  # 计算均值
σ² = (1/m) Σ (xᵢ - μ)²  # 计算方差
x̂ = (x - μ) / √(σ² + ε)  # 归一化
y = γx̂ + β  # 缩放和平移
```

### 9.4.2 BatchNorm的优势

1. **加速训练**：可以使用更大学习率
2. **减少对初始化的敏感性**：自动调整分布
3. **正则化效果**：引入噪声
4. **缓解梯度消失**：使梯度更稳定

### 9.4.3 BatchNorm的实现

```python
class BatchNorm(nn.Module):
    def __init__(self, num_features, eps=1e-5, momentum=0.1):
        super().__init__()
        self.eps = eps
        self.momentum = momentum
        
        self.gamma = nn.Parameter(torch.ones(num_features))
        self.beta = nn.Parameter(torch.zeros(num_features))
        
        self.register_buffer('running_mean', torch.zeros(num_features))
        self.register_buffer('running_var', torch.ones(num_features))
    
    def forward(self, x):
        if self.training:
            mean = x.mean(dim=0)
            var = x.var(dim=0, unbiased=False)
            
            self.running_mean = (1 - self.momentum) * self.running_mean + self.momentum * mean
            self.running_var = (1 - self.momentum) * self.running_var + self.momentum * var
        else:
            mean = self.running_mean
            var = self.running_var
        
        x_hat = (x - mean) / torch.sqrt(var + self.eps)
        return self.gamma * x_hat + self.beta
```

### 9.4.4 BatchNorm的局限性

1. **依赖批量大小**：小batch统计不稳定
2. **序列模型不适用**：变长序列难以处理
3. **训练和测试不一致**：需要维护running statistics

## 9.5 Layer Normalization

### 9.5.1 核心思想

**与BatchNorm的区别**：
- BatchNorm：对batch维度归一化
- LayerNorm：对特征维度归一化

**公式**：
```
μ = (1/D) Σ xᵢ  # 对特征维度求均值
σ² = (1/D) Σ (xᵢ - μ)²  # 对特征维度求方差
x̂ = (x - μ) / √(σ² + ε)
y = γx̂ + β
```

### 9.5.2 LayerNorm的优势

1. **不依赖批量大小**
2. **适合序列模型**
3. **训练和测试一致**
4. **Transformer的标准配置**

### 9.5.3 实现

```python
class LayerNorm(nn.Module):
    def __init__(self, d_model, eps=1e-6):
        super().__init__()
        self.gamma = nn.Parameter(torch.ones(d_model))
        self.beta = nn.Parameter(torch.zeros(d_model))
        self.eps = eps
    
    def forward(self, x):
        mean = x.mean(-1, keepdim=True)
        var = x.var(-1, unbiased=False, keepdim=True)
        x_hat = (x - mean) / torch.sqrt(var + self.eps)
        return self.gamma * x_hat + self.beta
```

## 9.6 其他归一化方法

### 9.6.1 Instance Normalization

**特点**：对每个样本的每个通道独立归一化

**应用**：风格迁移

### 9.6.2 Group Normalization

**特点**：将通道分成组，组内归一化

**优势**：不依赖批量大小

### 9.6.3 RMS Normalization

**特点**：只除以均方根，不减均值

**应用**：LLaMA等大语言模型

x̃ = λxᵢ + (1-λ)xⱼ

将一张图像的部分区域替换为另一张图像

## 9.8 早停（Early Stopping）

### 9.8.1 核心思想

**监控验证集性能**：
- 当验证损失不再下降时停止训练
- 保存验证损失最低的模型

### 9.8.2 实现

```python
best_val_loss = float('inf')
patience_counter = 0

for epoch in range(num_epochs):
    train_loss = train_one_epoch()
    val_loss = validate()
    
    if val_loss < best_val_loss:
        best_val_loss = val_loss
        patience_counter = 0
        save_checkpoint()
    else:
        patience_counter += 1
    
    if patience_counter >= patience:
        print("Early stopping")
        break
```

## 9.9 标签平滑（Label Smoothing）

### 9.9.1 核心思想

**硬标签**：[0, 0, 1, 0, 0]
**软标签**：[0.025, 0.025, 0.9, 0.025, 0.025]

**公式**：
```
y_smooth = y * (1 - ε) + ε / K
```

### 9.9.2 效果

- 防止模型过于自信
- 提高泛化能力
- 提高模型校准
