# 第7章 生成模型

> **核心问题**：如何让机器生成新的数据？生成模型的原理是什么？

## 7.1 生成模型概述

### 7.1.1 什么是生成模型

**定义**：学习数据分布 P(x) 的模型，可以从中采样生成新样本

**与判别模型的区别**：
| 类型 | 目标 | 示例 |
|------|------|------|
| 判别模型 | P(y\|x) | 分类器 |
| 生成模型 | P(x) 或 P(x,y) | 生成器 |

### 7.1.2 生成模型的应用

- 图像生成
- 文本生成
- 数据增强
- 异常检测
- 药物设计

## 7.2 自编码器（Autoencoder）

### 7.2.1 基本结构

```
输入 → [编码器] → 潜在表示 → [解码器] → 重建输出
```

**目标**：最小化重建误差
```
L = ||x - x̂||²
```

### 7.2.2 变分自编码器（VAE）

**核心思想**：将潜在空间正则化为高斯分布

**编码器输出**：均值μ和方差σ²
```
z = μ + σ * ε，ε ~ N(0, I)
```

**损失函数**：
```
L = 重建损失 + KL散度
L = ||x - x̂||² + D_KL(q(z|x) || p(z))
```

**KL散度的作用**：使潜在分布接近标准正态分布

### 7.2.3 VAE的数学推导

**证据下界（ELBO）**：
```
log p(x) ≥ E_q[log p(x|z)] - D_KL(q(z|x) || p(z))
```

最大化ELBO = 最大化对数似然的下界

## 7.3 生成对抗网络（GAN）

### 7.3.1 GAN的核心思想

**博弈论视角**：
- **生成器G**：生成假样本，试图欺骗判别器
- **判别器D**：区分真假样本

**目标函数**：
```
min_G max_D V(D, G) = E_x~p_data[log D(x)] + E_z~p_z[log(1 - D(G(z)))]
```

### 7.3.2 训练过程

**交替训练**：
1. 固定G，训练D：最大化判别准确率
2. 固定D，训练G：最小化log(1 - D(G(z)))

**直觉**：
- D像警察，试图识别假币
- G像造假者，试图制造以假乱真的假币
- 两者相互竞争，共同进步

### 7.3.3 GAN的训练技巧

**问题1：模式崩溃（Mode Collapse）**
- G只生成少数几种样本
- 解决方案：WGAN、谱归一化

**问题2：训练不稳定**
- G和D的平衡很难维持
- 解决方案：渐进式训练、谱归一化

**问题3：梯度消失**
- D太强时，G的梯度消失
- 解决方案：WGAN使用Wasserstein距离

### 7.3.4 GAN的变体

**DCGAN（Deep Convolutional GAN）**：
- 使用卷积层替代全连接层
- 成为图像生成的标准架构

**WGAN（Wasserstein GAN）**：
- 使用Wasserstein距离替代JS散度
- 训练更稳定

**StyleGAN**：
- 引入风格控制
- 可以控制生成图像的各种属性

**CycleGAN**：
- 无配对的图像风格转换
- 使用循环一致性损失

## 7.4 扩散模型（Diffusion Models）

### 7.4.1 核心思想

**前向过程**：逐步添加噪声
```
x_t = √(α_t) * x_{t-1} + √(1-α_t) * ε
```

**反向过程**：逐步去噪
```
x_{t-1} = (1/√α_t) * (x_t - (1-α_t)/√(1-ᾱ_t) * ε_θ(x_t, t))
```

### 7.4.2 数学原理

**前向过程的闭式解**：
```
x_t = √(ᾱ_t) * x_0 + √(1-ᾱ_t) * ε
```

**训练目标**：预测噪声
```
L = E[||ε - ε_θ(x_t, t)||²]
```

### 7.4.3 DDPM（Denoising Diffusion Probabilistic Models）

**关键创新**：
- 简化了扩散过程
- 使用固定的噪声调度
- 训练目标是预测噪声

**采样过程**：
```
for t = T, T-1, ..., 1:
    z ~ N(0, I) if t > 1 else 0
    x_{t-1} = (1/√α_t) * (x_t - (1-α_t)/√(1-ᾱ_t) * ε_θ(x_t, t)) + σ_t * z
```

### 7.4.4 扩散模型的优势

- 训练稳定（不像GAN有模式崩溃）
- 生成质量高
- 理论基础扎实
- 可以精确计算似然

### 7.4.5 扩散模型的加速

**问题**：采样需要很多步（通常1000步）

**解决方案**：
- DDIM：确定性采样，减少步数
- DPM-Solver：高阶求解器
- 一致性模型：一步生成

## 7.5 Flow模型

### 7.5.1 核心思想

**可逆变换**：学习一个可逆的映射
```
z = f(x)  ↔  x = f^{-1}(z)
```

**变量替换公式**：
```
p(x) = p(z) * |det(df/dx)|
```

### 7.5.2 RealNVP

**仿射耦合层**：
```
y1 = x1
y2 = x2 * exp(s(x1)) + t(x1)
```

**特点**：
- 可逆
- 雅可比行列式容易计算

### 7.5.3 Glow

**创新**：
- 可逆1×1卷积
- 多尺度架构
- 高质量图像生成

---

## 7.6 自回归模型

### 7.6.1 核心思想

**链式法则**：
```
p(x) = Π_i p(x_i | x_{<i})
```

**逐个生成**：按顺序生成每个元素

### 7.6.2 PixelCNN

**结构**：
- 使用掩码卷积
- 只能看到已生成的像素
- 逐像素生成图像

### 7.6.3 GPT（生成预训练Transformer）

**特点**：
- 使用Transformer解码器
- 掩码自注意力
- 预测下一个token

---

## 7.7 生成模型的比较

| 模型 | 优点 | 缺点 |
|------|------|------|
| VAE | 训练稳定，有理论基础 | 生成质量较低 |
| GAN | 生成质量高，速度快 | 训练不稳定，模式崩溃 |
| 扩散模型 | 生成质量高，训练稳定 | 采样速度慢 |
| Flow模型 | 可精确计算似然 | 模型复杂 |
| 自回归模型 | 可精确计算似然 | 生成速度慢 |

## 7.8 实践示例：用PyTorch实现简单GAN

```python
import torch
import torch.nn as nn

class Generator(nn.Module):
    def __init__(self, latent_dim, img_dim):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(latent_dim, 256),
            nn.LeakyReLU(0.2),
            nn.Linear(256, 512),
            nn.LeakyReLU(0.2),
            nn.Linear(512, img_dim),
            nn.Tanh()
        )
    
    def forward(self, z):
        return self.net(z)

class Discriminator(nn.Module):
    def __init__(self, img_dim):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(img_dim, 512),
            nn.LeakyReLU(0.2),
            nn.Linear(512, 256),
            nn.LeakyReLU(0.2),
            nn.Linear(256, 1),
            nn.Sigmoid()
        )
    
    def forward(self, x):
        return self.net(x)
```
