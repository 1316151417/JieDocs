# 第5章 循环神经网络与序列模型

> **核心问题**：如何处理序列数据？注意力机制如何解决信息瓶颈问题？

---

## 5.1 序列数据的特点

### 5.1.1 什么是序列数据

序列数据是有序的数据集合，每个元素依赖于前面的元素：

- **自然语言**：句子中的词语顺序
- **时间序列**：股票价格、天气数据
- **语音**：音频信号的时间序列
- **DNA序列**：基因序列

### 5.1.2 序列建模的挑战

1. **变长输入**：不同序列长度不同
2. **长程依赖**：序列中相距较远的元素可能有重要关联
3. **时序顺序**：顺序很重要，打乱顺序会改变含义

---

## 5.2 循环神经网络（RNN）

### 5.2.1 基本RNN结构

**核心思想**：网络有记忆，可以记住之前的信息

```
h_t = tanh(W_hh * h_{t-1} + W_xh * x_t + b_h)
y_t = W_hy * h_t + b_y
```

其中：
- `x_t`：时间步t的输入
- `h_t`：时间步t的隐藏状态
- `y_t`：时间步t的输出

**展开形式**：
```
x_1 -> [RNN] -> h_1 -> [RNN] -> h_2 -> ... -> [RNN] -> h_T
```

### 5.2.2 RNN的参数共享

**关键特点**：所有时间步共享相同的参数
- W_xh：输入到隐藏的权重
- W_hh：隐藏到隐藏的权重
- W_hy：隐藏到输出的权重

**优势**：
- 可以处理任意长度的序列
- 参数量不随序列长度增加

### 5.2.3 RNN的训练：BPTT

**时间反向传播**（Backpropagation Through Time）：

1. 前向传播：计算所有时间步的输出和损失
2. 反向传播：从最后一个时间步开始，向前计算梯度
3. 参数更新：汇总所有时间步的梯度

**梯度计算**：
```
dL/dW_hh = Sigma_t dL_t/dW_hh
```

---

## 5.3 梯度消失与梯度爆炸

### 5.3.1 问题描述

**梯度消失**：
```
dh_t/dh_k = Prod_{i=k+1}^t dh_i/dh_{i-1}
```

如果 `||dh_i/dh_{i-1}|| < 1`，梯度会指数级衰减。

**梯度爆炸**：
如果 `||dh_i/dh_{i-1}|| > 1`，梯度会指数级增长。

### 5.3.2 解决方案

**梯度裁剪**（Gradient Clipping）：
```
if ||g|| > threshold:
    g = threshold * g / ||g||
```

**更好的架构**：LSTM和GRU

---

## 5.4 长短期记忆网络（LSTM）

### 5.4.1 LSTM的核心思想

LSTM通过**门控机制**选择性地记住或忘记信息：

**三个门**：
1. **遗忘门**（Forget Gate）：决定忘记什么
2. **输入门**（Input Gate）：决定记住什么
3. **输出门**（Output Gate）：决定输出什么

### 5.4.2 LSTM的数学公式

```
f_t = sigma(W_f * [h_{t-1}, x_t] + b_f)  # 遗忘门
i_t = sigma(W_i * [h_{t-1}, x_t] + b_i)  # 输入门
g_t = tanh(W_g * [h_{t-1}, x_t] + b_g)   # 候选记忆
o_t = sigma(W_o * [h_{t-1}, x_t] + b_o)  # 输出门

c_t = f_t * c_{t-1} + i_t * g_t           # 更新记忆
h_t = o_t * tanh(c_t)                      # 输出
```

### 5.4.3 LSTM如何解决梯度消失

**关键**：记忆单元c_t的更新是**加法**而非乘法

```
c_t = f_t * c_{t-1} + i_t * g_t
```

梯度可以通过记忆单元直接传播，不会指数衰减。

---

## 5.5 门控循环单元（GRU）

### 5.5.1 GRU的简化

GRU是LSTM的简化版本，只有两个门：

```
z_t = sigma(W_z * [h_{t-1}, x_t])        # 更新门
r_t = sigma(W_r * [h_{t-1}, x_t])        # 重置门

h_tilde_t = tanh(W * [r_t * h_{t-1}, x_t])  # 候选隐藏状态
h_t = (1 - z_t) * h_{t-1} + z_t * h_tilde_t # 最终隐藏状态
```

### 5.5.2 LSTM vs GRU

| 特性 | LSTM | GRU |
|------|------|-----|
| 门的数量 | 3个 | 2个 |
| 参数量 | 更多 | 更少 |
| 训练速度 | 较慢 | 较快 |
| 效果 | 通常更好 | 相当 |

## 5.6 双向RNN

### 5.6.1 为什么需要双向

**问题**：单向RNN只能利用过去的信息

**例子**：
- "我住在巴黎，[MASK]是法国的首都"
- 需要同时利用前文和后文

### 5.6.2 双向RNN结构

```
前向：h_t-> = RNN->(x_t, h_{t-1}->)
后向：h_t<- = RNN<-(x_t, h_{t+1}<-)
输出：h_t = [h_t->; h_t<-]
```

---

## 5.7 深层RNN

### 5.7.1 多层RNN

```
第1层：h_t^{(1)} = RNN^{(1)}(x_t, h_{t-1}^{(1)})
第2层：h_t^{(2)} = RNN^{(2)}(h_t^{(1)}, h_{t-1}^{(2)})
...
```

**应用**：
- 机器翻译通常使用4-8层
- 需要Dropout等正则化技术

---

## 5.8 序列到序列模型（Seq2Seq）

### 5.8.1 编码器-解码器架构

```
编码器：将输入序列编码为固定长度向量
解码器：从向量生成输出序列
```

**结构**：
```
输入序列 -> [编码器RNN] -> 上下文向量 -> [解码器RNN] -> 输出序列
```

### 5.8.2 Seq2Seq的应用

- 机器翻译
- 文本摘要
- 对话系统
- 语音识别

### 5.8.3 信息瓶颈问题

将整个源句子压缩成固定长度向量是一个瓶颈，会降低编码器-解码器神经机器翻译的性能，尤其对于较长的句子。

> "We conjecture that the use of a fixed-length vector is a bottleneck in improving the performance of this basic encoder-decoder approach."
> — Bahdanau, Cho & Bengio, *Neural Machine Translation by Jointly Learning to Align and Translate* (arXiv:1409.0473)

这一发现在该论文的长度分层实验中得到了验证：当句子长度超过20-30个词时，BLEU分数显著下降。Cho等人（2014）也独立记录了同样的句子长度退化现象，Sutskever等人（2014）则通过反转句子顺序来缓解这一限制。注意力机制的发明正是为了解决这一瓶颈。

---

## 5.9 注意力机制的起源

### 5.9.1 注意力的核心思想

**问题**：解码器应该关注输入的哪个部分？

**解决方案**：为每个解码步骤动态加权输入

### 5.9.2 Bahdanau注意力

```
e_{t,i} = score(s_{t-1}, h_i)
alpha_{t,i} = softmax(e_{t,i})
c_t = Sigma_i alpha_{t,i} * h_i
```

其中：
- `s_{t-1}`：解码器前一时刻的状态
- `h_i`：编码器第i个位置的输出
- `score`：对齐函数（可以是点积、MLP等）

### 5.9.3 注意力的意义

- 解决了信息瓶颈问题
- 提供了可解释性（可以看到关注了哪些词）
- 为Transformer奠定了基础

## 5.10 实践示例：用PyTorch实现LSTM

```python
import torch
import torch.nn as nn

class LSTMClassifier(nn.Module):
    def __init__(self, vocab_size, embed_dim, hidden_dim, num_classes):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.lstm = nn.LSTM(embed_dim, hidden_dim, batch_first=True)
        self.fc = nn.Linear(hidden_dim, num_classes)

    def forward(self, x):
        # x: (batch_size, seq_length)
        embedded = self.embedding(x)  # (batch_size, seq_length, embed_dim)
        output, (hidden, cell) = self.lstm(embedded)
        # hidden: (1, batch_size, hidden_dim)
        return self.fc(hidden.squeeze(0))

# 使用示例
model = LSTMClassifier(vocab_size=10000, embed_dim=128, hidden_dim=256, num_classes=2)
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(model.parameters())

# 训练
for batch_x, batch_y in dataloader:
    outputs = model(batch_x)
    loss = criterion(outputs, batch_y)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
```

## 5.11 本章小结

| 要点 | 内容 |
|------|------|
| RNN | 处理序列数据的基础架构 |
| LSTM | 通过门控机制解决梯度消失 |
| GRU | LSTM的简化版本 |
| Seq2Seq | 编码器-解码器架构，存在信息瓶颈 |
| 信息瓶颈 | 固定长度向量限制翻译性能，尤其对长句子 |
