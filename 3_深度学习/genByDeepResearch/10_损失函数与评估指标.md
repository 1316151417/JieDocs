# 第10章 损失函数与评估指标

> **核心问题**：如何定义"好"的模型？如何衡量模型性能？

---

## 10.1 损失函数概述

### 10.1.1 损失函数的作用

**目标**：衡量模型预测与真实值的差距

**优化目标**：
```
min_θ L(θ) = (1/N) Σ loss(f(xᵢ; θ), yᵢ)
```

### 10.1.2 损失函数的选择原则

1. **可微性**：需要计算梯度
2. **凸性**：理想情况下是凸函数
3. **鲁棒性**：对异常值不敏感
4. **任务相关性**：与评估指标一致

---

## 10.2 回归损失函数

### 10.2.1 均方误差（MSE）

**公式**：
```
MSE = (1/N) Σ (yᵢ - ŷᵢ)²
```

**特点**：
- 对异常值敏感（平方放大）
- 梯度与误差成正比
- 最常用的回归损失

### 10.2.2 平均绝对误差（MAE）

**公式**：
```
MAE = (1/N) Σ |yᵢ - ŷᵢ|
```

**特点**：
- 对异常值鲁棒
- 梯度恒定
- 在零点不可导

### 10.2.3 Huber损失

**公式**：
```
L_δ(y, ŷ) = { 0.5 * (y - ŷ)²           if |y - ŷ| ≤ δ
            { δ * |y - ŷ| - 0.5 * δ²   otherwise
```

**特点**：
- 结合MSE和MAE的优点
- 对异常值鲁棒
- 处处可导

### 10.2.4 对数余弦损失（Log-Cosh）

**公式**：
```
L = Σ log(cosh(ŷᵢ - yᵢ))
```

**特点**：
- 近似MSE但更平滑
- 对异常值更鲁棒

## 10.3 分类损失函数

### 10.3.1 二分类交叉熵

**公式**：
```
L = -[y log(ŷ) + (1-y) log(1-ŷ)]
```

**推导**：
- 从最大似然估计导出
- 假设标签服从伯努利分布

**梯度**：
```
∂L/∂ŷ = -y/ŷ + (1-y)/(1-ŷ)
```

### 10.3.2 多分类交叉熵

**公式**：
```
L = -Σᵢ yᵢ log(ŷᵢ)
```

**Softmax**：
```
ŷᵢ = exp(zᵢ) / Σⱼ exp(zⱼ)
```

**数值稳定性**：
```
log(ŷᵢ) = zᵢ - log(Σⱼ exp(zⱼ))
= zᵢ - max(z) - log(Σⱼ exp(zⱼ - max(z)))
```

### 10.3.3 Focal Loss

**公式**：
```
FL(p_t) = -α_t (1 - p_t)^γ log(p_t)
```

**特点**：
- 解决类别不平衡问题
- 减少易分类样本的权重
- γ > 0，通常取2

### 10.3.4 KL散度损失

**公式**：
```
D_KL(p || q) = Σ p(x) log(p(x)/q(x))
```

**与交叉熵的关系**：
```
H(p, q) = H(p) + D_KL(p || q)
```

**应用**：
- 知识蒸馏
- VAE

---

## 10.4 排序损失函数

### 10.4.1 合页损失（Hinge Loss）

**公式**：
```
L = max(0, 1 - y * ŷ)
```

**应用**：支持向量机（SVM）

### 10.4.2 对比损失（Contrastive Loss）

**公式**：
```
L = y * d² + (1-y) * max(0, margin - d)²
```

**应用**：孪生网络，度量学习

### 10.4.3 三元组损失（Triplet Loss）

**公式**：
```
L = max(0, d(a, p) - d(a, n) + margin)
```

**应用**：人脸识别，图像检索

---

## 10.5 生成模型损失

### 10.5.1 GAN损失

**原始GAN损失**：
```
min_G max_D E[log D(x)] + E[log(1 - D(G(z)))]
```

**Wasserstein损失**：
```
min_G max_D E[D(x)] - E[D(G(z))]
```

### 10.5.2 VAE损失

**ELBO损失**：
```
L = 重建损失 + KL散度
L = E[log p(x|z)] - D_KL(q(z|x) || p(z))
```

### 10.5.3 扩散模型损失

**噪声预测损失**：
```
L = E[||ε - ε_θ(x_t, t)||²]
```

## 10.6 评估指标

### 10.6.1 分类指标

**准确率（Accuracy）**：
```
Accuracy = 正确预测数 / 总样本数
```

**精确率（Precision）**：
```
Precision = TP / (TP + FP)
```

**召回率（Recall）**：
```
Recall = TP / (TP + FN)
```

**F1分数**：
```
F1 = 2 * Precision * Recall / (Precision + Recall)
```

**ROC-AUC**：
- ROC曲线下的面积
- 衡量模型区分正负样本的能力

### 10.6.2 回归指标

**均方根误差（RMSE）**：
```
RMSE = √MSE
```

**平均绝对百分比误差（MAPE）**：
```
MAPE = (100/N) Σ |y - ŷ| / |y|
```

**R²分数**：
```
R² = 1 - Σ(y - ŷ)² / Σ(y - ȳ)²
```

### 10.6.3 生成模型指标

**FID（Fréchet Inception Distance）**：
```
FID = ||μ_r - μ_g||² + Tr(Σ_r + Σ_g - 2√(Σ_r Σ_g))
```

**IS（Inception Score）**：
```
IS = exp(E[D_KL(p(y|x) || p(y))])
```

### 10.6.4 NLP指标

**BLEU**：
```
BLEU = BP * exp(Σ wₙ log pₙ)
```

**ROUGE**：
- ROUGE-N：n-gram召回率
- ROUGE-L：最长公共子序列

**Perplexity**：
```
PPL = exp(-1/N Σ log p(xᵢ|x_{<i}))
```

## 10.7 损失函数设计原则

### 10.7.1 任务相关性

**分类任务**：交叉熵
**回归任务**：MSE或MAE
**排序任务**：Triplet Loss
**生成任务**：GAN Loss或ELBO

### 10.7.2 鲁棒性

**异常值多**：使用MAE或Huber Loss
**类别不平衡**：使用Focal Loss或加权交叉熵

### 10.7.3 可优化性

**处处可导**：避免使用不可导的损失
**梯度行为**：避免梯度消失或爆炸

## 10.8 实践建议

### 10.8.1 损失函数选择

| 任务 | 推荐损失函数 |
|------|-------------|
| 二分类 | 二分类交叉熵 |
| 多分类 | 多分类交叉熵 |
| 回归 | MSE或Huber Loss |
| 目标检测 | Focal Loss + L1/L2 |
| 语义分割 | Dice Loss + 交叉熵 |
| 图像生成 | GAN Loss + L1重建 |

### 10.8.2 评估指标选择

| 场景 | 推荐指标 |
|------|----------|
| 类别平衡 | 准确率 |
| 类别不平衡 | F1、AUC |
| 回归 | RMSE、R² |
| 生成模型 | FID |
| 机器翻译 | BLEU |
