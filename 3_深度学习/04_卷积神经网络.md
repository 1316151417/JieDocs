# 第4章 卷积神经网络（CNN）

> **核心问题**：CNN如何高效处理图像数据？残差学习如何解决深层网络的退化问题？

---

## 4.1 从全连接到卷积

### 4.1.1 全连接网络处理图像的问题

**问题1：参数爆炸**
- 224x224x3的图像，展平后有150,528个输入
- 如果第一个隐藏层有1024个神经元，需要1.54亿个参数
- 参数过多导致过拟合和计算困难

**问题2：破坏空间结构**
- 图像展平为一维向量后，丢失了空间位置信息
- 无法利用图像的局部相关性

**问题3：不具备平移不变性**
- 同一个物体在图像不同位置，全连接网络需要重新学习

### 4.1.2 CNN的核心思想

CNN通过三个关键思想解决上述问题：

1. **局部连接**（Local Connectivity）：每个神经元只连接输入的一个局部区域
2. **权值共享**（Weight Sharing）：同一个卷积核在整个图像上滑动
3. **空间下采样**（Spatial Pooling）：逐步减小特征图尺寸

## 4.2 卷积操作

### 4.2.1 2D卷积

**数学定义**：
```
(I * K)[i,j] = Sigma_m Sigma_n I[i+m, j+n] * K[m,n]
```

**直观理解**：
- 卷积核（滤波器）在输入图像上滑动
- 每个位置计算卷积核与局部区域的点积
- 输出称为特征图（Feature Map）

### 4.2.2 卷积的关键参数

**步长（Stride）**：
- 卷积核每次滑动的距离
- 步长>1可以实现下采样

**填充（Padding）**：
- 在输入边缘填充零值
- "Same"填充：保持输出尺寸
- "Valid"填充：不填充

**输出尺寸计算**：
```
output_size = (input_size - kernel_size + 2 * padding) / stride + 1
```

### 4.2.3 多通道卷积

**输入**：(C_in, H, W) - C_in个通道
**卷积核**：(C_in, K_h, K_w) - 每个通道一个K_h x K_w的核
**输出**：(1, H', W') - 一个特征图

**多个卷积核**：
- 使用N个不同的卷积核
- 输出N个特征图
- 堆叠形成(N, H', W')的输出

## 4.3 池化层

### 4.3.1 最大池化（Max Pooling）

```
在每个2x2区域取最大值
```

**作用**：
- 减少空间维度
- 提供平移不变性
- 减少计算量

### 4.3.2 平均池化（Average Pooling）

```
在每个2x2区域取平均值
```

### 4.3.3 全局平均池化（Global Average Pooling）

```
对整个特征图取平均，得到一个标量
```

**应用**：替代全连接层，减少参数

## 4.4 经典CNN架构

### 4.4.1 LeNet-5（1998）

**结构**：
```
输入(32x32) -> Conv(6@5x5) -> Pool -> Conv(16@5x5) -> Pool -> FC -> FC -> 输出
```

**贡献**：
- 第一个成功的CNN应用
- 用于手写数字识别

### 4.4.2 AlexNet（2012）

**关键创新**：
- 使用ReLU激活函数
- Dropout正则化
- 数据增强
- GPU训练

**历史意义**：
- ImageNet竞赛错误率从26%降到15%
- 开启了深度学习时代

### 4.4.3 VGGNet（2014）

**核心思想**：使用多个3x3小卷积核代替大卷积核

```
两个3x3卷积 = 一个5x5卷积的感受野
三个3x3卷积 = 一个7x7卷积的感受野
```

**优势**：
- 更少的参数
- 更多的非线性
- 更深的网络

### 4.4.4 GoogLeNet/Inception（2014）

**核心思想**：Inception模块

```
输入 -> [1x1 Conv] -> [3x3 Conv] -> [5x5 Conv] -> [MaxPool] -> Concat
```

**创新**：
- 多尺度特征提取
- 1x1卷积降维
- 更深更高效

### 4.4.5 ResNet（2015）——残差学习

**核心思想**：残差连接

```
y = F(x) + x
```

**退化问题的本质**：

深层网络的退化问题（degradation problem）并非由过拟合引起，而是优化困难。当网络深度增加时，准确率先饱和然后迅速下降。令人意外的是，这种退化不是由过拟合导致的——向适当深度的模型添加更多层会导致更高的训练误差。

> "When deeper networks are able to start converging, a degradation problem has been exposed: with the network depth increasing, accuracy gets saturated and then degrades rapidly. Unexpectedly, such degradation is not caused by overfitting, and adding more layers to a suitably deep model leads to higher training error."
> — He et al., *Deep Residual Learning for Image Recognition* (arXiv:1512.03385)

**残差学习的解决方案**：

残差学习通过将层重新表述为学习相对于层输入的残差函数（而非学习无参考的函数），来解决退化问题。大量实验证据表明，残差网络更容易优化，并且能够从显著增加的深度中获得精度提升。

> "We explicitly reformulate the layers as learning residual functions with reference to the layer inputs, instead of learning unreferenced functions. We provide comprehensive empirical evidence showing that these residual networks are easier to optimize, and can gain accuracy from considerably increased depth."
> — He et al., *Deep Residual Learning for Image Recognition* (arXiv:1512.03385)

**ImageNet上的突破性成果**：

- 152层残差网络——比VGG深8倍，但复杂度更低
- 残差网络集成在ImageNet测试集上达到3.57% top-5错误率
- 赢得ILSVRC 2015分类任务第一名

> "depth of 152 layers--8x deeper than VGG nets but still having lower complexity. An ensemble of these residual nets achieves 3.57% error on the ImageNet test set. This result won the 1st place on the ILSVRC 2015 classification task."
> — He et al., *Deep Residual Learning for Image Recognition* (arXiv:1512.03385)

**残差表示的迁移能力**：

残差表示在其他视觉任务上同样表现出色。在COCO目标检测数据集上，仅凭极深的表示就获得了28%的相对改进，并在COCO检测和分割竞赛中均获得第一名。

> "Solely due to our extremely deep representations, we obtain a 28% relative improvement on the COCO object detection dataset. Deep residual nets are the foundations of our submissions to ILSVRC & COCO 2015 competitions, where we also won the 1st places on the tasks of ImageNet detection, ImageNet localization, COCO detection, and COCO segmentation."
> — He et al., *Deep Residual Learning for Image Recognition* (arXiv:1512.03385)

### 4.4.6 DenseNet（2017）

**核心思想**：密集连接

```
x_l = H_l([x_0, x_1, ..., x_{l-1}])
```

**优势**：
- 特征复用
- 缓解梯度消失
- 参数效率高

### 4.4.7 EfficientNet（2019）

**核心思想**：复合缩放

```
depth: d = alpha^phi
width: w = beta^phi
resolution: r = gamma^phi
```

**创新**：
- 系统地平衡网络深度、宽度和分辨率
- 在准确率和效率之间取得最佳平衡

## 4.5 现代CNN技术

### 4.5.1 深度可分离卷积

**标准卷积**：
```
参数量 = K x K x C_in x C_out
```

**深度可分离卷积**：
```
深度卷积：K x K x C_in
逐点卷积：1 x 1 x C_in x C_out
总参数量 = K x K x C_in + C_in x C_out
```

**应用**：MobileNet系列，用于移动端

### 4.5.2 空洞卷积（Dilated Convolution）

**特点**：卷积核元素之间有间隔

**优势**：
- 不增加参数的情况下增大感受野
- 用于语义分割等需要大上下文的任务

### 4.5.3 可变形卷积（Deformable Convolution）

**特点**：卷积核的采样位置可学习

**优势**：
- 适应不同形状的目标
- 提高对几何变换的鲁棒性

## 4.6 CNN的应用

### 4.6.1 图像分类

**经典数据集**：
- CIFAR-10/100
- ImageNet（1000类）
- Places365

### 4.6.2 目标检测

**两阶段方法**：
- R-CNN -> Fast R-CNN -> Faster R-CNN
- 先生成候选区域，再分类

**单阶段方法**：
- YOLO系列
- SSD
- 直接预测边界框和类别

### 4.6.3 语义分割

**FCN（全卷积网络）**：
- 将全连接层替换为卷积层
- 输出与输入同尺寸的分割图

**U-Net**：
- 编码器-解码器结构
- 跳跃连接
- 医学图像分割的标配

### 4.6.4 图像生成

**GAN（生成对抗网络）**：
- 生成器和判别器对抗训练
- DCGAN使用卷积层
- StyleGAN实现风格控制

## 4.7 实践示例：用PyTorch实现ResNet

```python
import torch
import torch.nn as nn

class ResidualBlock(nn.Module):
    def __init__(self, in_channels, out_channels, stride=1):
        super().__init__()
        self.conv1 = nn.Conv2d(in_channels, out_channels, 3, stride, 1, bias=False)
        self.bn1 = nn.BatchNorm2d(out_channels)
        self.conv2 = nn.Conv2d(out_channels, out_channels, 3, 1, 1, bias=False)
        self.bn2 = nn.BatchNorm2d(out_channels)

        self.shortcut = nn.Sequential()
        if stride != 1 or in_channels != out_channels:
            self.shortcut = nn.Sequential(
                nn.Conv2d(in_channels, out_channels, 1, stride, bias=False),
                nn.BatchNorm2d(out_channels)
            )

    def forward(self, x):
        residual = self.shortcut(x)
        out = torch.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        out += residual
        return torch.relu(out)

class ResNet(nn.Module):
    def __init__(self, num_classes=10):
        super().__init__()
        self.conv1 = nn.Conv2d(3, 64, 3, 1, 1, bias=False)
        self.bn1 = nn.BatchNorm2d(64)

        self.layer1 = self._make_layer(64, 64, 2, stride=1)
        self.layer2 = self._make_layer(64, 128, 2, stride=2)
        self.layer3 = self._make_layer(128, 256, 2, stride=2)

        self.fc = nn.Linear(256, num_classes)

    def _make_layer(self, in_channels, out_channels, num_blocks, stride):
        layers = [ResidualBlock(in_channels, out_channels, stride)]
        for _ in range(1, num_blocks):
            layers.append(ResidualBlock(out_channels, out_channels))
        return nn.Sequential(*layers)

    def forward(self, x):
        out = torch.relu(self.bn1(self.conv1(x)))
        out = self.layer1(out)
        out = self.layer2(out)
        out = self.layer3(out)
        out = nn.functional.adaptive_avg_pool2d(out, 1)
        out = out.view(out.size(0), -1)
        return self.fc(out)
```
