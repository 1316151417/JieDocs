# **Adam、AdamW、权重衰减与正则化**

## **一、问题背景**

在现代 Transformer 训练代码中，经常可以看到：

```python
optimizer = torch.optim.AdamW(
    optim_groups,
    lr=learning_rate,
    betas=betas
)
```

以及参数分组：

```python
decay_params = [p for n, p in param_dict.items() if p.dim() >= 2]
nodecay_params = [p for n, p in param_dict.items() if p.dim() < 2]
```

核心问题：

1. 什么是权重衰减？
2. 什么是 Adam？
3. 什么是 AdamW？
4. 什么是正则化？
5. 为什么不同参数需要设置不同的权重衰减？

---

# **二、权重衰减 Weight Decay**

## **1. 什么是权重衰减？**

一句话：

权重衰减就是训练过程中持续给参数一个“往 0 缩小”的力，限制参数规模。

例如：

```text
weight = 10
```

正常梯度更新：

```text
10 → 10.2
```

加入权重衰减后：

```text
10 → 10.2 → 10.19
             ↑
          往 0 拉一点
```

其核心形式可以粗略理解为：

```text
w = w - learning_rate × weight_decay × w
```

参数会逐渐缩小：

```text
10
↓
9.9
↓
9.801
↓
9.703
```

## **2. 为什么限制权重过大？**

模型可能通过极端参数组合强行拟合训练数据：

```text
年龄 × 10000
+ 性别 × -9999
+ 收入 × 8763
```

这种模型可能在训练集表现很好，但对输入中的微小变化非常敏感。

例如：

```text
输入变化 0.001
↓
× 10000
↓
输出变化 10
```

微小噪声被巨大权重放大。

权重衰减相当于告诉模型：

如果多个参数方案都能降低 Loss，优先选择参数规模更小、更平缓的方案。

因此，Weight Decay 是一种常见的正则化手段。

# **三、Adam**

## **1. 普通梯度下降的问题**

普通 SGD 的参数更新：

```python
w = w - learning_rate * grad
```

例如：

```text
w = 10
grad = 2
learning_rate = 0.1

10 - 0.1 × 2 = 9.8
```

问题在于，不同参数的梯度尺度可能差异巨大：

```text
w1 梯度：0.00001
w2 梯度：1
w3 梯度：10000
```

如果统一使用：

```text
learning_rate = 0.001
```

可能出现：

```text
w1 → 几乎不动
w2 → 正常更新
w3 → 更新幅度巨大
```

统一的学习率很难同时适应所有参数。

## **2. Adam 解决什么问题？**

一句话：

Adam 根据每个参数历史梯度的方向和尺度，自适应调整参数的实际更新幅度。

可以粗略理解为：

```text
w1 → 自己的学习节奏
w2 → 自己的学习节奏
w3 → 自己的学习节奏
```

Adam 主要记录两个信息。

### **梯度的一阶矩**

记录历史梯度的移动平均：

```text
1.0
1.2
0.8
1.1
```

整体趋势大约是：

```text
1.0
```

记为：

```text
m_t
```

它回答的问题是：

最近的梯度总体想往哪个方向走？

本质类似 Momentum（动量）。

### **梯度的二阶矩**

Adam 同时记录梯度平方的移动平均：

```text
1²
1.2²
0.8²
1.1²
```

记为：

```text
v_t
```

它主要反映：

这个参数历史梯度的尺度有多大？

如果梯度长期很大：

```text
100
200
150
```

Adam 会压低实际更新幅度。

如果梯度长期较小：

```text
0.001
0.002
0.001
```

则不会受到巨大梯度尺度的强烈压制。

Adam 的核心思想可以粗略理解为：

```text
更新量 ≈ 梯度方向趋势 / 梯度历史尺度
```

## **3. Adam 的本质**

Adam 给每个参数进行自适应的梯度尺度调整，同时利用历史梯度平滑更新方向。

因此 Adam 特别适合参数规模巨大、不同参数梯度尺度差异明显的深度神经网络。

# **四、AdamW**

## **1. AdamW 中的 W 是什么？**

AdamW 中的 `W` 指：

```text
Weight Decay
```

即权重衰减。

更准确地说：

AdamW = Adam with Decoupled Weight Decay

核心创新是：

将权重衰减与 Adam 的梯度优化过程解耦。

## **2. 为什么 Adam 不能简单结合 L2 正则？**

传统 L2 正则会在 Loss 中加入：

```text
Loss + λw²
```

求导后：

```text
gradient + 2λw
```

整个梯度再进入 Adam：

```text
真实梯度
    +
权重惩罚梯度
    ↓
Adam
    ↓
自适应缩放
```

问题是：

Adam 会对权重惩罚产生的梯度一起进行自适应缩放。

原本希望稳定地把参数往 0 拉，但这个“拉力”也被 Adam 调整了。

## **3. AdamW 如何解决？**

AdamW 将两个过程拆开：

```text
真实梯度
    ↓
Adam
    ↓
参数优化

权重
    ↓
Weight Decay
    ↓
独立衰减
```

粗略理解：

```text
w = 10

Adam 更新：
-0.2

Weight Decay：
-0.01

最终：
10 - 0.2 - 0.01 = 9.79
```

因此：

Adam 负责“如何根据梯度学习”，Weight Decay 负责“限制参数规模”。

两者职责独立。

# **五、什么是正则化？**

## **1. 正则化解决什么问题？**

正则化主要解决：

过拟合。

一句话：

正则化就是主动限制模型的学习自由，防止模型为了降低训练误差，学习训练数据中的偶然细节和噪声。

例如训练数据：

```text
小明：20 岁 → 喜欢游戏
小王：21 岁 → 喜欢游戏
小张：40 岁 → 不喜欢游戏
```

希望模型学习：

```text
年轻人可能更喜欢游戏
```

但能力很强的模型可能学习：

```text
年龄 = 20 → 喜欢
年龄 = 21 → 喜欢
年龄 = 40 → 不喜欢
```

甚至学习：

```text
姓名包含“明” → 喜欢游戏
姓名包含“王” → 喜欢游戏
```

训练集准确率可能达到：

```text
100%
```

但面对：

```text
小李：22 岁
```

模型无法正确判断。

这就是过拟合：

模型记住了训练数据，而没有学习更普遍的规律。

---

# **六、正则化的本质**

现实训练数据可以粗略理解为：

```text
训练数据 = 真实规律 + 随机噪声
```

模型能力不足：

```text
真实规律都学不会
↓
欠拟合
```

模型能力合适：

```text
主要学习真实规律
↓
泛化能力较好
```

模型能力非常强：

```text
学习真实规律
+
继续学习随机噪声
↓
过拟合
```

因此，模型能力越强，并不意味着泛化能力一定越好。

正则化本质上是：

给模型增加一定的约束或干扰，使模型更难学习偶然细节，从而优先学习稳定、重复、普遍存在的规律。

---

# **七、常见正则化方法**

## **Weight Decay**

```text
可以学习
但参数不要变得过于极端
```

限制参数规模。

## **Dropout**

```text
训练过程中随机关闭部分神经元
```

防止模型过度依赖少数特征或固定神经元组合。

## **数据增强**

例如图片：

```text
原图
旋转
裁剪
改变亮度
```

模型都需要正确识别。

迫使模型学习更稳定的视觉特征。

## **Early Stopping**

当出现：

```text
训练集 Loss 继续下降
验证集效果开始下降
```

停止训练。

避免模型继续学习训练数据中的细节和噪声。

---

# **八、为什么 Weight Decay 属于正则化？**

假设存在两个都能降低训练 Loss 的参数方案。

方案 A：

```text
w1 = 10000
w2 = -9999
```

方案 B：

```text
w1 = 1.2
w2 = 0.8
```

Weight Decay 会倾向方案 B。

其背后包含一种归纳偏置：

参数规模更小、更平缓的解，更可能具有较好的泛化能力。

因此 Weight Decay 通过限制参数规模，降低模型学习极端、脆弱规律的可能性。

# **九、Transformer 中为什么需要参数分组？**

常见代码：

```python
decay_params = [
    p for n, p in param_dict.items()
    if p.dim() >= 2
]

nodecay_params = [
    p for n, p in param_dict.items()
    if p.dim() < 2
]
```

通常：

|**参数**|**维度**|**Weight Decay**|
|---|---|---|
|Linear.weight|2D|是|
|Embedding.weight|2D|是|
|Linear.bias|1D|否|
|LayerNorm.weight|1D|否|
|RMSNorm.weight|1D|否|

核心思想：

```text
主权重矩阵
↓
参与大规模特征变换
↓
进行 Weight Decay

bias / Norm 参数
↓
负责偏移或尺度调整
↓
通常不进行 Weight Decay
```

使用参数维度判断是一种简单实用的经验规则：

```python
p.dim() >= 2
```

并不是严格的数学定律。

# **十、核心总结**

整个模型训练可以理解为三个力量：

```text
Loss
↓
告诉模型：往哪里学习

Adam
↓
决定：根据历史梯度，以什么节奏更新每个参数

Weight Decay
↓
限制：参数不要走向过于极端的解
```

AdamW 将 Adam 与 Weight Decay 解耦：

```text
Adam → 优化学习过程
Weight Decay → 正则化参数规模
```

而正则化更高层的目标是：

限制模型过度迎合训练数据，使模型从“记住训练样本”转向“学习更稳定、可泛化的规律”。

一句话记忆：

**Adam 决定怎么学，Weight Decay 限制别学得太极端，AdamW 将两者正确组合；它们最终服务于更稳定的训练和更好的泛化能力。**
