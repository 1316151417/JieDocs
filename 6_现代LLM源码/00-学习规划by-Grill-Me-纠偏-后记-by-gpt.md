# 现代 LLM 后续学习与实践规划

## 总原则

- 当前业务工作优先。
- AI 每周投入 3～5 小时。
- 一次只推进一个项目。
- 以实验、代码和报告作为验收结果。

## 第一阶段：现有实验收口（0～3 个月）

### 工作

- 熟悉业务流程。
- 掌握系统架构与核心链路。
- 独立负责一个模块。
- 解决一个实际问题。

### AI

- 建立固定测试集。
- 对比 Base、SFT、LoRA。
- 补充量化指标。
- 整理成功与失败案例。
- 完善可复现实验仓库。
- 输出一篇实验报告。

## 第二阶段：数据与评测（3～6 个月）

- 建设代码数据清洗、分类、去重流程。
- 调整通用 Python 与机器学习代码比例。
- 固定模型、Token 数和训练参数。
- 对比不同数据配比的训练结果。
- 建立代码能力 Benchmark。
- 评测通用能力、领域能力与能力退化。
- 输出数据配比实验报告。

## 第三阶段：推理与部署（6～9 个月）

- 学习 KV Cache。
- 学习批处理与连续批处理。
- 完成 INT8、INT4 量化。
- 使用 vLLM 部署模型。
- 对比显存、延迟、吞吐与质量。
- 建立推理监控。
- 输出推理性能报告。

## 第四阶段：Agent 与综合实践（9～12 个月）

- 手写最小 Tool Call 循环。
- 实现状态管理、停止条件和重试。
- 实现权限控制与幂等处理。
- 建立 Agent Benchmark 与 grader。
- 分析失败轨迹。
- 按场景比较直接上下文、关键词搜索、向量检索和自主搜索。
- 输出综合实验报告。

## 每周安排

- 工作日：2 次，每次 1 小时。
- 周末：1 次，连续 2～3 小时。
- 每周完成一个可验证的小成果。
- 每月完成一次实验复盘。

## 暂不投入

- 新模型源码横向阅读。
- Agent 框架对比。
- 通用 RAG 课程。
- PPO、GRPO、RLHF 实现。
- CUDA Kernel。
- 大规模分布式预训练。
- 60 分钟通识分享的持续润色。

## 年度验收

- 一个完整 SFT/LoRA 评测项目。
- 一个数据配比与 Benchmark 项目。
- 一个模型推理部署项目。
- 一个 Agent 评测项目。
- 四份可复现实验报告。
- 一套完整的模型训练、评测与推理知识体系。
