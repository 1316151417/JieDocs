```python
import torch  # 导入 PyTorch
```

```python
dim = 8  # 假设每个 head 的维度是 8，必须是偶数，因为 RoPE 每 2 维一组
```

```python
end = 4  # 假设最大序列长度是 4，也就是有 4 个 token 位置
```

```python
theta = 10000.0  # RoPE 默认频率基数，和 Transformer 正弦位置编码类似
```

```python
torch.arange(0, dim, 2)  # 生成偶数维度索引：0,2,4,6
```

```python
torch.arange(0, dim, 2).float() / dim  # 得到每组维度对应的指数比例
```

```python
freqs = 1.0 / (theta ** (torch.arange(0, dim, 2).float() / dim))  # 计算每组二维向量的旋转频率
```

```python
freqs  # 查看频率，越靠后的维度频率越低
```

```python
t = torch.arange(end)  # 生成 token 位置：0,1,2,3
```

```python
t  # 查看位置序列
```

```python
freqs_matrix = torch.outer(t, freqs).float()  # 每个位置 × 每个频率，得到每个位置每组维度的旋转角度
```

```python
freqs_matrix  # 查看角度矩阵，shape 是 [4,4]
```

```python
freqs_cos = torch.cos(freqs_matrix)  # 计算每个旋转角度的 cos
```

```python
freqs_sin = torch.sin(freqs_matrix)  # 计算每个旋转角度的 sin
```

```python
freqs_cos  # 查看 cos 矩阵
```

```python
freqs_sin  # 查看 sin 矩阵
```

```python
xq = torch.arange(1 * 4 * 1 * 8).float().reshape(1, 4, 1, 8)  # 构造 q，shape=[batch=1, seq=4, heads=1, head_dim=8]
```

```python
xq  # 查看原始 q
```

```python
xq.shape  # 查看形状
```

把最后一维每两个一组拆开：

```python
xq_pair = xq.reshape(xq.shape[:-1] + (-1, 2))  # 把 head_dim=8 拆成 4 组，每组 2 维
```

```python
xq_pair  # 查看拆分结果
```

```python
xq_pair.shape  # shape=[1,4,1,4,2]
```

拆成实部和虚部：

```python
xq_r, xq_i = xq_pair.unbind(-1)  # 每组二维向量拆成第一维 xq_r 和第二维 xq_i
```

```python
xq_r  # 相当于每组二维向量的 x 坐标
```

```python
xq_i  # 相当于每组二维向量的 y 坐标
```

调整 cos/sin 形状，让它可以广播：

```python
freqs_cos_view = freqs_cos.view(1, 4, 1, 4)  # 从 [seq=4, dim/2=4] 变成 [1,4,1,4]
```

```python
freqs_sin_view = freqs_sin.view(1, 4, 1, 4)  # 同理，方便和 xq_r/xq_i 相乘
```

```python
xq_r.shape, freqs_cos_view.shape  # 两者可以广播相乘
```

执行旋转：

```python
xq_out_r = xq_r * freqs_cos_view - xq_i * freqs_sin_view  # 旋转后的 x 坐标
```

```python
xq_out_i = xq_r * freqs_sin_view + xq_i * freqs_cos_view  # 旋转后的 y 坐标
```

```python
xq_out_r  # 查看旋转后的实部
```

```python
xq_out_i  # 查看旋转后的虚部
```

拼回原始形状：

```python
xq_out_pair = torch.stack([xq_out_r, xq_out_i], dim=-1)  # 把旋转后的 x/y 坐标重新合成二维对
```

```python
xq_out_pair.shape  # shape=[1,4,1,4,2]
```

```python
xq_out = xq_out_pair.flatten(3)  # 把最后两维 [4,2] 重新压平成 head_dim=8
```

```python
xq_out  # 最终 RoPE 后的 q
```

```python
xq_out.shape  # shape 仍然是 [1,4,1,8]
```

## **旋转公式的原理**

RoPE 用的是二维旋转矩阵。

一个二维向量：

```text
[x, y]
```

旋转角度 `θ` 后变成：

```text
x' = x cosθ - y sinθ
y' = x sinθ + y cosθ
```

也可以写成矩阵：

```text
[x']   [cosθ  -sinθ] [x]
[y'] = [sinθ   cosθ] [y]
```

代码里的：

```python
xq_out_r = xq_r * cos - xq_i * sin
xq_out_i = xq_r * sin + xq_i * cos
```

就是这个公式。

RoPE 的本质是：把 `head_dim` 每两个维度当成一个二维向量，然后根据 token 位置旋转不同角度。
