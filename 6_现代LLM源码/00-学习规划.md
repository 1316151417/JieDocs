# **第一部分：LLaMA（整个阶段最重要）**

预计时间：**1~2 周**

## **为什么先学 LLaMA**

现代几乎所有开源模型都是 LLaMA 系：

```text
LLaMA
   │
   ├── Vicuna
   ├── Alpaca
   ├── Yi
   ├── Baichuan
   ├── Qwen
   ├── DeepSeek
   ├── MiniCPM
   ├── InternLM
   ├── GLM(部分设计不同)
```

真正理解了 LLaMA，后面阅读速度会快很多。

# **第四部分：源码横向对比**

建议自己整理一张表。

| **模块**    | **GPT-2** | **LLaMA** | **Qwen** | **DeepSeek V3** |
| --------- | --------- | --------- | -------- | --------------- |
| Norm      | LayerNorm | RMSNorm   | RMSNorm  | RMSNorm         |
| Position  | Learned   | RoPE      | RoPE     | RoPE            |
| FFN       | GELU      | SwiGLU    | SwiGLU   | MoE + SwiGLU    |
| Attention | MHA       | MHA/GQA   | GQA      | MLA             |
| KV Cache  | 普通        | 普通        | 优化       | MLA             |
| 长上下文      | 无         | 一般        | YaRN 等扩展 | 更完善             |

每看完一个模型，就更新这张表。

这会帮助你快速建立对各模型演进路线的整体认知。

# **第五部分：推理流程（独立专题）**

这是很多人容易忽略，但工程价值最高的一部分。

建议专题学习：

```
Prefill

↓

Decode

↓

KV Cache

↓

Sampling

↓

Batch

↓

Streaming
```

理解：

为什么：

```
第一次 Forward

和

第二次 Forward

完全不同。
```

理解：

```
为什么：

KV Cache

只能缓存 KV？

不能缓存 Q？
```

这一部分结束后，再进入：

```
PagedAttention

Continuous Batch

Scheduler
```

也就是：

vLLM。

# **整个学习阶段的最终产出**

建议给自己设定以下可验证目标，而不是单纯“读完源码”。

1. **源码阅读笔记**：为 LLaMA、Qwen、DeepSeek V3 各整理一份模块级笔记（目录结构、核心类、调用链、与论文对应关系）。
2. **Mini LLaMA**：独立实现一个仅包含 Forward 的简化版本（约 300–600 行）。
3. **模型演进对比表**：维护一张从 GPT-2 → LLaMA → Qwen → DeepSeek V3 的结构演进表。
4. **推理流程图**：画出 Prefill、Decode、KV Cache 更新、Sampling 的完整调用流程。
5. **阅读能力目标**：能够在一个陌生 LLM 仓库中，用 30 分钟左右定位模型入口、Attention 实现、MLP、位置编码、KV Cache 和生成逻辑，并判断其相对于 LLaMA 的主要改动。

完成这一阶段后，你的能力会从**“理解 LLM 的原理”**提升到**“理解 LLM 的实现”**。此后，无论是阅读新的模型论文，还是分析新的开源仓库，重点都会从“它是什么”转变为“它相对于已有实现改了什么，以及为什么这样改”。
