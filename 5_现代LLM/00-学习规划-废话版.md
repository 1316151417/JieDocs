# 现代 LLM 学习规划（GPT-3 之后）

> 当前阶段：已完成深度学习基础、Transformer、GPT-1/2/3、BERT，并具备 GPT-1 从零实现能力。
>
> 目标：建立现代 LLM 的完整知识体系，具备判断 AI 技术演进方向、理解新模型设计、设计 AI 系统的能力，而不仅仅是会使用 Agent 框架。

---

# 一、为什么继续学习现代 LLM？

## 当前 AI 学习容易陷入两个误区

### 误区一：过度学习 Agent

目前大量 AI 教程集中在：

- LangGraph
- CrewAI
- AutoGen
- MCP
- Workflow
- RAG

这些技术：

- 上手快
- Demo 容易
- 内容多
- 门槛相对较低

但真正的技术壁垒正在不断降低。

Agent 更多属于**应用层**，而不是 AI 的核心能力。

---

### 误区二：钻研过深的底层 Infra

例如：

- CUDA
- Triton
- PTX
- NCCL
- Kernel
- GPU 通信

这些属于 AI Infra 工程。

虽然价值很高，但对于业务研发而言，投入产出比（ROI）并不高。

---

## 最适合自己的位置

AI 技术栈可以抽象为四层：

```
应用层
-----------------------
Agent
Workflow
MCP
RAG
Tool Calling

模型层
-----------------------
LLM
MoE
Attention
RLHF
Reasoning

Infra层
-----------------------
vLLM
Serving
KV Cache
CUDA

硬件层
-----------------------
GPU
网络
存储
```

未来主要投入：

> **模型层 + AI 工程**

而不是：

- 继续卷 Agent
- 深入 CUDA Kernel

---

# 二、学习目标

不是成为：

> CUDA 工程师

也不是成为：

> Agent 调参工程师

而是培养以下能力：

## ① 理解现代 LLM 为什么这样设计

例如：

为什么：

- RoPE
- RMSNorm
- SwiGLU
- FlashAttention
- GQA
- MoE

逐渐成为现代模型标配。

---

## ② 建立技术判断力

看到任何一个新模型：

例如：

DeepSeek

Claude

Qwen

Gemini

可以迅速判断：

- 哪些是真创新
- 哪些只是工程优化
- 哪些只是营销包装

---

## ③ 能设计真正的 AI 系统

知道：

模型擅长什么？

模型不擅长什么？

什么时候应该：

- Agent
- Workflow
- Tool Calling
- Fine-tuning
- RAG

而不是所有问题都交给一个 Agent。

---

# 三、学习路线

## 第一阶段：现代 LLM 演化（★★★★★）

目标：

回答一个问题：

> GPT-3 之后到底发生了什么？

建议学习顺序：

```
GPT3
    ↓
InstructGPT（RLHF）
    ↓
LLaMA
    ↓
RoPE
    ↓
RMSNorm
    ↓
SwiGLU
    ↓
FlashAttention
    ↓
MQA / GQA
    ↓
MoE
```

---

### 每个知识点重点回答

固定回答：

- 为什么提出？
- 解决什么问题？
- 核心思想是什么？
- 优点？
- 缺点？
- 后来为什么成为主流？

而不是：

逐字翻译论文。

---

## 第二阶段：阅读现代模型源码（★★★★★）

建议顺序：

```
GPT2
（已完成）

↓

LLaMA

↓

Qwen

↓

DeepSeek V3
```

重点阅读：

```
README

↓

model.py

↓

attention.py

↓

moe.py

↓

inference.py
```

无需一开始阅读全部源码。

重点理解：

现代模型相比 GPT 的变化。

---

## 第三阶段：现代推理系统（★★★★☆）

重点学习：

```
vLLM

↓

KV Cache

↓

PagedAttention

↓

Scheduler

↓

Continuous Batching

↓

Serving
```

理解：

为什么现在模型可以：

- 高并发
- 低延迟
- 高吞吐

即可。

无需深入 CUDA。

# 六、论文阅读方法

不要：

```
论文逐句精读
```

推荐：

```
论文

↓

理解背景

↓

为什么提出

↓

解决什么问题

↓

优缺点

↓

代码实现

↓

自己总结
```

最终：

形成自己的理解。

---

# 十一、最终目标

真正的竞争力，不是：

> 会使用 AI。

也不是：

> 会搭建 Agent。

而是：

> **理解现代 LLM 的能力边界，能够判断技术演进方向，并将 AI 落地到真实业务中，解决真正有价值的问题。**

这是未来 AI 工程师最重要的核心能力。
