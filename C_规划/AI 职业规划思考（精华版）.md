AI 职业规划思考（精华版）

一、学习方向

已完成

已经基本掌握现代 LLM 的第一阶段：

- Transformer
- GPT-1 / GPT-2 / GPT-3
- Tokenizer（Byte-Level BPE）
- GPT 从零实现
- Agent / MCP / Tool Calling / RAG

后续只需补齐：

- InstructGPT（SFT、RLHF）★★★★★
- LoRA（理解原理即可）★★★☆☆

无需继续深入训练基础设施（CUDA、分布式训练等）。

  

二、最大的认知变化

过去认为：

技术 = 竞争力。

现在认为：

解决真实问题 = 竞争力。

继续学习新的模型、框架，边际收益已经越来越低。

  

三、对知识库的新判断

传统知识库（Wiki / RAG）不是未来。

原因：

- 维护成本高
- 容易过期
- 模型越来越聪明
- Tool Calling 会越来越强

未来更重要的是：

Knowledge Discovery（按需获取知识）

而不是：

Knowledge Storage（提前存储知识）

  

四、AI 真正的竞争点

未来竞争的重点不是：

- Prompt
- RAG
- Agent

而是：

Model + Environment + Feedback Loop

AI 的能力越来越来自：

- 工具
- 环境
- 状态
- 反馈

而不是一次 Prompt。

  

五、为什么一直找不到方向

不是能力不足。

而是：

一直在做”研发提效”。

AI 写代码、AI 排障、AI Wiki……

这些方向：

- ROI 不明显
- 很容易被通用 Agent 替代
- 很难形成长期壁垒

  

六、真正值得长期研究的问题

不要研究：

AI 如何写代码。

而要研究：

AI 如何在真实企业环境中，以可预测、可评估、可维护的方式完成复杂工作。

这是一个长期存在的问题，而不是某个框架的能力。

  

七、未来几年最重要的一句话

不要再为了学习技术而学习技术，而要寻找一个足够大的问题，并围绕它持续积累。

技术会不断变化。

真正长期的竞争力来自：

持续解决一个重要问题，而不是持续学习新的技术名词。
