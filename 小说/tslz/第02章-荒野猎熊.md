# 第02章 荒野猎熊

📍 地点：荒野长草地 → 杂木林 → 小溪边
👥 人物：大师、剑客

**情节要点**

- 二人在过腰长草的荒野南行，手表与日照时间对不上号，只见野兔、野羊、鹿等见人就逃，推断附近有人猎杀、应有人烟。
- 入一片曾被人砍伐的梨木混生林，发现小溪，痛饮解渴。剑客削三支梨木标枪，二人歇息。
- 大师趁剑客熟睡，用金刚符熏烤枪头——木枪竟硬如精钢、削不动、能凿石溅火星，但沾血或湿水即失效。
- 二人再试飞剑诀仍不动。溪对岸钻出一头五尺余高黑熊，剑客以木枪迎战，大师配合。
- 剑客掷枪中熊肩非要害，挺枪刺穿熊掌却被震飞兵器；大师一枪误中熊颈白色毛团（要害），贯穿而出；剑客以金绝剑劈入熊脑，黑熊狂嚎后倒地身亡。
- 二人得熊皮、四只熊掌、一枚熊胆，用离火咒生火烤肉备路粮。日暮时忽闻溪下游传来狗吠与人声。

⚙ 关键设定 / 法宝：金刚符（熏物使木质硬如精钢，沾血/水失效）；离火咒（无火自燃点火）。
➡ 下章引子：溪下游有人叫喊，似有古人接近。
