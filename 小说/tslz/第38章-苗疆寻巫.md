# 第38章 苗疆寻巫

📍 地点：滇南山林、扎卡山寨（巫师木楼）、道术空间内
👥 人物：大师、剑客、公孙凤、大天师、扎卡（老巫师）

**情节要点**

- 因飞入会破坏巫场（干扰道术、动物狂暴互伤，大天师曾误破致百人伤），四人徒步五十余里入山，沿途巨兽友善无视——皆巫师所驭。
- 大天师授读心术（感受人念）与役兽法（发己念于兽），众人才悟此前点化巨蛇用心念之理。
- 入寨见老巫师扎卡（枯槁极老、戴猿骨法杖、他心通、说河南官话）；其维持巫场十年已力衰，四面部族虎视。
- 两策：建道场扩巫场十倍（承传人难继）、或举族迁入道术空间；扎卡随大师入空间参观，见日月风云雷皆可控、甚满意，唯求日月东升西落。
- 大天师允设移动术使日月升落；大师另铭遁术法诀于寨边路碑，族人凭心念神力自开出入之门、与外界不失联。
- 扎卡召集千余族人参观，留三十时辰遁术门后众人离去，待其决议。

⚙ 关键设定 / 法宝：巫场（干扰道术、约束百兽，破则动物互伤）；读心术/役兽法（他心通）；扎卡（苗疆巫师、他心通）；道术空间迁族方案；路碑遁术门。
➡ 下章引子：扎卡族尚在商议，大天师又指引寻十年前南迁的玩蛊族——途中将有奇遇。
