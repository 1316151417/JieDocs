# 第26章 寻访天师

📍 地点：终南→江西途中（湖北鸡公山）、天师府外小镇、天师府山林迷阵
👥 人物：大师、剑客、公孙凤、云豹花花、护车灰衣人、盗贼

**情节要点**

- 飞离终南，大师施避风符在每人身上形成"风不流动层"挡罡风，剑遁时速可近四百公里。
- 过湖北鸡公山，见盗贼围攻护车灰衣人；大师首次投巽风符，符离手自燃，飞砂走石，盗贼团团转无法组攻，护车人有序脱险。
- 午前抵天师府外小镇，街上半数道装，符箓摊林立；镇摊竟有"掌中五雷引"（地仙级掌心雷符，价千八百两，当代掌门所制）。
- 镇上评价大天师：贪财吝啬不好色，却是镇人衣食父母；问讯知张真人近日又云游外出。
- 入镇外天师府山林迷阵，小径生岔、雾起回路消失，二人以阴阳数理选路破解，终出阵见天师府红墙绿瓦，大门洞开，门槛上竟随意躺一人睡觉。

⚙ 关键设定 / 法宝：避风符（挡飞行罡风）；巽风符（首次实用，飞砂走石）；掌中五雷引（地仙级掌心雷符）；天师府山林迷阵（阴阳数理选路破解）。
