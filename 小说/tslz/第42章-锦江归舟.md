# 第42章 锦江归舟

📍 地点：金沙江-岷江水路/乐山/益州望江楼
👥 人物：大师、剑客、公孙凤、大天师、薛涛、方大娘、胖道钟涛、黄征安（黄胡子）

**情节要点**

- 四人乘飞船顺金沙江、岷江上行抵乐山，观凌云大佛；大天师嫌世上大像皆为佛造，决意雕一尊更胜的道家天尊像。
- 次日逆岷江而上，公孙凤以飞剑为船动力连用两日大进；黄昏抵望江楼，闻薛涛琴声，以箫笛相和，重逢薛涛与方大娘。
- 大天师与方大娘（织女门方毓堃）竟是四十年前总角之交；公孙凤自报是公孙三燕侄女，众人盘根错节皆旧识。
- 请薛涛荐玉工，青羊宫胖道钟涛（擅陆地飞行术）闻琴即至，见巨玉璞狂喜，飞奔去拉来玉工黄征安。
- 黄胡子贴耳听石、断为老坑祖母绿级、无裂隙极品，追问此玉何来、是谁的。

⚙ 关键设定 / 法宝：胖道钟涛、黄胡子均吴道子画僮一脉第三代传人（塑像/玉雕各擅）；公孙凤飞剑渐可扛船。
➡ 下章引子：玉工既得，黄胡子欲以"吴带当风"风格雕天尊像，需金刚符与切玉新工具。
