# 第06章 破鬼妪坟

📍 地点：汶川附近小山村 → 村后坟包 → 坟下石洞石室
👥 人物：大师、剑客、骆子成、吉伯（村老汉）、三阴鬼妪（妖人）、被掳八村民

**情节要点**

- 雨后投宿小山村，连失八名男子，二人自告除妖。
- 探村后以乾坤一宝打杀一只黄目妖兽收魂；开阴阳眼见坟边狐妖，断正主在坟中。
- 坟洞入地，大师血点金刚符护体（半小时）。洞中八被掳村民如僵尸围来，摇惊魂钟定住穿过。
- 内室遇三阴鬼妪，自承布僵尸阵掳人。掷天魔丹炸伤鬼妪，鬼妪飞石砸伤大师（靠金刚符保命）。
- 鬼妪鬼缠丝缚剑客夺剑。大师危急念飞剑诀竟成，金绝剑飞回斩断鬼妪左臂，鬼妪遁术逃。
- 悟飞剑诀关键：须以血涂剑（剑柄藏血筒）。又悟移山诀（升石飞射）。
- 以震灵诀唤醒八"僵尸"（实为永久催眠），领九人出洞，村民夹道欢迎。

⚙ 关键设定 / 法宝：飞剑诀（关键：滴血驭剑/剑柄藏血筒）；金刚符（血化生效，护体半小时）；阴阳眼（夜视、见妖魅）；移山诀（升石飞射）；震灵诀（解催眠）；隐身符（一次性）；五鬼搬运、鬼缠丝（鬼妪术）。
➡ 下章引子：云豹再度追来；二人留村练法术，将悟出御剑飞行。
