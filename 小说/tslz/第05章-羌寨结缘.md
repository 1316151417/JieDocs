# 第05章 羌寨结缘

📍 地点：荒山野林 → 羌寨（山上）→ 岷江栈道 → 荒山溪边营地
👥 人物：大师、剑客、骆子成（成都行商）、羌酋及羌人、云豹花花

**情节要点**

- 遇成都行商骆子成（以盐茶换山货），亮熊皮蛇皮，受邀结伴返成都。
- 至羌寨（石屋碉楼），二人蛇皮被认出是除害杀蛇王，成寨中英雄受披皮致敬。
- 羌酋设牦牛宴、咂酒、跳锅庄、摔康狂欢；夜遣处女暖被，二人仓皇逃出。
- 随骆子成下山走岷江栈道，夜宿溪边削竹吹现代小调。
- 后半夜云豹潜来伏二人中间，天亮惊呆骆子成——竟是所救之豹尾随二三百里。二人踢走豹，笑而不答。

⚙ 关键设定 / 法宝：羌寨防御体系（石屋碉楼）；咂酒/跳锅庄/摔康风俗。
➡ 下章引子：一行人继续南下，将遇山村闹妖怪、破鬼妪坟。
