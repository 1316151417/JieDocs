# 第23章 庆功宴饯别酒

📍 地点：太行八寨大寨校场、寨门
👥 人物：大师、剑客、公孙凤、余日庆、牛金鹏、骆擎山、云豹花花

**情节要点**

- 余日庆坚持先喝庆功酒方放行；下午举寨三千人开三百余桌，马肉米酒庆功兼饯别。
- 剑客邀余日庆舞其祖传吴钩剑法，余日庆献舞；舞毕剑客御剑于暮色中凌空绘秋菊，无形削断寨门碗口粗拴马桩，满寨惊服。
- 余日庆问飞剑符是否人人可用，大师答须强念力；二人悟出新法——直接画飞剑诀符，由使用者点血烧熏给剑。
- 大师就地画三张飞剑符；余日庆咬破滴血熏剑，初试剑能动、离桌飞三丈即坠；公孙凤抢符照施，短剑一飞冲天数十丈，刺穿拴马桩，唯拔剑不能。
- 二人判定成败关键在念力专注持久，非剑之轻重。
- 夜议飞剑符有效期：旧符见水血即失效，唯玉葫芦地龙血所画符永固，欲全身画金刚符尚需问大天师。次日天明全寨送别，三人一豹御木剑腾空而去。

⚙ 关键设定 / 法宝：飞剑诀（点血烧熏给剑，凭念力驭剑）；吴钩剑（剑头侧出三寸分支似短戈）；地龙血画符永固。
➡ 下章引子：三人一豹飞离太行，下一目标——寻大天师问神之遁与符法之秘（暗示往终南山）。
