# 第09章 望江论道

📍 地点：成都衣帽店 → 兵器铺 → 祥记皮行 → 望江楼（锦江边）→ 贡嘎大雪山
👥 人物：大师、剑客、薛涛（女校书）、方大娘（神针大娘）、堂倌

**情节要点**

- 买才子装（金兑银一两换二十一两），配剑鞘。祥记裁不动蛇皮，荐方大娘在望江楼看薛涛。
- 望江楼访薛涛被堂倌挡驾，大师以"不会做诗也会偷"通传入，见薛涛（校书）与方大娘（神针）。
- 方大娘要二人过薛涛"偷诗"关。大师偷白乐天句并泄"此时无声胜有声"天机（此句尚未写出），又预薛涛筑楼寿七十三，惊二妇。
- 求方大娘以金绝剑裁蛇皮制水靠宝衣四套，不收钱，三天取。
- 三天拓碑四百余通请薛涛签名款，学得运气调息恢复术。
- 方大娘交宝衣（金丝线缝永不坏），透露需雪莲调病。二人驾剑遁飞贡嘎，一时采雪莲百余株返。
- 赠方大娘十五朵、薛涛十朵，余卖药店赚八百余两。薛涛闻竹笛吹现代曲，赠两支工艺箫笛。

⚙ 关键设定 / 法宝：蛇皮宝衣（水靠式，金丝线缝永不坏，空手入白刃）；雪莲（妇科止血补气灵药）；运气调息术（恢复法力倍速）；拓碑藏品（薛涛签名款）。
➡ 下章引子：二人离成都驾剑遁沿长江东下寻大天师，将在巫山遇仙。
