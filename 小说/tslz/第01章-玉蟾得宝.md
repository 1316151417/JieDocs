# 第01章 玉蟾得宝

📍 地点：考古队驻地院落 → 玉蟾台（临河小土墩）→ 宿舍 → 院落（穿越）
👥 人物：大师、剑客（考古队搭档）、考古队司机

**情节要点**

- 大师借得文物"神之遁"羊皮书，苦参"参蟾而逸"一句不解；剑客不以为然。
- 司机提玉蟾台传说（杀玉蟾精/拜蟾宫），大师悟"蟾"即月亮，前往一探。
- 以风水勘出真坛不在高岗凉亭，而在临河小土墩，疑大天师布疑阵藏物。
- 挖得蝌蚪文石碣，译出为阴阳龙虎玄阴坛，唐宪宗元和次年立，留器待有缘。
- 碣下铜盒私藏，开盒得金绝阴阳剑、乾坤一宝（紫玉葫芦）、伏魔神帕、惊魂钟、玉管笔、圣符纸及三十六符咒。
- 试离火咒、霹雳符皆成，飞剑诀、神之遁仍不通。
- 夜试神之遁：披帕负剑指月念咒，月变暗红，二人发光飘起。
- 落地由夜变昼，身处陌生树林，时空俱变，不知何地、能否归。

⚙ 关键设定 / 法宝：神之遁（时空穿越术，"蟾"即月亮）；玉蟾台阴阳龙虎玄阴坛；铜盒法宝——金绝阴阳剑（白金混陨星铸，斩妖除魔）、乾坤一宝（紫玉葫芦，收妖魂化天魔丹）、伏魔神帕（辟邪兼载咒文）、惊魂钟、玉管狼毫、圣符纸、三十六道符咒（含离火咒、霹雳符）。
➡ 下章引子：二人穿越到陌生荒野，不知何地、何年、如何归，只能见步行步。
