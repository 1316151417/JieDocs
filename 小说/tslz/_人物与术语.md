# 《天师列传》人物与术语表（供各章保持一致）

## 主要人物
- **大师** ＝ 洪达士：古文字专家、玄学爱好者，绰号"大师"，考古队员，穿越后修道。本名少用。
- **剑客** ＝ 龙剑可：发掘巧手、剑术高手（省武术赛舞剑银牌、击剑冠军），绰号"剑客"，大师搭档，一文一武。
- **公孙凤**：女飞贼，红线（红线盗盒）传人；先被擒后同行，后拜大天师为徒。大师的红颜之一。
- **大天师** ＝ 张宗禹：神之遁的创造者、传道高人，收公孙凤为徒，全程授业解惑。
- **云豹花花**：大师救活并收服的灵兽云豹，常随行。
- **余日庆**：太行八寨头领（老四），后继任老大，习飞剑符。
- **骆子成**：羌寨一带行商，引二人入羌寨。
- **石霸**：晚唐猎人，二人在其家得知身处晚唐、配制火药。
- **薛涛 / 方大娘**：成都女校书薛涛、方大娘（制蛇皮宝衣）。
- **韩湘子**：八仙之一，终南山隐士。
- **袁天启**：巫山潜道。
- **吕洞宾（纯阳真人）**：草海所遇仙人。
- **扎卡 / 嘎多**：苗疆巫师扎卡、寻蛊族嘎多。
- **元稹**：彝陵所识诗人。
- **钟涛（胖道）/ 黄征安（黄胡子玉工）**：锦江重逢的友人。

## 关键术语/法宝
- **神之遁**：羊皮书所载时空穿越遁术（时空扭曲），全书起点。
- **飞剑诀 / 剑遁**：滴血驭剑、御剑飞行。
- **道术空间 / 乾坤一宝 / 乾坤袋**：可收纳万物、自成天地的空间法宝。
- **三十六洞天**：大师剑客自创的三十六个空间世界（创世）。
- **常见法诀**：移山诀、金刚符、五雷符、离火诀、九天玄冰诀、巽风符、天魔丹、伏魔帕、惊魂钟。
- **玄冰离火枪**：以离火诀发冰弹的连发火器，二人造物。
- **连弩 / 三大弩阵**：雁行阵、城形箭垒、渐退阵。
- **神之武装**：罗马篇中四人编造、用法诀伪装成神器的骑士装备。

## 时空背景
现代人穿越至**晚唐**（约唐末），后遍历蜀地、太行、终南、建康、苗疆、缅北、草海、楼兰、希腊、罗马等，兼有"创世/空间"线。
